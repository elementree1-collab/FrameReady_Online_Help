iPad Overview

An iPad can be used to access your FrameReady software within your own Wi-Fi area (called: In-Store) or used to run FrameReady independently, without Wi-Fi, outside your business location (called: Off-Site).

FileMaker Pro 19 icon.

Overview

FrameReady offers the option to use FileMaker Go on your iPad -- convenient, mobile and space-saving! Information is updated in real time on both the server computer and the iPad.

  • The iPad runs the FileMaker Go 19 app (free). See also: iPad Requirements

  • Your FileMaker files and data is made accessible either:

    • by transferring files to the iPad via iTunes, or

    • by connecting via Wi-Fi to your FileMaker server computer, on your local network, which is running the FrameReady program.

Requirements

  • Requires FileMaker Server software, installed on a separate computer, to host the FrameReady files.

  • Requires Claris FileMaker Go 19 (free download from the App Store).

  • FileMaker Go 19.4 - 19.5 is compatible with iOS devices running iOS 14 minimum.

  • Requires a Wi-Fi connection.

  • Requires the purchase of an additional Network License.

  • Requires an AirPrint compatible printer if you wish to print from the iPad.

Two ways to use FrameReady on your iPad

Using an iPad In-Store

  • An additional network license is required. FileMaker Server is required.

  • Use the iPad on your shop's private wifi to access FrameReady (which is installed and running on your server computer), to take orders, update inventory, add photos of artwork, etc.

  • Information is updated in real time on both the server computer and the iPad.

  • No syncing via iTunes is required.

  • Access is only available within the range of your store’s Wi-Fi.

  • See: Set up iPad for In-Store

Using an iPad Off-Site

  • Transfer using iTunes, a copy of your FrameReady software to take to any location on the iPad, e.g. art shows, in-home consultations, etc.

  • Any changes made on the iPad will need to be manually re-entered into the FrameReady software on your computer or, if the computer has not been touched while you were off-site (preferred method), then the files can be manually transferred back to the computer via iTunes.

  • See: Set up iPad for Off-Site

Note: The iPad is unable to update vendors or send an email with an attachment. This is due to limitations with FileMaker Go.

Tip: You must use an AirPrint compatible printer if you wish to print from the iPad.
