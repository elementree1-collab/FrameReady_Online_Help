Add a Customer to a Work Order

Main Menu > Work Orders

Post a Work Order to an Invoice by assigning a customer to the Work Order.

How to assign a Customer to a Work Order

  1. Enter a customer by clicking on the Name, Company or Phone button.



    FrameReady searches for the customer to see if the customer has already been entered. If not, you are be asked to create a new record for them.

  2. OR, if you know the customer is new, then use the New Customer sidebar button.



    The New Customer dialog box appears.

  3. Enter the customers First Name, Last Name and, if applicable, Company. Click OK.

    The New Contact Information window appears.

  4. Fill out as much as you are able. Click Done.

    The Work Order reappears with the new customer information added.
