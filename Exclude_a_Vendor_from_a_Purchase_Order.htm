Exclude a Vendor from a Purchase Order

Main Menu > Work Orders

If you do not wish to order from a particular vendor at the time your run your Purchase Orders, then FrameReady allows you to exclude any vendor(s). The data for any omitted vendor is stored in a temporary file until the next time you process the frame order.

How to Cancel a Frame Order (per Work Order)

Important: Omitting a vendor from a PO can only be done during the Create Frame Order process.

  1. Exclude a vendor from the current Purchase Order by clicking the associated Omit button (located in the Frame Order dialog box, with the heading "Create Purchase Orders for the Following Vendors")

  2. Then, the next time you generate a Frame Order (provided there are new Work Orders), the previously omitted vendor(s) appear(s) in the list again.

See also: How to Create a Frame Order

How to Update a Work Order already posted to a Purchase Order

If you omit a vendor and then go back and change the Work Order (which used items from the omitted vendor), then those changes will not be updated in the already existing Purchase Order.

  1. To have the changes appear on the next Purchase Order, you must duplicate the Work Order.

  2. Next, make your changes to the duplicated Work Order.

  3. Delete the original Work Order.
