Set up FrameReady Multi Site

Main Menu > Setup Data > Multi Site tab

Use this section to setup and manage your Multi Site license of FrameReady.

Setup Data - Multi Site tab Explained

  • Enter as many different sites/locations as you are licensed for.

  • Use the yellow arrows at the top to move between sites/locations.

  • Only available with a FrameReady Multi Site license.

Info Tab

  1. Enter the business information pertaining to each location: Business name, address, phone, email, URL, business hours, shipping address, business number, and tax rate(s).

  2. Use the yellow arrows in the top to move between sites/locations.

  3. Click Done when finished or switch to another tab.

Email Tab

  1. Follow the same instructions as here. (Site 1 is the default.)

  2. Use the yellow arrows in the top to move between sites/locations.

  3. Click Done when finished or switch to another tab.

Reward Points Tab

This feature allows you to issue customer loyalty / reward points on all purchases. You can set the values on this screen for each individual site.

  1. Enter the monetary value of a single point in the Reward Points Ratio field.

    This is how much a customer must spend to earn one reward point.

  2. Enter the number of points needed to redeem $1.00 in the Reward Points Redemption field.

    This is how many reward points a customer must use to save one dollar.

  3. If applicable, check the Reward Points may be used to pay sales tax field.

  4. Use the yellow arrows in the top to move between sites/locations.

  5. Click Done when finished or switch to another tab.

Logo Tab

You must import your logo into each record; even if each site uses the same logo.

  1. Use the yellow arrows in the top to move between sites/locations.

  2. Click Done when finished or switch to another tab.
