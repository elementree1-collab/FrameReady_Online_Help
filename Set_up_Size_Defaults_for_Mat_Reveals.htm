Set up Size Defaults for Mat Reveals

Price Codes > Default Mat Reveals sidebar button

The Default Mat Reveals sidebar button in the Price Codes file lets you set up defaults to auto-fill a mat reveal whenever you enter a matboard number on a Work Order.

How to Change the Size Defaults for Mat Reveals

  1. Go to Price Codes and switch to Form View. Click the Default Mat Reveals sidebar button.

  2. The Default Mat Reveals dialog box appears.

  3. The default reveal values for Mats 2 to 7 are displayed; change them as desired. 

    These defaults can be over-ridden on any Work Order.

  4. Click Proceed.

Important: When you click Proceed, FrameReady performs Replace Commands and should not be interrupted. This operation may take a few moments, but is intentional (the reveal data must be updated for each and every matboard record).
