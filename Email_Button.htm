Work Orders

Main Menu > Work Orders > List View 

Email Button

  • The Email button composes an email based on the Completion Email. See: Set up Work Order Email Messages

  • When clicked, it fills in the necessary information concerning the artwork, title or description, addresses the email to the correct customer and signs it with the sales rep name in the Order Taken By field.

This is a wonderful Customer Service tool

You should ask the customer’s permission while you are taking in the Work Order if they would like to receive an email notification when their piece is ready for pick-up. Use this tool to set yourself apart from your competition and save your staff time and effort. Unclaimed framing is difficult to store and, if you have not received payment, costly.

  • The message may be edited on-screen for individual customers. To edit the base message, see: Set up Work Order Email Messages

  • This function will only operate if an email address is present in the Contacts file. Hover your cursor over the icon on the Work Order (list view) to see a message telling you whether an address is present or not.

  • The message will display in order for you to make personal comments before clicking Send.
