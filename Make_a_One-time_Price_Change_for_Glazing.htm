Make a One-time Price Change for Glazing

Main Menu > Work Orders > Group Details

When using a code table for pricing, we often recommend that you enter the amount of 9999 for any glass sizes which are not available. This is a great way to identify to the sales person that this glass is not available and they should select a different option. HOWEVER... Sometimes you can order what the customer wants and therefore need to enter a retail price. You can change the price of an item using a code table on a work order for a one-time only situation and not have it affect subsequent pricing of that item. This will only affect the price on this work order.

  1. On the Work Order, click on the underlined word for the Group. e.g. Glazing/Fabric.

  2. On the Details screen, open the green Code Price tab.

    There are three price boxes in this tab and the field priority is as follows:

    If the box is marked for Square inch pricing, then Code Price by Square is being used.

    If the box for Square Inch is not marked, then Code Price by XY is being used.

    If the box  for Square Inch is not marked, and the Code Price by XY is empty, then the Code Price by UI is being used.

  3. From the information above, determine which price is being used: Code Price by Square Inch, by XY or by UI and highlight the amount in that field.

  4. Enter the retail price you want to charge for this item on this one Work Order.

    When you leave the field, you should see the price change at the top of the screen (in the tan field).

  5. Click Done to return to the Work Order screen.
