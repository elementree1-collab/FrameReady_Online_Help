Digital Images

Having a digital image of a moulding profile or a piece of consignment art can be invaluable as a reference. Images can be stored in many different files in FrameReady.

  • See also: Resize Digital Images

Importing Images into FrameReady

  • You can import reference images for:

    • retail products

    • customer’s artwork

    • pre, during, and post production images of the framing techniques for a Work Order

    • moulding profiles (especially helpful for mobile framers and galleries).

  • Images can be imported from any digital file or catalog.

Photos can be added from an iOS Device. See: iPhone and iPad Apps

Caution: FileMaker Inc has deprecated the "Store only a reference to the file" feature. This means it may be removed from future versions of FileMaker Pro.

  • Avoid using the Store only as Reference to the file option.

  • Do not import large image files.

    • Resize before importing, as this helps prevent the database from becoming too large.

  • Do not store artwork, before and aft++_{Update: FrameReady 12.2.2 (or higher) can help you resize images to 600Kb in size to help keep your database size manageable. Use the Resize button to scale the image down to a useful size for storage.


  • See: Resize Digital Images

Price Codes – Moulding Group

Many moulding companies have web sites where you may capture catalog profile images. Having them in your FrameReady program allows the cutter in the back room to double check the selection of a moulding on a certain work order.

Price Codes file > Moulding group > Form View > Image tab

  • Click Add a Photo to import a JPEG or TIF file of your moulding sample.

  • Use the Resize button to scale the image down to a useful size for storage.

  • You may use the Note field for things such as moulding is prone to flaws, wax finish is hand rubbed.

Price Codes – All Other Groups

You may wish to reference an obscure component item, such as comp corners or security hangers, with a digital photo.

Price Codes file > other groups > Form View > Image tab

  • Click the Add to Photo button to import a photo.

  • Use the Resize button to scale the image down to a useful size for storage.

Products File

Products file > Form View > Image tab

  • Click the Add to Photo button to import a photo.

  • Use the Resize button to scale the image down to a useful size for storage.

Work Order File

Work Order file > Form View > Image tab

  • Picture File stores an unlimited number of digital photos. It is the same button that appears in the Shop tab of the Work Order screen. This would be where you would store photos of the step-by-step mounting or framing process of a complex or difficult order.

  • Use the Resize button to scale the image down to a useful size for storage.

  • See: Add Photos to a Work Order

Contacts File

Contacts file > Form View > Artists tab > Add a Photo button

  • The Print Bio feature is a document is for galleries wanting to produce a write-up about a certain contact (artist) for a gallery show or reception. The image prints onto this document.

  • Use the Resize button to scale the image down to a useful size for storage.

Art Resource File

Main Menu > Art Resource file > Subject tab

  • The images in this file are not entered here, but loaded from the Products file.

  • There is an option to have a product picture print on the invoice under Invoice Options. Only pictures uploaded to the Products file will be printed, not images uploaded to the Work Order file.

  • To delete an unwanted image, click on the image and press the Delete or Backspace key on your keyboard.
