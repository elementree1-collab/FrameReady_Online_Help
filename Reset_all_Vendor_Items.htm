Reset all Vendor Items

Main Menu > Update Vendor Pricing button

Occasionally, a vendor update contains corrections to a number of items, e.g. those with an incorrect moulding width, or description. However, simply downloading the update will not replace that data in your system.

Warning: if you have added UPC/barcode numbers (because the vendor did not provide them) or have created your own categories for these items, then do not use this feature.

How to Reset all Items from a Vendor

  1. On the Main Menu, in the Price Codes section, click the Update Vendor Pricing button.

  2. Select the supplier.

  3. While holding the Ctrl key on the keyboard, click the Proceed button.

  4. Once the Proceed/Cancel screen disappears, you can let go of the Ctrl key.

    FrameReady downloads and resets the data fields for that vendor. This procedure will not affect Inventory or PO settings.

All older versions of FrameReady

If you Track Inventory

  1. Navigate to the Price Codes file and click the Find button.

  2. Select the supplier from the Supplier drop-down.

  3. Enter  >0  into the Auto Inv or Manual Inv Qty box (depending which inventory method you use).

  4. Click Perform Find. This finds inventory items from the supplier.

  5. Click the Inventory List View button and print the list.

  6. Click Find again.

  7. Select the same supplier from the Supplier list.

  8. Click Perform Find. This finds all items from the supplier.

  9. From the Menubar, select Records > Delete found records.

  10. Go to the Main Menu.

  11. Click the Update Vendor Pricing button.

  12. Locate and update the supplier from the Vendor Update screen.

  13. From your printed list, re-enter any inventory.

If you use the Corner Sample box

  1. Navigate to the Price Codes file and click the Find button.

  2. Select the supplier from the Supplier list.

  3. Check the Corner Sample checkbox.

  4. Click Perform Find.

  5. Print the list.

  6. Click Find.

  7. Select the supplier from the Supplier list.

  8. Click Perform Find.

  9. Select Delete found records from the Records menu.

  10. Update the supplier from the Vendor Update screen.

  11. Re-select any Corner Sample items from your printed list.

If you do not Track Inventory and do not use the Corner Sample box

  1. Navigate to the Price Codes file and click the Find button.

  2. Select the supplier from the Supplier list.

  3. Click Perform Find.

  4. Select Delete found records from the Records menu.

  5. Update the supplier from the Vendor Update screen.
