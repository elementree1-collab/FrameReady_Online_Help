Print only the Items you Stock

Question

When I update my vendor pricing does it add items from the vendor's catalog that I do not currently have in stock? 

Answer

Yes. During the vendor update process, items not found in your files are imported as new items. (You can choose to not import the new items.) The vendor update will pause and ask if you wish to print a list of these items.

However, if you wish to print a list of these items but omit the ones you do not have, you will need to identify which items you are using on the list by using either the Moulding or Matboard Sample box or the Marked box. Use the following instructions, after completing the vendor update:

How to Print Only the Items You Stock

  1. You will need the correct Validation Date for the company in question.

    The Validation Date can be found on the Vendor Update screen by clicking Main Menu > Update Vendor Pricing. Look in the Validation Date column.

  2. Go into your Price Codes.

  3. If you are going to use the Marked box, then click on the Perform menu and select Unmark All.

    If you are going to use the Sample box to identify your records, then ignore this step.

    See also: Using the Marked Field

Caution: this will unmark any previously marked items you may have.

  1. Click the Find button.

  2. Select the appropriate Supplier from the Supplier drop-down list.

  3. Enter the Vendor's Validation Date into the Validation date field top right.

  4. Click the Perform Find button.

    Results appear in a list view.

  5. Click in the Moulding or Matboard Sample box or the Marked box for each of the new moulding/matboard items that you actually carry.

  6. Click the Find button again.

  7. Click the Marked box. Or, click the Moulding or Matboard Sample box AND enter the Validation Date AND Supplier.

  8. Click Perform Find.

    A list with only the items you marked appears.

  9. Print the list using the Print List button at the top.

  10. There are three different types of printouts you can select from:

    • Retail Price – lists the Item Number, Description of moulding (as provided by manufacturer), Supplier, and Retail Price per foot. It fits approx. 32 items per page.

    • Items Only –  3 columns of Item Number only. This option may make it more difficult to find your sample.

    • Detailed – fits 12 items per page and provides all pricing and size info as well as Item, Description, Barcode, Group and Validation Date.

  11. The Sort dialog box appears. The default is to sort by Item Number. Click Sort or Cancel if you want the list to stay as it appears.

    A print preview appears.
