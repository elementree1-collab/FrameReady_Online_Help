The Solution

  • Please see this Help Article: Missing Markups

“Could not be found in the Price Codes file”

The Problem

  • I’m trying to enter in a component on a Work Order and I get the message “could not be found in the Price Codes file”. Yet I go to the Price Codes file and the item is there. What am I doing wrong?

The Solution

  • There is a really good chance that you have entered the quotes sign  ”  into the Item number field in the Price Codes file, e.g. when pricing mirrors.

  • Never use the  ”  sign as an abbreviation for the word inch. This sign cannot be read by FileMaker Pro. Instead use Mirror- one inch as the Item number, for example.
