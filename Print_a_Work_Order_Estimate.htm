Print a Work Order Estimate (Blind)

Main Menu > Work Orders

One document you may choose to give to a customer is the Blind Estimate: it shows prices but not moulding or matboard numbers.

Work Order Estimate Overview

  • Shows individual prices of each component and total but no details of mat or moulding numbers.

  • Records which employee prepared the quote and includes a disclaimer footnote (which you can compose for your own shop requirements, e.g. This estimate is only good for 30 days).

  • Useful for giving a quote when you know the customer will take it down the street and compare with your competitor.

How to Save  a Work Order Estimate as a PDF

  1. Locate the customer’s Work Order (in form view).

  2. Click the Print Documents sidebar button on the left.

  3. Be sure that the print settings (bottom of the screen) say Pause On Preview and Show Print Dialog Box both say Yes.

  4. Click the Estimate button.



    A preview screen appears with a menu at the very top of the screen that says Print or Save as PDF.

  5. Click Save as PDF.



    The Save Records as PDF dialog box appears.

  6. In the File name field type the name you wish to use for this document.

Tip: Use the Work Order number or the customer’s name.

  1. At the top of the screen, in the Save In field, select the location where you would like to save the document.

  2. Click Save.

    The previous screen appears.

  3. Click Continue.

  4. Click Cancel.

How to Print a Work Order Estimate

  1. Go to Work Orders file form view > Print Documents sidebar button on left > Estimate.

  2. Choose Save as PDF or click Continue to print.

    or

    Go to Work Orders file > Print.

  3. Choose Estimate.

  4. Choose Save as PDF or click Continue to print.
