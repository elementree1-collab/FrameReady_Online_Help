Main Menu > Price Codes > List View Button

  • See also: Price Codes Form View

Price Codes List View

New Button

  • Create a new Price Codes file record.

Delete All Discontinued Items

  • Performs a search for all items marked as “Discontinued” giving you the option to delete them.

Unmark All Button

  • Find all marked records and deselect the X.

Mark Found Set Button

  • Put an X in the Marked field of all the records that make up the current found set.

    Be sure to unmark previously marked records prior to marking your new set or the newly marked records will be added to the group when your perform a Find for Marked records.

  • See also: Using the Marked Field

Find Marked Records Button

  • Find and list all marked records.

Delete Record Button

  • Permanently remove the current record.

Print List Button

  • Print the found set or, if none, the full list.

  • You can choose to print a Retail Price, Item Only or Detailed view.

Inventory List View Button

  • Switch to an data input screen; useful for entering inventory details, particularly at year end.

  • Choose Other List View to exit.

Modify Order Type Button

  • Globally set a Length, Chop or Join ordering/pricing for all mouldings or for a selected group or vendor.

Flag As Discontinued Button

  • Set the Verification field to “Discontinued” for the current found set.
