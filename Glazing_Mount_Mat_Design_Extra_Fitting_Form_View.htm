Explanation of the Glass, Mounting, Mat Design, Extra and Fitting Form Views

Describing the Groups: Glass, Mounting, Mat Design, Hardware, Extra and Fitting screens.

This item is being priced by Label

  • This information is determined by what you have entered into the blue Pricing tab.

Item Field

  • Either the number supplied by the vendor or a descriptor created by you, e.g. Anti-reflective glass = AR 24×36.

  • For Mounting items: Hover over the Description to see the Quantity On Hand. If the item is Not Verified or Discontinued, then the message appears to the left.

UPC Field 

  • The barcode supplied by some vendors on their samples. Items in the Price Codes file can be entered into a Work Order by either the Item number or the UPC.

Manufacturer #  Field

  • Catalog number of this item supplied by the vendor. Optional.

Description Field

  • Supplied by the manufacturer and appears on the Work Order screen and on the printed copy.

Thickness Field

  • If you include this information, then it will be used in the rabbet depth calculator.

Cost  Field

  • The list price as supplied by the vendor.

Dimension Drop-down

  • Defaults to 32×40 if no entry is selected from the drop-down list.

  • The size of stock affects the price per square inch which FrameReady uses to calculate the area and price of glazing or mounting. If a size is selected, then make sure that the cost corresponds to the size.

Minimum Cost Field / Popover

  • If your supplier has a minimum cost for when ordering the item, then you can enter it here.

Markup Field / Popover

  • Enter a factor used to mark up the Cost x Area. It is what is detailed in the blue Pricing tab.

Set Price Field / Popover

  • Details from the blue Pricing tab.

Minimum Price Field / Popover

  • if you wish to charge a minimum price that overrides the calculated formula, then you can enter it here. A pop-over box appears into which  you can enter a formula or the actual price. This is the same as typing it into the Pricing > Minimum tab to the right.

Note: the Minimum Cost field (above) can be used in the formula to derive the Minimum Price, e.g., Minimum Cost * 2.

Code Field / Popover

  • Details from the blue Pricing tab.

Supplier Drop-down

  • Auto-filled when vendor pricing is updated from the FrameReady website.

  • If you are entering your own mouldings, then use this field for either the manufacturer or distributor’s name.

Category Drop-down

  • Sometimes provided by the manufacturer and refers to a group of moulding, e.g. Winterlude Collection. Optional.

Group Drop-down

  • Be sure to place the item in the correct group.

  • Also determines what field it will appear in on the Work Order.
