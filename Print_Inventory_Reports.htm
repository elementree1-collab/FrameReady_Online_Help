Print Inventory Reports

Main Menu > Price Codes > List View > Inventory List View > Print - Year End button

How to edit a Work Order when the Auto Update of materials inventory feature is active.

  • The Inventory Report showing all items with a value in the Quantity field (negative, zero or higher).

  • It also shows Location, Variance, Actual and Qty fields for each item and is sorted by Supplier only.

How to Print an Inventory Count

  1. Go to Price Codes file.

  2. Click the Moulding sidebar button to find all of the wood, metal, liner, fillet etc. items in your database. You can then do the same for each of the other sidebar button groups listed on the left side of the Form View screen.

    or

    You may want to search for only those items that are in stock, i.e. click Find and enter  >0  into the Qty field. Optionally select a Supplier if you want to know how many Larson Juhl, for example, you have.

  3. Switch to List View.

  4. Click the Inventory List View button.



    The Inventory List View screen appears.

  5. Click the Print - Year End button.

  6. This report also includes the total (wholesale) cost.

Why is there a negative quantity on my physical inventory list?

  • A negative quantity appears when an item has been sold but was not first recorded as received into inventory.

  • Remove the negative sign to correct this.

Inventory Report from the Main Menu

Requires use of the Auto Update System.

  • The Inventory Reports button on the Main Menu generates a report (using the All Price Code Items button) which lets you sort the report by Location or by Group.

  • It shows all moulding, mat and glass items with a quantity greater than zero.

  • It does not show the Variance or Actual columns, nor does it provide a wholesale cost total.
