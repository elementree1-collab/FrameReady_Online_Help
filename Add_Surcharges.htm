Add Surcharges

Main Menu > Price Codes

Some vendors apply surcharges to certain mouldings. Each moulding might have a specific value for which you need to keep track and/or a minimum amount which is required to place an order. This is done in the Frame Pricing tab in the Price Codes File.

How to Add Moulding Surcharges

  1. Locate the moulding record in the Price Codes file.

  2. Open the blue Frame Pricing tab.

  3. There are several options to consider and/or use:

    • Minimum Footage

    • Oversize Footage

    • Width Multiplier

    • Ship Code

  4. See below for further details.

Minimum Footage

  • Enter the minimum footage (or meters) that your vendor charges you for this particular moulding.

  • When this moulding is entered onto a Work Order, and the footage required is less than the minimum, then the Retail Price is based on the Minimum Footage.

Oversize Footage Fields

  • Some vendors have a surcharge when the footage exceeds a certain amount, e.g. 12 feet, after which a percentage is added to the finished frame, e.g. 10%. They may also have a second charge for over a higher amount, e.g. 15 feet, Surcharge: 20%.

  • Enter the amount of Footage as a whole number.

Surcharge Fields

  • Percentage only; enter as a decimal, e.g.  .10  = 10%.

  • This amount is applied for all footage which exceeds the value displayed above it.

Width Multiplier

  • The moulding width multiplier compensates for footage lost when cutting a frame on certain chop saws.

  • The value in this field is multiplied against moulding width, for example, a 2" moulding times a 1.25 multiplier increases the moulding width to 2 1/2" and the required footage is increased accordingly.

  • This field must always have a value of at least 1 and not exceed 2.

  • This multiplier may be set for each individual moulding or may be set across the board from Main Menu > Work Order > Options tab > More Options text button > General tab. If you set the width multiplier from the Main Menu, then changing it here for one moulding overrides the Main Menu setting.

Ship Code

  • To cover costs based on size (Moulding only).

  • Adds pricing of a Code Table to the retail price of a moulding.

  • The code can be applied to an individual moulding record, to a selected group (eg. wood, liner, etc.) of a supplier, or to all moulding items from a supplier.

  • The Code Table:

    • can be based on united inch size to cover costs (ie. joining fees)

    • can be based on width x height to cover additional expenses (ie. shipping costs)

    • can be used in combination with Canadian Vendor Code Matrix
