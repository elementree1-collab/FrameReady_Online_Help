Print Incomplete Orders

Work Orders

As part of successful shop management, FrameReady provides different ways of printing your incomplete Work Orders.

How to Print Incomplete Orders

As a Printable Report: General Summary

This report shows the Work Order number, the Date (in M/D/YY format), the Qty, Description, Due Date, Priority, Location and Value of Art.

  1. In the Work Orders file, click the List of Incomplete Orders sidebar button (form view) or the Find Incomplete button (list view).


  2. The list of incomplete Work Orders appears in List View (if there is only one, it appears in Form View).

  3. Click the Print List button.

  4. A print preview of the document appears.

As a Printable Report: Incomplete Schedule

This report shows the Due Date, Work Order number, Customer, Description, Frame Size, Moulding number, Matboard, Mounting and Glass numbers.

Tip: you can use all incomplete Work Orders or the Found Set.

  1. Click the Print Documents sidebar button on the left.

  2. The Print Documents window appears.

  3. Click the Schedule of Incomplete button.

  4. A dialog box appears.

  5. To use all incomplete Work Orders, click All.

    To use only the found set, click Found Set.

    A printable and highly useful document is generated for you.
