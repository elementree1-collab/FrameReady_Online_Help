Adding or Editing Footnote Text

  1. From the Main Menu click Set up Data and open the Footnotes tab.

  2. Type whichever text you wish in the text block. The text is limited to the space available.

The text is limited to the space visible in the boxed area.

These disclaimers appear on the printed forms only.

Tip: You can format text (font, size and color) from Menu Bar > Format or select some text and right-click.

  1. If defaulting your printed customer documents to French or Spanish, then these footnotes may be typed in those languages.

  2. Click Done to return to the Main Menu.
