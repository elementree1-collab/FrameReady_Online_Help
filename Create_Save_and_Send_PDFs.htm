Create, Save, and Send PDFs

Invoices and documents from the Work Order file may be conveniently sent to customers as an email PDF attachment.

Where to Save Files to be Used by FrameReady?

s your Desktop feeling cluttered? Are you having difficulty keeping track of where you can find the different PDFs and images you have created for your frame orders and invoices? Perhaps it’s time to be a bit more organized.

Just like you would keep track of physical documents in folders in a filing cabinet, you can create simple systems in your computer to organize your important documents. The options for creating systems are endless, but let us recommend one that we believe to be the most simplistic.

By default if you have upgraded to FrameReady 12, you may have realized that FrameReady has created a folder on your computer called FrameReady Documents. This folder was created to store PDF files for your invoices, proposals, purchase orders, etc. If you are creating a PDF copy of a document to email to a contact, FrameReady will store it in this folder for you.

This folder can also be used to store any photographs you’ve taken of artwork or finished pieces. You can create folders to store moulding sample images. If you collect PDF catalogues for your vendors, they can also go here.

Again, what you choose to store and how you do it is up to you, but taking some time to organize your computer will not only benefit you but any employee working with you. You’ll always know where to find your information and everyone else will, too.

How to set FrameReady up for PDF

FrameReady will automatically create this folder if it is not found.

  • If you haven’t created a FrameReady Document folder, then the first time you attempt to send a PDF you will see a dialog box with the message:

    • [Invoice_##.pdf" could not be created on this disk. Use a different name, make more room on the disk, unlock it or use a different disk.

  • Then you will see a dialog box:

    • Please create a folder in your Documents folder named "FrameReady Documents" in which to store the PDF files. Then try again."

Create a Folder for Windows

  1. Go to File Explorer > Documents.

  2. Look for a folder named FrameReady Documents. If it is not there, then do the following:

  3. Click the New Folder button.

  4. Name the new foldert  FrameReady Documents  

    Note the space between the words.

Create a Folder for Mac OS X

  1. Go to Finder > Documents.

  2. Create a New Folder in Documents.

  3. Name it  FrameReady Documents  

    Note the space between the words.

To avoid these error messages make sure you set up your FrameReady Documents folder first.

How to set up PDF options for Invoices

  1. Edit your message using the directions here: Set up Invoice Email Message

  2. Click Done.

  3. On the Main Menu, in the Invoices section, open the Options tab.

  4. Locate the Pause on Preview radio button and select Yes.

How to send a PDF from an Invoice

  1. Navigate to the desired Invoice using the Find button or arrows.

  2. Click the Email envelope icon at the top right of the Invoice screen.

  3. FrameReady generates an email with the pertinent invoice based on the text information you entered under Main Menu > Invoices (blue section) > Options tab > Edit Email Messagebutton.

How to send a PDF Proposal from a Work Order

  1. Go to the desired Work Order from which you wish to send a proposal.

  2. In the menu bar, click Email and choose Edit Default Message.

  3. Open the Proposal Email tab.

  4. Make your preferred edits.

  5. Click Done.

  6. Make sure you have an email address selected for the customer.

  7. In the menu bar, click Email and choose Proposal.

  8. FrameReady generates an email with the pertinent proposal based on the text information you entered in Main Menu.

How to send a PDF Completion Email from a Work Order

  1. Locate the desired Work Order from which you wish to send a notice that the frame is ready to be picked up.

  2. In the menu bar, click Email and choose Edit Default Message.

  3. Open the Proposal Email tab.

  4. Make your preferred edits.

  5. Click Done.

  6. Make sure you have a valid email address selected for the customer.

  7. In the menu bar, click Email and choose Work Order Completed.

  8. FrameReady generates an email with the pertinent job completion information based on the edits you made in Main Menu.
