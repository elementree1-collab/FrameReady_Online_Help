Add and Price Spacers

Main Menu > Work Orders

Whether you are using Foamboard, FrameSpace, EconoSpace, or something else, you need to identify in the Work Order which spacer you are using, where it is being placed, and the retail price to charge.

How to Enter Spacers on a Work Order

Placement

  • Use the checkbox (between the mat descriptions) to identify where the spacer will be placed.

    • Scroll down to "Mat Entry" in this Article to Learn More...

  • If entering more than three mats, then use the Mats Detail screen (click the underlined Mats button). 

    • See item #6 in this Article to Learn More...

Spacer

  • If you are entering foamboard, then it can be selected from the Mount/Stretch group. You can also use the yellow Quantity field for when you need more than one layer.

  • If you are using FrameSpace or EconoSpace, then use the Extra group to make your selection.

  • If the item you want is not listed in the Work Order drop down, then add it to the PriceCodes file. 

    • Learn how to add: Mat Design, Extra & Fitting items...

Pricing a Spacer

  • There is a challenge in taking a linear item sold by the foot and then pricing it by the United Inch (UI) but it can be done.

  • The calculation is: UI * 2 / 12 * (retail price per foot) / UI = Price per UI

  • An example would be:

    11 + 14 = 25UI * 2 = 50" / 12" = 4.166 ft * $15 (cost * markup) = $62.49 therefore ( $62.49 / 25UI = price per UI of $2.49)

  • You can create an Excel spreadsheet to calculate the Price per UI.

  • Or, download this one created in Excel *. Feel free to modify it, test it, and make changes. Enter your numbers in the pale yellow fields. Then take the amount in the Excel's Price per UI column and enter it into FrameReady, under the Extra Pricing tab, in the Price Per UI field.

* The Price Per UI field rounds up to two decimals, e.g.  .17  or, for greater accuracy, you may want to use 3 or 4 decimal places, e.g.  .1675
