Labels Form View

Main Menu > Product Labels

The Product Labels file is where a label can be printed for a retail product, a work order, or a price code item.

Labels Form View Explained

Top Navigation Buttons

  • The Main Menu icon button takes you back to the Main Menu when you are done printing or if you need to access other aspects of FrameReady.

  • The Price Codes file icon button takes you directly to the Price Codes file in case you need to look up a moulding number or perform a find for the group of mouldings you wish to create labels for.

  • The Products file icon button takes you directly to the Price Codes file in case you need to look up a product number or search for a group of items for which you wish to create labels.

  • The Work Order file icon button takes you directly to the Work Order file. This may be helpful in looking up the number of a work order for which you are printing a label.

Item Number Field

  • The Item Number can be typed in or imported from the Products or Price Codes file.

  • When an item number is entered and you press the Tab key, a lookup is performed from the Products or Work Order file. If a match is found, then all information related to the number will populate the corresponding fields.

Description Field

  • Automatically populated if the item number matches a number in either the Products, Price Codes or Work Order file, and contains a value in the Description field in that file.

  • Modifications may be made to the Description field but will not be reflected in the original record in the Products or Work Order files.

Artist Field

  • The Artist field has the same properties as the Description field.

Price Field

  • The Price field has the same properties as the Description field except that it is formatted as a number with two decimal places.

L/E# Field

  • The number and range of the limited edition print.

  • If a number is in the corresponding field in the Products file, then it is populated when you enter the Item Number.

  • When entering manually, you can enter numbers and letters into this field.

Number of Labels Needed Field

  • This field is required.

  • Set to print multiples of the same label. The number of labels needed can vary for each product number.

  • It must have a value in order to print or enter the next item. If using the Scripts menu to import multiple labels, then the number of labels printed for each item will be one -- regardless of the number entered on the screen.

Start Position Field

  • The Start Position field must be entered on the first data entry screen in order to move to the next item or print.

  • The number indicates the next available label on a sheet of labels.

  • For example, if the first 8 labels have already been used, then enter 9 as the starting position.

  • Labels are printed going down the columns not across.

Next Item Button

  • For multiple entries. It will store the previous record entered and clear the screen for the next entry.

  • The screen is basically the same as the original except for the addition of the Start Over button which will remove your previous entries and present you with a blank Data Entry screen for your first label.

Print Button

  • Prints all of the records you have created for the label identified.

  • A preview of the labels as they will be printed will appear.

  • You can cancel if you chose the wrong layout or you need to modify the data. Click Continue to print the labels.

Print Layout Number

  • The Print Layout Number field is used by FrameReady to determine which label layout to use for printing.

  • It MUST contain a value and it must be greater than 2.

  • Enter the number that corresponds with the label layout you wish to print.

Label Name and Layout Number Table

  • The Label Name can be either the name you have given to the layout or the name generated by FMP.

  • The name of the layout can be changed by going into the Layout mode and clicking on the Layouts menu and choosing Layout Setup. After creating a new layout, the name and layout number will be added to the list.

  • The actual Layout # is generated by FileMaker Pro each time you create a layout. Although you can change the name of the layout, you cannot change the number. The number is used to identify which layout screen to be printed.

  • If you delete a layout, then it will affect the printing of other labels, therefore, it is recommended that you do not delete a layout. The layout number can be seen in the Layout mode. The total number of layouts used is beside the flip book.

Start Over Button

  • The Start Over button is located on the Product Label Printing screen.

  • In the data entry screen, the Start Position field is replaced with a Start Over button which will remove all the records you have previously entered and present you with a blank data entry screen in which to enter your first label.
