Work Orders Form View Explained

Main Menu > Work Orders

Top Navigation Buttons

Find Button

  • Opens a search screen where you can enter one or more criteria by which to find a Work Order, e.g. find all Work Orders for a particular customer, or orders that don’t have an Invoice, etc.

Find All Button

  • Finds all Work Orders in the database and moves to the last record.

  • To view items in a list format, click on the List View button.

Print Button (Printer Icon)

  • Prints the current Work Order; use if you need to print only just this one Work Order.

  • It will not notate if the Work Order is one of a group.

  • Use the Print Documents sidebar button for normal printing purposes.

Sub Total Button (Calculator Icon)

  • Calculates the total of all the Work Orders for the current customer for this session

    or

    for Work Orders with the same Job # in the Shop Tab.

  • Useful when a customer has several pieces to be framed and wants to know the subtotal after two or three Work Orders.

  • Clicking this button a creates a Found Set.

Frame Notes Button (Notepad Icon)

  • The Frames Notes button brings up a dialog box where special instructions may be notated to this Work Order. When notes are entered, the button on the Work Order will change. The notes appear on the printed Work Order and on the Work Order > Printed Documents > Matboard Cut List.

Another Order for this Customer Button

  • Creates a new Work Order for the same customer. This time-saving feature automatically inserts the same customer information in the appropriate fields.

  • Use whenever a customer has more than one piece to be framed at one session.

  • It also populates the Order Taken By sales rep/ employee name field.

New Work Order Button

  • Creates a new blank Work Order for you to fill in. If you have set up any default entries on the Main Menu, these fields will be populated in your new Work Order. You can change any of the items appearing on your Work Order by using the pop-up menus or clear them using the green delete button.

Message/Alert Area

  • The wide, light grey slim box in the center of the screen is your Message/Alert area. It will alert you to possible errors. When the error or missing information has been corrected, the red-lettered message will disappear. Example messages: "Frame components exceed rabbet depth" or "Specify Mat Margin Value".

Scenarios Button

Blue button, center of screen

  • Scenarios allows you to store and compare up to five frame designs on a single Work Order.

  • Create multiple possibilities for the customer and make a side-by-side comparison of the components and price, all in one Work Order. When the customer has selected the design they want, it will then become the frame design for the Work Order.

  • See also: Scenarios
