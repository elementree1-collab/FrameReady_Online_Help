To Do List / Message Center Screen Explained

Find Button

  • The Find button allows users to search for a specific message or a grouping of messages using the following criteria: To, From, Message ID#, Date, Priority Date, Priority and Status.

Find All Button

  • The Find All button accesses all current records. It does not find deleted messages.

Printer Icon Button

  • Prints all records.

  • Use the Find feature to print selected ones.

  • The print out will contain: To, Date, Priority Date, Item, Priority and Status.

  • Pages are numbered at the bottom and show the date printed.

New Message Button

  • Creates a blank, ready-to-go record.

Message Section

Item ID #

  • The record number. It can be used for searching or for identifying a particular record.

Priority Radio Buttons

  • Select the Priority you wish to give to this record. The labels cannot be edited.

Priority Date Field

  • Automatically set. Click the calendar icon to select a date other than the current one.

To Field

  • Address the message in the To field. This can be edited in order to list employee names.

From Field

  • The name of the sender.

  • Edit the list in order to list employee names.

Status Radio Buttons

  • Select the appropriate function for this record.

  • Choosing Other... triggers a dialog box to appear and request details.

  • Tip: To blank out all of the radio buttons, click on one of them and then press the Delete key twice.

Action Type Dropdown

  • The list may be edited with your own terminology.

Keywords Field

  • Group your records under Keywords (these are different than the Contacts file keywords).

Item Field

  • The Item field can be used as the To Do or Message title.

Notes Field

  • Use the Notes field for detailed instructions or explanations.

  • Paste documents from word processing applications.

Sidebar Buttons Explained

Toggle Ruler Button

  • Displays editing features at the top of the screen.

  • The Ruler will not highlight for selection until you click in a text block.
