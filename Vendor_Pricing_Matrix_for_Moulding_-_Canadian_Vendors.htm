Vendor Price Matrix for Moulding – Canadian Vendors

Another option available to Canadian framers is to utilize a vendor Pricing Matrix.

  • The Pricing Matrix specifies a retail price based on a code assigned to a moulding profile, e.g., LW4 refers to a Larson Juhl code 4 for wood moulding. The code relates to a Pricing Matrix which specifies a retail price at given UI increments.

  • Vendor-supplied matrixes are updated periodically and can be downloaded from the FrameReady website, provided that your Annual Service Subscription/Membership is active.

  • See also: Vendor Price Matrix For Moulding - Canadian Vendors

How to Enable Vendor Matrix Pricing

  1. In the Price Codes file, switch to Moulding and open the Code Pricing tab.

  2. To use Matrix Pricing for all moulding with a matrix code, click the Select All Codes button.

  3. A dialog box appears.

  4. Click the Enable button.

    FrameReady find all items, in the moulding group, which have a vendor code (e.g. LW2) and places an X in the box.

When the checkbox is marked with an X, the Code Pricing for the Code overrides all other pricing options, i.e. Formula and Set Price. Also, this pricing method cannot be combined with any other pricing options under the Frame Pricing tab.

Tip: You can preview Code Pricing data by clicking the Show Code button or use the Code Tables feature.

How to Disable Vendor Matrix Pricing

  1. To disable the Matrix pricing, follow the above steps.

  2. Select Disable from the dialog box.
