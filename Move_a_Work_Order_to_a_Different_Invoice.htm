Move a Work Order to a Different Invoice

Main Menu > Invoices

A customer's orders are spread over several Invoices and it is preferred to have all items on the same Invoice.

How to Move a Work Order to another Invoice

  1. Locate the Invoice with the Work Order you want to move to another Invoice. Take note of the Work Order number, e.g.  A0028  , we'll need it later.

  2. Click the purple Data Entry button.



    The Line Item Entry screen appears.

  3. Click the Delete (X) button (right column) of the line item.

  4. A dialog box appears: Would you like to unpost this Work Order before deleting the line from the Invoice?

  5. Click Yes.

    The Work Order status changes back to 'unposted.'

  6. If this Invoice no longer has any line items, then click Done.

  7. Next, click the Void button and enter a note in the Invoice Note field, e.g. Moved to Invoice #1234.

  8. Locate the Invoice you want to add the Work Order onto.

  9. Click the Data Entry button.



    The Line Item Entry screen appears.

  10. Do not hand-enter the Work Order into the Item Number field.

    Instead, click the Search Item magnifying glass icon. 

  11. The Search For Item dialog box appears. Enter the Work Order number, e.g.  A0028 , in the Item Number field.

  12. Click the Search button.

    The Work Order now appears on the Invoice.

  13. Repeat as needed.
