Find Duplicate Records

It is important not to have duplicate moulding, product or client numbers in your system. If you have two items with the same number, FrameReady will find and enter the first matching number and it may not be the one you are looking for.

How to Find Duplicate Records

  1. Choose Price Codes file > Find.

  2. Click in any one field where you suspect that you may have duplicate records.

  3. Type an  !  (exclamation mark).

  4. Click Perform Find.

    FrameReady searches through the database and finds all records that appear more than once. Use the Sort button to group the records together.

  5. Delete the duplicate records.

Note: Some duplicates are inevitable. Although most suppliers have an suffix to prevent duplicates, some companies do not have a suffix and a moulding sold by a distributor may legitimately have the same moulding number. For example: Both Framerica and LeWinter carried BW26966 at one time.

How to Remove Duplicate Price Code Items

Warning: Any information you have entered on the record will be permanently deleted when you delete the record, i.e. inventory, location, threshold, reorder, moulding sample, etc. Always chose to keep the record containing this information.

A) Short List of Duplicates

If you only have a few duplicate items in the list, you can click on the column heading: Item to sort the list by item number. This will place items with the same number beside each other.

  1. Make sure you are in level4 and have clicked the Unmark All button in the list view of the Price Codes file.

  2. Check the Marked box of each record to be deleted.

  3. Click the Find Marked Records button.

    The screen will change to show only the records you have Marked.

  4. Click on Records in the menu bar at the top of the screen and select Delete Found Records…

    A dialog box will appear for you to confirm the number of records to be deleted. 

  5. If the amount does not seem correct, click Cancel and perform the find again. Otherwise, click Delete All to remove the items displayed on the screen.

B) Long List of Duplicates

If you have a large number of items in your list, then you may want to delete all of them and then perform the vendor update again for each vendor on the list. The number of records in your list is shown in the top left corner, e.g. 1 of 387.

  1. Make sure you are open in level4.

  2. Click on the column heading: Supplier to sort the list by the Supplier’s name.

  3. Scroll through to list to see which suppliers will need to be updated and write down their names.

    If there are only a few duplicates for some of the suppliers, perform a search for Duplicates for that specific supplier and handle them the same as the above instructions for A) Short List of Duplicates.

  4. Click on Records in the menu bar at the top of the screen and select Delete Found Records…

    A dialog box will appear for you to confirm the number of records to be deleted. 

  5. If the amount does not seem correct, click Cancel and perform the find again. Otherwise, click Delete All to remove the items displayed on the screen.

  6. On the Main Menu, click on Update Vendor Pricing and update each supplier whose name you wrote down from the list that was deleted.
