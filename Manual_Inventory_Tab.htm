Manual Inventory Tab - All Groups

Price Codes > "Group" sidebar button > Manual Inv tab

The Manual Inventory tab identifies inventory levels and storage locations for manually entering and removing inventory.

See also: Inventory Management Overview

Important: Do not use these quantity fields when Automatic Inventory feature is active.

  • There are two slightly different implementations for Manual Inventory, one for Moulding and a second for Matboard, Fabric, and Glass.

  • Only the first entry in the Location field will appear on printed reports.

Manual Inventory tab for Moulding

Qty Column / Fields

  • The Qty fields display the available footage for this record.

  • Quantities must be updated manually.

  • Enter the length of moulding in decimal form, e.g. 8’3” = 8.25

  • Round off the partial foot measurement to a quarter of a foot

    • e.g. 3” = .25

    • 6” = .5

    • 9” = .75

    • 8’7” = 8.5

Location Column / Fields

  • Name of the place where you have the stock stored, alpha-numeric designations are acceptable.

  • Only the first entry in the Location field will appear on printed reports.

Discount Field

  • Enter a percentage value.

  • Use if your vendor gives you a % off the list price. This provides for an accurate accounting of your inventory value -- but does not affect the retail price.

Price Code discounts do not affect your retail price, only the value of your inventory. If you wish to pass this discount on to your customers, you must modify your Markup.

Total Footage Label

  • The calculated total footage.

Total Value Label

  • The calculated value of your inventory after the discount (if applicable).

Manual Inventory tab for Matboard, Fabric, and Glass

Qty Column / Fields

  • The Qty fields display the available item count for this record.

  • Quantities must be updated manually.

X and Y Column / Fields

  • The size of the matboard is expressed in two fields X and Y ; allows for the tracking of partial sizes. The actual number of any size must be entered into the quantity field.

  • X and Y are inches.

  • Set your Cost per Dimension drop-down to reflect inches (and not United Inches)

Location Column / Fields

  • Name of the place where you have the stock stored, alpha-numeric designations are acceptable.

  • Only the first entry in the Location field will appear on printed reports.

Discount Field

  • Enter a percentage value.

  • Use if your vendor gives you a % off the list price. This provides for an accurate accounting of your inventory value -- but does not affect the retail price.

Price Code discounts do not affect your retail price, only the value of your inventory. If you wish to pass this discount on to your customers, you must modify your Markup.

Total Qty Label

  • The calculated total boards.

Total Value Label

  • The calculated value of your inventory after the discount (if applicable).
