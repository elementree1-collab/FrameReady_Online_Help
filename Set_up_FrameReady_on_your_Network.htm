Set up FrameReady on Your Network

Important! FileMaker has made a change to their platform that we must comply with: "Peer-To-Peer" non server-based sharing is no longer being supported. Instead, FileMaker Inc. requires the use of FileMaker Server software to make solutions, such as FrameReady, available for use over a network.

How to set up FrameReady on your Network

  1. The default protocol for networking is TCP/IP. It is recommended that each computer be assigned a static IP address rather than using DHCP.

  2. Review these Networking Guidelines.

Caution: If you are unfamiliar with setting up a computer network, then hire a network technician to do it for you.

  1. Install FrameReady, FileMaker Server, and FileMaker Pro on your server computer.

    The Sever computer should be your fastest, most powerful computer. The information on the Server computer is shared with the other computers via the network.

    See: FileMaker Server Overview

  2. Install only FileMaker Pro on all computers on the network.

    The name of the computer is automatically entered as the User Name during the installation process.

  3. You will now need to set FrameReady to Multi User on the Server computer.

    See: Set up FrameReady for Multi-User
