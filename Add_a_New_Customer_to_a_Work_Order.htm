Add a New Customer to a Work Order

Main Menu > Work Orders

How to Add a New Customer to a Work Order 

  1. On the Work Order, click the New Customer sidebar button (top left corner).

  2. A dialog box appears: it's job is to search the Contacts file to make sure the customer has not been previously entered (this prevents duplicates).

    Enter the First and Last Name of the customer.

Tip: If you think the customer is already in the database, then enter the first few letters of their first and last name. Eg. for Susan Brown enter Su for the first name as she may have been entered as Susan, Susie or Sue. Before a new record is created, FrameReady searches for that name to help prevents duplicate records for the same customer.

  1. If the name entered is not found, then a new record for this customer is created in the Contacts file and the following screen appears.

  2. A unique ID# is automatically assigned. 

    Fill in the necessary information you want to collect from your customers.

  3. Every contact has an X marked as a default in the General checkbox under Customer Preferences. Uncheck the box if this is not a customer; for example, if it's a supplier.

  4. We recommended that you collect a phone number and/or email address to contact the customer when the order is completed.

Note: It is a good idea to be familiar with the Privacy Act in your country or state. The information you collect may be subject to these laws.

  1. Other information you may wish to fill in:

    Artists- refers to any artists they like to collect and LE numbers which they wish to reserve.

    Art Type / Notes - communication sent to the customer

    Group / Details - framing preferences, and personal information

  2. New Keywords can be added to the Customer Preferences list directly from this screen, a useful marketing tool when compiling emailing lists and tracking.

  3. Click Done and the data is entered onto the current Work Order.
