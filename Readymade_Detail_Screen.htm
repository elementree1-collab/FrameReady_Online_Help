Readymade Detail Screen

Work Orders > Framing Materials section > Readymade text button (or any clickable text in Framing Materials Section) > Readymade tab

Tip: The tabs at the top of each Work Order Detail Screen allow you to move through the Work Order in different ways.

Use this field when selling a Readymade frame which you are using in a custom order.

Readymade Detail Explained

  • Click Readymade to view more details or make up to two entries.

  • The Readymade does not appear as a separate line item on the customer’s invoice, but FrameReady updates the inventory in the Products file to reflect the sale of this Readymade frame.

Readymade Detail Screen Explained

Item Field

  • Use a barcode scanner to enter the Readymade frame or type in the item number exactly into this field.

Magnifying glass Icon

  • Use to look up any Readymade frame in your product inventory.

Blue Button

  • Use to enter items (name and retail price) not yet in your system.

Checkbox

  • Use to post the Readymade as a separate line item on an Invoice.

Description Field

  • Readymade description.

Wholesale Field

  • Cost, as stored in the Products file.

  • Not visible when logged in as level1.

Retail Field

  • Use to adjust the price. Changes here do not affect the item in the Products file.

Price Field

  • Value is pulled from the Products file.

  • Not modifiable.

Discount Field

  • Use to apply a percentage discount. Stored in decimal form, e.g. .10 = 10%

Qty on Hand Field

  • Value is pulled from the Products file.

  • Not modifiable.

Clear (X) Button

  • Use to remove the line item.

Total Field

  • The total retail price of all items, quantities, and discounts.
