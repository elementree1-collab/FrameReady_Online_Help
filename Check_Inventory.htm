Check Inventory

Main Menu > Work Orders > Entering Inventory for use with Manual Inventory

You may want to manually adjust your inventory as you work, therefore this screen allows easy access to all framing components.

How to Check your  Inventory

  • The Check Inventory button is only available for Mats, Mount Stretch, Glazing/Fabric.

  1. On a Work Order, click the underlined Mats button (or Mount Stretch, or Glazing/Fabric).

  2. Open the Inventory tab.

  3. Click the Check Inventory button.

  4. The "Check Inventory" window appears.

  5. You may enter inventory on this screen.

    Qty = amount

    X and Y = width and height

    Total = sum (not price)

    Location = shop shelf or bin #.

  6. Use the buttons to load inventory data for any Price Code item added into the field on the Work Order.

  7. Click Done to return to the Mat detail screen.
