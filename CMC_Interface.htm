CMC Interface

Main Menu > Work Orders

  1. Go to Work Order file.

  2. Fill in the appropriate information on a Work Order, entering all measurements. i.e., image size, margins, white space, and mat reveals.

  3. Enter any Extra Windows if this is a multi-opening mat.

It is always assumed that a mat includes one opening, so if your design has a total of 5 openings, then enter  4  in the Extra Windows field.

  1. When it comes to items like V-grooves and title boxes the rules differ depending on the CMC.

  2. Enter all mat numbers and any mat fillets.

Tip: make sure the size of the fillet is correct using the Modify button.

  1. If the opening is an oval or circle, then click the Oval/Circle Window checkbox.

Do not select anything from the Mat Designs menu on the Work Order screen. These will be selected from the CMC screen. If your design includes a painted mat or french panel, then select the design after you have created the CMC export file.
