Add Moulding to a Work Order

Main Menu > Work Orders

The frame moulding number you wish to enter can be typed or scanned directly into the Moulding field, the yellow field to the right of Frame1 on the work order screen.

How to enter Moulding to a Work Order

  1. Use the magnifying glass button, to the right of that field.

  2. The "Search for Moulding Number" dialog box appears.

  3. Locate a moulding by entering the first 3 to 4 digits in the Item field or a Description, e.g. matte black, or the Group to which it belongs, e.g. wood.

    The more criteria entered into the search, the narrower the search will be, e.g. Item: 11, Group: Metal. 

  4. Click the Search button.

    If only one moulding is found, then it is entered automatically on the Work Order. If more than one moulding meets the criteria, then a list appears displaying them all.



    Simply click on the moulding you wish to use. You may need to scroll down to see them all. The Description field will display any text provided by the supplier. This is a good way to verify that the correct moulding has been entered. If no description has been provided by the supplier, the field will remain blank. You can enter your own description or modify the one provided in the Price Codes file. This information will appear on the printed Work Order.

  5. Or... When the corner sample has not yet been entered into the Price Codes file, click the blue button (at the end of the Frame1 row) to access a screen where you can enter a Moulding Number and Retail Price for the entire frame.



    In the case of a stacked/layered frame job, the frame closest to the image will be displayed on the main Work Order screen; however, the price on the screen will reflect the total of all frames in the layered frames button.
