How to edit a Work Order when the Auto Update of materials inventory feature is active.

How to Edit a Work Order (for use with Auto-Inventory)

  1. In order to change, edit, or modify a Work Order you must click the purple Modify Work Order button. This is because the fields are locked.



    The Work Order data entry screen appears.

  2. Behind the scenes, the materials on the Work Order are temporarily returned to inventory when you click the Modify Work Order button and only returned when you click the Work Order Done button.

  3. To exit, click either the WORK ORDER DONE or KEEP AS ESTIMATE button.

Important: To exit the Work Order, you must click one or the other. There is no other way to exit the Work Order!

  1. If you click the WORK ORDER DONE button, then the inventory automatically updates.

  2. If you click the KEEP AS ESTIMATE button, then the inventory will not be affected.
