Pricing Options and Defaults for Fabric

Price Codes > Fabric Group sidebar button > Fabric Pricing tab > Pricing Options and Defaults button

The Pricing Options and Defaults screen is a separate file used as a reference for vendor price updates and for storing your own unique formulas.

What is a Default Record?

  • When FrameReady imports a new vendor record, such as a new fabric, it needs to know what pricing formula to apply to that particular record.

  • FrameReady searches the Pricing Options and Defaults file for a Default Record which describes and instructs FrameReady on how to price the item.

It is important to understand and properly set up the Default Records.

Fabric Pricing Options and Defaults

  1. Open the Price Codes file, switch to Matboard (form view) and open the Fabric Pricing tab.

  2. Click the Pricing Options and Defaults button.



    The Pricing Options and Defaults window appears.

  3. In this screen you will see numerous Pricing Records, on alternating colored blocks, going down the screen.

    Each record consists of the Markup, Set Price, Minimum Price, Code, Area unit, Combination box and Default selection box. Records can be divided into three parts:

    • The part which determines the price to be calculated: Markup, Set Price and/or Code.

    • The part that governs how the area will be priced: UI Area, Square Inch, etc.

    • The part which governs when and if it will be applied: Default.

Explanation of the Pricing Options and Defaults for Fabric Screen

New Record Button

  • Creates a blank new record at the bottom of the screen for you to fill in. If this was created in error, use the Delete button to remove it.

Find Button

  • Opens Enter Search Criteria screen to find one or more pricing records by whatever criteria you enter. Click the Find button on the left side of the screen or press the Enter on your keyboard to perform your find.

Show All Button

  • Displays all records in a list view.

Done Button

  • Returns you to the Price Codes file and the moulding record you were previously viewing.

Default Use Only

  • Both a heading and a button (that’s why it is underlined). When clicked it finds all records selected as Default.

Buttons and Controls

Markup Field

  • The Markup field can have a formula entered into it or simply the markup to be used for this pricing option. If you are entering just the markup, be sure to enter the markup in a number not a decimal, e.g. 3 or 3.0

    If you are entering a formula, you must identify the cost field as “Cost”. Your formula can also differentiate between matboard sizes by using the word “Dimensions”.

Set Price Field

  • A fixed dollar amount added to the calculated price of a matboard or other item.

  • Can be entered as a number or a formula.

  • The Set Price is consistent regardless of the size.

Minimum Price Field

  • The Minimum Price 

Code Field

  • The Code field allows you to specify a code table or a series of code tables based on a series of cost increments.

Combine Formula and Code Pricing Checkbox

  • Used in special circumstances where neither a formula nor a code table will work but a combination of the two will. An example of this is a fabric wrapped mat where the fabric is priced by the linear yard and the substrate on which it is wrapped on is priced by a code table.

Area Unit Field

  • How the pricing formula is applied to the item. For example, if you want to price your fabric by the square foot as opposed to the square inch, then you can specify that here.

Enlarge Button

  • Opens a screen where the Formula and Set Price are the only items on the screen. This provides you with more room to view longer formulas.

    Also contains a button to email your formula to the FrameReady Team for tech support.

Select Button

  • Applies the formula to the record that you were previously viewing in the Price Codes file.

Apply to Group Button

  • Opens a dialog box where you can apply the formula to a select group of records.

Duplicate Button

  • Clones or duplicate the current record; you can then modify for a different group, size, or supplier.

Delete Button

  • Use to remove any unwanted Pricing Formula records.

Default Checkbox

  • Appears on all records but is only applied or active if an X appears in the box. Otherwise the record and the rules it contains are ignored and not applied.

    • When the Default check box is selected, a Group list, Dimensions field, and Supplier field appear below it.

    • The group governs which records will have the Pricing Formula applied it.

    • The Dimensions and Supplier fields allow you make a Pricing Formula size and vendor specific.

      E.g. when a vendor pricing update is performed and new records are imported to the Price Codes file, the program will search for a vendor specific default record before applying a generic record.

    • If the dimensions and supplier fields are left blank, then the pricing default is applied to all sizes and all suppliers with items belonging to the selected group(s).

Important: For any given Group (Metal, Wood etc.) there must always be at least one default generic record, i.e., the Supplier field is left blank.

When is a Default Generic Record Used?

  • When you click on Lookup My Default button (located on the Frabric Pricing tab), it will paste the appropriate pricing default into the Formula and Set Price fields for the item you are currently viewing.

  • When you download your Vendor Pricing Updates, your default selection is applied to all new moulding records for that vendor.

  • If the Default checkbox is not selected, then the formula are not be applied to any records. It is simply a pricing option that you may chose to use at a later date.
