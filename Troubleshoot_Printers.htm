Troubleshoot Printers

If FrameReady is not printing to the correct printer, or not printing at all, check that the printer is installed correctly and is set as the default printer.

See also: Set up Receipt Printer

Basic Printer Troubleshooting Checklist

  • Was anything changed on your computer recently? For example, security software, antivirus software, firewall changes, new or updated routers, operating system updates. It is known that such changes can affect peripherals such as printers.

  • Turn off the printer, unplug - replug the power cord and turn the printer back on.

  • Save your work and restart the computer.

  • Check the cable connections and make sure all printer cables are connected securely. For wireless printers, try plugging them in using USB instead.

  • Check the printer's status for any error codes and then search online for information.

  • Check your printer instructions on how to print a self-test page.

  • If FrameReady refuses to print, try printing from another software program on the same computer.

  • Try printing from another computer.

  • Check the print queue and clear out any documents that have not printed.

  • Check to see if any software or print driver updates are needed.

  • If all else fails, then your printer might be at the end of its service life. Consider investing in a new printer and properly recycling the old printer.

Before You Begin Troubleshooting

  1. Print a test page from another program.

  2. Make sure all printer cables are connected securely.

  3. Refer to any documentation from your printer manufacturer.

  4. Check Main Menu > Work Order > Options section > More Options... button > Print Options tab > Print Setup... button

    A print set-up dialog box appears. If you have more than one printer and FileMaker Pro is unable to find which printer you wish to use or you wish to change default printers.

If you are only having printing problems with FrameReady, then use the following steps.

Windows

Set Default Printer In Windows

  1. Go to the Start Menu and select Printers and Faxes.

    You may need to go to Control Panel > Printers and Faxes or Control Panel > Devices and Printers. d

  2. Make sure the desired printer has a black or green default check.

  3. If not, right-click the desired default printer and select Set as Default.

  4. Right-click and Delete any printers listed that you no longer use.

Set Default Printer In FrameReady

  1. Login under the level4 account and password.

  2. On the Main Menu, in the file menubar, click Perform and choose Restore Full Menus.

  3. Click File > Print Setup.

  4. Select the desired default printer from the dropdown list and click OK.

Turn on Show Print Dialog

  1. From the Main Menu > Work Orders section > Options tab.

  2. Change Show print dialog box before printing to Yes.

  3. Navigate to the Work Order and click the Printer icon.

  4. Confirm that the correct printer is selected in the print dialog box.

Macintosh

  • See also: HP Printers on Mac

Set Default Printer In OS X

  1. Go to the Apple Menu and select System Preferences.

  2. Select Printers & Scanners.

  3. Make sure the desired printer is labeled as Default.

  4. If not, hold down the Control key on your keyboard and single-click the desired printer and select Set default printer.

  5. Single-click any printers listed that you no longer use and click the – button to delete them.

Turn on Show Print Dialog

  1. From the Main Menu > Work Orders section > Options tab.

  2. Change Show print dialog box before printing to Yes.

  3. Navigate to the Work Order and click the Printer icon.

  4. Confirm that the correct printer is selected in the print dialog box.

Print options for Work Orders or Invoices only print 1 copy when set to print more

The Problem

  • You have set the print options for Work Orders or Invoices to print more than one copy; however only one copy is printed.

The Solution

  • As with previous versions of FrameReady, you must turn off the “Show Print Dialog Box Before Printing” option when you choose to print more than one copy. Otherwise, your system’s printer defaults are used and will reset the quantity to one (1).

Printed Proposal is Missing Data

The Problem

  • The print preview and/or the printed Proposal document is missing data, e.g. no customer information. Or you receive the message “20.pdf could not be created on this disk.”

The Solution

  • There must be a retail price for the Work Order, otherwise FrameReady fails to properly create the document.

  • Things to check:

  1. Do not use FileMaker operators in the Job # field. See: Formula Operators

  2. Enter zero (0) in the Other field. When you exit the field, the zero disappears but the missing information appears on the Proposal document.

Documents are printing in French/Spanish

The Problem

  • Instead of the printing in the default language, a document prints in French or Spanish.

The Reason

  • The print language for that contact has been changed.

How to Change Language for Printed Documents

  1. Perform a find for the Contact in your Contact file.

  2. Locate and uncheck the French or Spanish checkbox.

    All documents printed for this customer will revert to the default language.

Documents available in French/Spanish

  • Work Order: General Summary, Proposal, Estimate, and Scenarios

  • Invoices

  • Gift Certificates
