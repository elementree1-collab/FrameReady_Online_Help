Installing FrameReady on Windows

These instructions are for Single User installations only.

  • To use FrameReady with more than one computer with FrameReady requires the installation and use of FileMaker Server software on a compatible computer system.

  • See: FileMaker Server Overview

To Uninstall FrameReady Trial Version

  1. Do not uninstall your FrameReady Trial.

  2. It can be activated to the full Standard or Lite version; doing so will keep your records intact. During activation, you can ask that we help clear out any test records.

To Install FrameReady

  1. In the email you received, follow the link to the web page to download the FrameReady and FileMaker Pro files.

  2. Open the Downloads folder and double click the FrameReady and FileMaker Pro files.

  3. Follow the instructions on the web page.

How to Add a FrameReady Icon to the Windows Desktop

For Single User/Single Installations Only

New in FrameReady 11

Default location of FrameReady 11, 12

Windows: C:\Users\[Account name]\FrameReady 11 [or 12]

mac OS: Macintosh HD\Users\[Account name]\FrameReady 11 [or 12]

  1. Press Windows + E to open File Explorer.

  2. In the left panel, look under This PC and single-click Local Disk (C):

  3. In the left panel, double-click the Users folder. Identify your account folder and then double-click to enter it.

  4. Locate and then double-click the FrameReady 12 folder to enter it.

  5. Right-click the file named FrameReady.fmp12 and choose Create shortcut.

    A shortcut named     FrameReady.fmp12 - Shortcut appears.

  6. Drag the shortcut to your Desktop or to the Taskbar, whichever you prefer.

  7. If you wish to rename the shortcut, press F2 on your keyboard. Press Enter to finalize your changes.
