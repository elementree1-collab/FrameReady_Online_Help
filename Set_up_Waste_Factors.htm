Set up Framing Waste Factors

There are several areas in FrameReady where you can increase the amount of moulding ordered.

About the Width Multiplier

The moulding width multiplier compensates for footage lost when cutting a frame on certain chop saws.

  • The Width Multiplier value is multiplied against moulding width. For example, a 2" moulding width a 1.25 multiplier increases the moulding width to 2 1/2” and the required footage is increased accordingly.

  • The Width Multiplier field must always have a value of at least 1 and should not exceed 2.

  • Some shops have a double-mitre chop saw that has extra waste, so they enter the moulding width multiplier at 1.1 or 1.25. Many set Larson Juhl at 1.25 because they have a higher waste chart than other companies.  

  • The multiplier may be set for each individual moulding or may be set across the board.
    See: Set up Work Order General Options

  • If you have set the width multiplier from the Main Menu, then you can override it for individual mouldings.
    See: Frame Detail Screen

Waste Factor when Calculating Cost

Main Menu > Work Order > Options tab > More Options… > General tab

  • For shop use only, a waste factor can be added to all Work Orders.

  • Enter the percentage in decimal form, for example  5  .

  • When you create a Cost Report For Found Set, then this value is used to add a waste cost to the moulding footage.
    See: Work Order Cost Report

Accounting for Waste on a Purchase Order

  • The Purchase Order shows you the width and height of the frame (along with the footage) so that if the frame is 48" x 20”, then you can increase the amount in the footage field to 20 feet. Doing so requires the framer to know where the cuts will fall on a length of moulding. And, if there is a flaw in the stick, it may not help. 

  • The data for stick length is different for each moulding company and is not provided to us. Even if it was, there is no where in FrameReady to enter it. Perhaps we will see this information available in the future.
