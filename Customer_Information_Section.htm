Customer Information Section Explained


The view after clicking "New Work Order"


The view after assigning the Work Order to a Contact.

Name Button

  • Use to search for all or part of the customer’s name. If a record is found, then the customer is inserted. If more than one record is found, then a list is displayed for you to choose the correct customer. If no records are found, then you are given a new customer record to fill in.

Company Button

  • Functions the same as the Find by Name except that it searches the Company field in the Contacts file.

Phone Button

  • Displays a search dialog box where you can search any customer’s phone number with either 7 or 10 digits. It is not necessary to add dashes or brackets.

(Contact) ID#

  • If you know a customer’s ID #, you can type the number in and click the Enter key (located on the number pad.) You cannot type into the phone number fields to edit until an ID# is present.

  • Assigned automatically when entering new customers.

  • To remove a customer from a Work Order, simply click the X to the right of the customer ID#.

X Button

  • Removes the customer from the current Work Order but does not delete them from your database.

Phone Number Fields

  • Only three phone numbers and their location are displayed on this screen. More numbers can be listed in the customer’s record in the Contacts file.

Email Address Field

  • If there is an email address present, clicking this button presents a pick-up notification scripted email.

  • Entering or editing an email address in this field modifies the customer record in the Contacts file.

  • See also: Sending a Completion Email from a Work Order

Customer Name and Address Field

  • The large square displays the customer’s name and address.

  • If the information needs to be edited, simply click on the Contacts button, make the corrections, and then click back to the Work Order.

Customer Notes Field

  • Customer Notes entered in this section appear on all screens with this customer’s information.

  • However, these notes will not print onto any documents. Use for discreet information, e.g. previous cheque bounced, so long as the customer cannot see the screen.
