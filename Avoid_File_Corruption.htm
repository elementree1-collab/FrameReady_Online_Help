Avoid File Corruption

Disable Hibernation/Sleep Mode

  • FileMaker can struggle to wake up if the computer has entered hibernation or sleep mode. It is recommended that you disable all sleep functions (although you can still have the display go to sleep if necessary).

Plug Your Computer into an Uninterruptible Power Supply

  • If FrameReady is open when your computer experiences a power failure or brown-out, then there is a high probability that some FrameReady files were damaged.

  • Plugging your FrameReady computer into a battery-equipped UPS can help eliminate some of those instances.

Adjust Your Antivirus Software Settings

  • Please set the antivirus software so that it does NOT scan the Databases folder and subfolders, or any location FileMaker Server or FileMaker Pro is opening the databases from.

  • If scanning of the files is necessary, then the antivirus software should instead scan the backup destination folder.

  • Please schedule the antivirus software so that it does NOT scan during the time FileMaker Server is backing up the database files. It is preferable to scan the FrameReady database files after the files have been backed up completely.

How Antivirus Software May Cause FrameReady File Corruption

  • An antivirus program could lock bytes within a file while it is scanning the file for viruses. Such a lock could cause the operating system to return an error when FileMaker Server tries to write data to the file, resulting in the file being closed as damaged.

  • Note that this also applies to files that FileMaker Server is performing a backup to. If the antivirus software is scanning a backup file when the backup schedule occurs, the open database may not be backed up because the destination file is locked which may result in the loss of data.

  • The same issue applies if FileMaker Pro has the database open and it is not shared and the antivirus software tries to scan the file.

Review Your Automated Backup Settings

  • The cloud-syncing features of Dropbox, Google Drive, OneDrive, and others are dangerous to the FrameReady files. When you are using FrameReady, those files are open, are subject to many changes as you use the program, and cannot be backed up while open.

  • Do not move the FrameReady folder into your Dropbox, OneDrive, or other cloud-syncing folder.

  • Exit completely out of FrameReady before making a manual backup.
