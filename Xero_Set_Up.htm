Xero Set Up

Setup Data  > Fiscal tab > Xero Integration Settings button

Use these steps to set up your Xero Integration in FrameReady.

How to Set up Xero Integration

  1. Go to this web address:

    https://developer.xero.com/myapps

  2. Log in using your email address and Xero password.

    If asked to set up multi-factor authentication, you can do this later.

  3. Click the blue New app button (top right).

  4. In the App name field, give this "app" a clear name, e.g. FrameReady Link

  5. For the Integration type, select "Web app"

  6. In the Company or application URL field, enter https://frameready.com

  7. In the Redirect URL field, enter: https://frameready.com/xero

  8. Check the box I have read and agree to the Xero Developer Platform Terms & Conditions.

  9. Click the blue Create app button.

  10. On the web page that appears, click Configuration (lefthand side navbar).

  11. On the Configuration web page, copy the Client id field that was created for you.

  12. Go back to FrameReady.

    On the Main Menu, click the Setup Data icon (upper right).

  13. Open the Fiscal tab, and click the Xero Integrations Settings button.

  14. The Xero Integration in FrameReady; click the mouse into the Client ID field (marked in red) and paste the Client id from Xero.

  15. Go back to the Xero web page; click the Generate a Secret button.

  16. A new field appears; click Copy.

  17. Go back to the Xero Integration in FrameReady.

  18. Click the mouse into the Client Secret field (marked in red) and paste the Client secret from Xero.

  19. Click the mouse into the Redirect URL field (marked in red) and enter:  https://frameready.com/xero

  20. Click the Authenticate button (top right).

  21. When the Xero login screen appears, log in to your Xero account.

  22. If asked to set up multi-factor authentication, you can do this later; click Not now.

  23. Xero wants to confirm givng access to the "new app" you created. Scroll down and click Allow Access.

  24. If you entered https://www.frameready.com in the Redirect URL field, then the FrameReady homepage appears. 

    Click the Continue button (lower right).

  25. The Xero Integration returns to the Settings layout; an alert appears.



    Also, the Xero Integration switches from "off" to "on" (lower left).

  26. In the Xero Integration in FrameReady, click the Update Organization from Xero button.

  27. When completed, an alert appears. Click OK to dismiss it.

  28. You should see your Xero Organization Name appear.

    To add a second organization (for FrameReady Multi Site), use the plus icon (top right).



    If your store has multiple sites and each site is a separate organization in Xero, then add the new organizations and turn Multisite On if you would like to link each individual site to the respective organization.
