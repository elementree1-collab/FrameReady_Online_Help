Overview of Files in FrameReady

Main Menu

The Filing Cabinet Concept

  • To understand how FrameReady works, imagine a work order sheet, a list of price charts, an invoice form (or cash register), and an address book of customers. These are the basic components of FrameReady.

  • But instead of having these items scattered over a counter top or in filing cabinets, they are stored in the computer.

Overview of the FrameReady Filing System

The Main Menu

Tip: FrameReady always starts at the Main Menu.

  • The Main Menu is a specialized dashboard: it has shortcuts to help you move quickly to other areas of the program, to find documents, set up the basic business information and set default options for Work Orders and Invoices.

The FrameReady Files

FrameReady includes these special files (or filing cabinets):

  • Message Center

  • Price Codes

  • Work Orders

  • Contacts

  • Product Labels

  • Gift Certificates

  • Purchase Orders

  • Invoices

  • Products

  • Outbound Consignments

  • Time Cards

  • Art Resource

A Closer Look at the FrameReady Files

FrameReady uses color-coding for the various areas of the program. We have color-coded the FrameReady screens so you can quickly know that "you are in the right place."

 

Message Center

  • Leave notes for others and monitor tasks for employees.

  • Store store policies for quick reference.

See Message Center

 

Price Codes

  • Store pricing information for all materials used in the process of building a frame.

  • Used to calculate the retail price in the Work Order.

  • Group materials for easy, one-click access. View, edit or print pricing formulas and code tables.

See Price Codes File

 

Products

  • Track sales and inventory of any item that does not require assembly.

  • The Products file can automatically update inventory, transfer data to Work Orders and Invoices, track sales dates, and turnaround time.

  • Track items consigned to your shop. Import, view and email retail items images. Print text or image directories of art.

  • FrameReady Multi Site: track inventory for up to four stores. Move inventory from one location to another.

See Products File

 

Product Labels

  • Generate a variety of different size labels for retail items. Add barcodes to the design.

  • Print labels in multiple, starting at any location on a sheet. Create designer layouts.

See Product Labels File

 

Contacts

  • Store information about anyone you contact, i.e., Customers, Suppliers, Artists, Companies, etc.

  • Contains a word processing function for letters, address labels, envelopes, etc.

  • Generate Mailing lists for specific target markets based on custom Keywords or the Artists listed in the customer’s record.

  • Send messages to individual customer or a found set of customers.

  • The Contacts file also provides an overview of your customer’s purchases by showing a listing of Invoices and Work Orders with subtotals. Discounts notated here are automatically applied to all Work Orders generated for the customer. Store and automatically apply (to Work Orders and Invoices) tax exemption number(s) and expiry dates. Track birthdates and referrals.

  • FrameReady Multi Site: keep all contacts in one central database but permits searches and reports based on individual locations.

See Contacts File

 

Gift Certificates

  • Print your own in three different styles in three languages. Track gift certificates and store credits.

  • Issue and redeem professionally-designed Gift Cards using a barcode.

  • Track store credits from customers who may have returned an item and a credit was given in lieu of a refund.

See Gift Certificates / Store Credits

 

Purchase Orders

  • Identify items ordered from a specific supplier.

  • Automatically transfer into inventory when received. Manually or automatically create Purchase Orders.

See Purchase Orders File

 

Invoices

  • Track all sales and payment transactions.

  • Generate accounts receivable, statements, sales performance, and deposit information.

  • FrameReady Multi Site: stores all Invoices in one central database and can generate individual reports for up to four stores.

See Invoices File

 

Work Orders

  • Create, price and track all custom frame Work Orders.

  • Print Estimates and Proposals. Monitor production flow.

  • Convert framed artwork for gallery display into retail products.

See Work Orders File

 

Chop Order*

Available only in FrameReady Wholesale, Chop  Order is an order taking system for businesses offering a chop service for moulding, glass, etc. Formerly called ChopReady and sold as a separate product, now discontinued and integrated into FrameReady Wholesale. Designed for the use by distributors of wholesale framing materials.

 

Outbound Consignments

Track retail products, such as prints, art, framed prints, sculpture, etc., that you have consigned to interior designers, other retail outlets and auctions. Post sold or returned items to an invoice or set as returned to inventory.

See Outbound Consignments File

 

Time Cards

Use as an employee time clock to track hours for payroll.

See Time Cards File

 

Art Resource

Compile a listing of art available from other sources. Group by Artist or Subject with digital images, web listings, contact info. Great for documenting art which is difficult to locate.

See Art Resource

 

Set Up Data

From the Main Menu, set up your basic business information, address, import a logo, edit footnote disclaimers, set up networking and security.

See Setting Up Basics

*Available only in FrameReady Wholesale

FrameReady Wholesale includes the above files as well as Chop Order (for receiving orders)

Note: FrameReady Lite includes the first four files listed.
