Edit Hourly Wages

Main Menu > Time Cards > Admin Login

How to Edit an Hourly Wage

  1. On the Main Menu, click the Time Cards icon.

  2. Login to the Administrator account.

  3. Find the Time Card you wish to edit or click the List View button and click the appropriate Emp ID button.

    The employee's time card appears.

  4. Open the Info tab.

  5. Click the Edit button next to the Regular Pay, Overtime Pay or Vacation Pay fields.

  6. A dialog box appears.

  7. Choose whether you are changing the wage for This Card or changing the Default wage.

  8. An edit dialog box appears.

  9. Enter a new hourly wage or vacation pay percentage for that employee.

  10. Click OK.

Note: all new Time Cards created for that employee will use the new value you entered; old Time Cards will remain as they are.

  1. Click Logout when you are finished.
