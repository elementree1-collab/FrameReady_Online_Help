Trouble Logging In

The Problem

  • Instead of logging into FrameReady, the expected Account Name and Password are not accepted.

  • If you are having difficulty logging in try these things first.

The Reasons

Things to Check

  • Account Name - this is where you enter  level1  or  level2  etc. If, instead, you see your name or your computer's name, backspace it out.

  • Make sure there are no spaces -- especially before or after the account number; and no space between level and the numeral.

  • Make sure you are using all lowercase for both account name and password

  • Password - double-check that  Caps Lock  has not been accidently turned on. Also confirm the password is appropriate for your version of FrameReady.

  • If you are using FrameReady Multi Site, then your login account name should be in the format  1-level2  or  3-level1 . The prefix indicates the multi site location.
