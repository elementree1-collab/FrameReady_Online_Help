Price Sampler Overview

Price Codes > Any Group (except Fitting, Multi-Angle and Supplies) > Pricing

In the form view of each Group’s Pricing tab, to the right, you will find four columns of numbers (Dimensions, United Inches, Footage, Price). This the Price Sampler ; it's job is to calculate and display what your  retail price looks like using the current values from Formula and/or Set Price tabs.

  • A great way to quickly look up a retail price for various  moulding sizes without creating a Work Order.

  • Changing the values in your Formula and/or Set Price results in a change in the sampler's data.

  • When setting your prices, use the Price Sampler data to gauge how your pricing works with different entries or combinations.

  The HxW column displays the size. The UI column displays a number of united inch values (which may be modified for this record). The Footage column displays the calculated footage based on the UI and the width of the moulding. The Price column displays the frame price based on the footage, the price per foot and the added Set Price.

Reset the Price Sampler

  • Use the Reset button to update the data displayed in the Price Sampler.

  • Use the Printer icon to print a price chart sheet for this.

Price Sampler Error

  • If a question mark appears in the Price Sampler, then there is an error in either the Set Price field or the Formula field (which calculates the markup).

  • Check both the Formula, to see if a  ?  also appears in the Markup field, and the Set Price, to see if a  ?  appears in tan field (not the off-white box where the equation is entered).

  • Once you know which field is causing the error, you can then correct it.

Tip: If you have difficulty locating the error, then contact the FrameReady Team for assistance at 1-888-281-3303 ET.
