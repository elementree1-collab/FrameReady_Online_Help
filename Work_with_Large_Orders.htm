Working with Large Orders

Main Menu > Work Orders

This is an overview of entering multiple Work Orders for large volume orders.

Entering Large Volume Orders in FrameReady

  1. Create the first Work Order as usual.

  2. In the Order tab, the Job # field and the Qty button should be blank.

  3. Click the Job # button to view existing job numbers; do not use an existing Job Number for new jobs/projects.

  4. In the Job Number field (below the Job # button), enter a unique Job Number.

  5. Finish entering your data into the Work Order.

  6. If you need to track Sidemark, Plan, and Room, then open the Notes tab.

  7. On the left-hand sidebar, click the Duplicate Work Order button.

  8. A dialog box appears.

  9. Click Yes to include customer information in the duplicate Work Order.

  10. Another dialog box appears.

  11. Click Keep so that the duplicated Work Order continues to use the Job Number you assigned (in Step 4 above).

  12. If a Note was added, then you are asked if you wish to also duplicate the note.

  13. The duplicated Work Order appears. The Qty button (in the Order tab) now reads "2".

  14. Adjust this new Work Order as necessary.

    When you are ready to create another Work Order for this job, click the Duplicate Work Order button and repeat Steps 7 - 10.

Printing Work Orders for Large Volume Orders

  1. From a Work Order belonging to the job, click the Print Documents button.

  2. In the Print For Shop section, click the All [Customer name]'s Orders button.

  3. To quickly view a list of all Work Orders in the job, click the Qty button in the Order tab.
