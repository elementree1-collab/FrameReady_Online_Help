Set up your Logo

Main Menu > Setup Data > Logo tab

Use this section to add your company logo to FrameReady.

  • See also: Print with Pre-printed Letterhead

Setup Data -Logo tab Explained

When added, your logo appears on:

  • Invoices

  • Letters

  • Envelopes

  • Statements

  • Work Order Summaries

  •  Gift Certificates

  • (any document handed to a customer)

The logo is re-sized automatically to fit all documents.

How to Prepare a Logo

  1. Your address and phone numbers should be included in the image.

  2. Crop out any white space around the image as this will affect the size of the logo on printed documents.

  3. Save your logo in PNG or JPEG format.

Note: The logo does not appear on "in house" documents, i.e. those which contain information not intended for customers (Sales Reports, Work Orders, Incomplete Lists, Accounts Receivables, etc.)

Adding Your Logo File

  1. Click the Insert Picture button.

    A dialog box appears.

  2. Select your file and make sure there is no X in the Store only a reference to the file checkbox.

  3. If your logo art contains your address and phone number then uncheck the Logo art does not include address or phone field.

  4. Click Done, when finished, to return to the Main Menu.
