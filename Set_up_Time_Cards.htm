Set up Time Cards

Main Menu > Time Cards

Before you begin, log into FrameReady as level3 or higher.

Important: Retrieval of lost or forgotten passwords by Adatasol Inc. is not covered under the annual tech support contract.

Initial Setup for your Time Cards

  1. On the Main Menu, click the Time Card icon.

  2. You are prompted to create an Administrator account.

  3. Click OK.

  4. The Enter a Password dialog appears.

  5. Enter a password, confirm the password and a password hint, and click OK.

  6. Click the Administrator's Employee ID button.


  7. The password dialog box appears.

  8. Enter your newly minted password and click OK.

  9. You will be prompted to create a new user, click YES.

  10. Enter and confirm a password and a password hint for the new user account (we'll add the new user's name in a moment).

  11. Click OK.

  12. A new account is created with a unique Employee ID.

  13. Enter the employee's First Name and Last Name into the appropriate fields.

    The full name will appear on the login screen and make it easier for the employee to locate their account in the list.

  14. To create more accounts, click the New User sidebar button.

    When complete, click the red Logout button (top right).
