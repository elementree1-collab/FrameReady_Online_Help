How to set up Matboard Pricing

  1. Go to Price Codes file and click the Matboard sidebar button.

  2. Find a sample matboard record with which to experiment. Use the Find button to find a number with which you are familiar.

  3. Open the blue Matboard Pricing tab.

    You will see a set of grey tabs: Markup, Set Price, Min Price, and Code.

  4. Open the Markup tab, and modify or enter your new formula.

  5. Open the Set Price tab and modify or enter your new set price.

  6. Choose the radio button for your desired pricing structure, e.g. United Inch Area, Square Inch…

  7. If necessary, click Reset button to update the Price Sampler.
