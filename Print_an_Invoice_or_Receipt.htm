Print an Invoice or Receipt

Main Menu > Invoices

How to Print an Invoice to a Standard Printer

  1. Locate the invoice in question.

  2. Click the Print Invoice icon.

  3. A print preview of the document appears.

  4. Click Continue to print or cancel.

When printed, Australian invoices use the heading "Tax Invoice"

See also: Set up Invoice Print Styles, How to Print a Blank Invoice

How to Print Multiple Invoices

  1. Perform a Find for the multiple Invoices you wish to print.

    Make sure you are in List View.

  2. Click the Print Invoice button.

  3. A dialog box appears.

  4. Click Current to print a single Invoice of the currently selected Invoice.

  5. Click Found Set to print a copy of each of the Invoices that you found.

How to Print a Receipt to a Receipt Printer

Important: The Print Receipt feature is designed to only print to receipt printers.

  1. Locate the invoice in question.

  2. Click the Print Receipt icon.

  3. A print preview of the document appears; formatted for a receipt printer.

  4. Click Continue to print or cancel.

See also: Set up Receipt Printer for Multi User
