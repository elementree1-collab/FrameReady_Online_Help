Accounts and Passwords Overview

Looking for Passwords for FrameReady Multi Site? See: Accounts for FrameReady Multi Site

  • All of the FrameReady files are password protected.

  • Additionally, there are four levels of access or accounts.

  • Account names and passwords are case-sensitive.

  • Each computer on a network can be opened with a different level password.

Be advised: If you call the FrameReady Team for password information, we can only reveal the account passwords to the individual listed in our records.

Accounts

FrameReady has four built-in accounts:

  1. Level One - new staff, entry level, part time employees

  2. Level Two - regular and senior staff, full time employees

  3. Level Three - shop owner, manager

  4. Level Four - technical support, power user

Passwords for Access FrameReady

  • With each account, there is an assigned password. You can find these four passwords accompanying your FrameReady program at the time of purchase.

  • Passwords can only be changed (logged in as level4) on the Main Menu, under File > Accounts > Change Password.

Note: Accounts and passwords are case sensitive and can only be changed while logged in as level4.

Level One Account

Best for new staff, entry level, part time employees

  • Account name: level1

  • Logging in with the level1 account gives access only to the following:

    • Work Orders

    • Contacts

    • Gift Certificates

    • Invoices

  • In level1, the following rules are active:

    • May look up Products but cannot makes changes

    • All costs and markups on the Work Order are hidden from view

    • Sales and Inventory Reports cannot be accessed

  • Password: can be located on a separate piece of paper accompanying your FrameReady program

Tip: The level1 account should be used in situations when customers can view screens containing sensitive data.

Level Two Account

Best for regular and senior staff, full time employees, this account gives access to all of the files, however the following rules are active:

  • Account name: level2

  • Level2 cannot use some functions, e.g. the Replace command

  • Reports cannot be accessed

  • Inventory cannot be accessed

  • Setup Data cannot be accessed

  • Password: located in a separate document accompanying your FrameReady program

Level Three Account

Best for shop owner, manager.

  • Account name: level3

  • Level3 allows for importing/exporting data, provides access to the Replace command, as well as other advanced features. You need to exercise caution when using some of these commands. If you are unsure of how to use these commands, then call technical support at 888-281-3303.

  • When FrameReady files are opened with FileMaker Pro, the layout mode can be accessed - this means new labels can be designed and added to your list.

  • Password: located in a separate document accompanying your FrameReady program

Level Four Account

Best for technical support, power users.

  • Account name: level4

  • This account allows the owner/manager to access the import/export, Replace Command, and other advanced FileMaker features. You need to exercise caution when using some of these commands.

It is strongly suggested that you do not use this level account unless you are familiar with programming in FileMaker Pro or you are being guided through this section by a FrameReady Team technician. You need to exercise caution when using some of these commands. (If you are unsure, call technical support at 1-888-281-3303)

  • Password: located in a separate document accompanying your FrameReady program
