Extra Detail Screen

Work Orders (form view) > Framing Materials section > Extra tab

Tip: The tabs at the top of each Work Order Detail Screen allows you to move through the Work Order with ease.

Extra Detail Tab Explained

  • The Extra Detail Screen is available when you require several different design elements.

  • When pricing and production will change based on the number of elements used, this screen allows you to provide all of the details for the order.

  • Enter up to four mounting or stretching options, check on inventory, and add individual discounts.

 

Extra Tab Explained

1) Item Field

  • Click in the empty field to reveal the list of possible component options pulled from the Price Code file.

2) Thickness Field

  • Fills in this value based on the information in the Price Codes file.

  • Affects the total depth required for framing components shown on the main Work Order screen.

3) Price Field

  • The individual unit price.

4) Qty Field

  • Allows you to apply the fees for components in the case where you need to mount or stretch multiple pieces for one frame.

5) Extended Price Field

  • The total price for the component, based on the quantity entered.

6) Discount Field

  • Used to apply a percentage discount to the individual component.

  • Must be notated on every component it should be applied to.

7) Total Price for the Extra Field

  • A non-modifiable field listing the total price for the components selected for the order.

 

Extra Detail Tabs

Unit of Measure Tab

  • Lists only the current measurements for the Work Order in United Inch and Square Inch.

Code Price Tab

  • The details for each value will populate from the Price Codes file.

  • Using the Code pricing will override any Formula pricing.

  • Changes made here will only effect the current Work Order and not future orders.

Code Field

  • Enter the code you would like to override to.

Code Price by XY Field

  • Will have priority over UI pricing.

Code Price by UI Field

  • Will only effect the pricing if nothing is entered in the XY field.

Formula Tab

  • The formulas created on this tab will only override the prices when there is no Code Price entered for the specific component.

Cost Tab

  • Cost calculations cannot be edited on this tab.

  • These values originate from the Price Codes file.

  • The only editable field is the Qty (Quantity) field, allowing you to add additional components when necessary.
