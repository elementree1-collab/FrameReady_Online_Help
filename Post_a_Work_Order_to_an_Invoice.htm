Post a Work Order to an Invoice

Main Menu > Work Orders > Form View

Now that you have filled in the information on the Work Order, you may wish to take a payment from your customer.

Tip: Until you are ready to take a payment, do not click the Post to Invoice button.

How to Post a Work Order to an Invoice

Caution: This feature only works if all the necessary Work Orders have been created -- on the same day, for the same customer -- or there is only one Work Order for the customer.

  1. On the Work Order screen, click the Post to Invoice sidebar button.

  2. A dialog box asks if want to print a Work Order summary as well as post to an Invoice.

  3. If you click Post Only, then the Invoice Line Item Entry screen appears with the Work Order(s) appearing as line item entries.

  4. To continue, see: Take a Payment

How to Post a Work Order to an Invoice - Menubar

  1. Select Perform on the Menubar at the top of the screen.

  2. Select Post to Invoice from the list of options on the pull down list.

  3. A dialog box asks if want to print a Work Order summary as well as post to an Invoice.

  4. If you click Post Only, then the Invoice Line Item Entry screen appears with the Work Order(s) appearing as line item entries.

  5. To continue, see: Take a Payment
