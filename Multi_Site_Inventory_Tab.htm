Multi Site Inventory Tab Explained

Move Inventory Button

  • Moves the product from one site to another. Invokes a dialog box requesting the quantity of product to move, the site that it is being moved from, and the site that it is being moved to. Inventory levels are recalculated, and an entry is made in the Log file.

View Log Button

  • Opens the Log file. Entries show the past history/activity of the Move Inventory button. The log can be searched (click View menu > Find Mode), printed out and can act as packing slip to go with the product when it is physically moved.

Report for All Sites Button

  • Generates a site-wide inventory list for all items or just the items in the found set.

GTTR Button

  • Opens the Related Records screen. For advanced use.

Multi Site Inventory Line Items Explained

Out Field

  • The quantity that has been consigned out at each separate site, using the Consignments file.

Site Field

  • The name of the site; color-coded.

Qty Sold Field

  • The number of items sold since inventory was first entered for this item.

  • When items are returned, the quantity sold is reduced.

Qty On Hand Field

  • The quantity of product inventory available at each location.

Threshold Field

  • Threshold is used to ensure that the product is always in stock. When the amount in the Qty on Hand field falls below the Threshold, then the amount in the Reorder Qty field is added to the Purchase Order created for this company. Company must be identified on screen.

  • See the "Rules" section below for more information.

  • Do not use a value of 0 (zero).

Keep on Hand Field

  • The quantity to always have available on hand.

  • When used, the Reorder Qty field will adjust to make sure that, the next time the item is ordered order,

  • See the "Rules" section below for more information.

Reorder Qty Field

  • The amount of product to reorder when the Threshold falls below the amount in the Qty on Hand field.

  • When Main Menu > Products > Create Purchase Order button is used, then a Purchase Order is created for the supplier as identified by this product.

  • See the "Rules" section below for more information.

Minimum Field

  • Optional. The minimum quantity that a supplier requires for re-ordering.

  • See the "Rules" section below for more information.

On Order Checkbox

  • Indicates that the Product item is on order (for that specific location).

Received Field

  • The date when the item was entered into FrameReady. This field is automatically entered with the current date when you create click on the New Item button.

First Sold Field

  • The date when the item was first sold. If the two dates below it are the same, this indicates that the item has only sold once.

Previously Sold Field

  • The date sold between first sale and the last sale.

Tip: If this date is the same as the first date, then this Product item has only sold twice in its history.

Last Sold Field

  • The date when this Product was most recently sold on an Invoice.

Turn Around Field

  • A calculated field counting the days between the two most recent sale dates.

Location Menu

  • The location, e.g. Bin or Shelf, where the item is stored at the current site.

List View Button

  • Switches to a list view of all Products at the current site.

Rules for Threshold, Keep on Hand, Reorder Qty and Minimum Fields

  • The Threshold field sets the point at which the Reorder Qty is posted to a PO.

Using the Minimum Field (Optional)

  • If the value in Minimum is greater than the sum of Keep on Hand minus Qty on Hand,  then the Reorder Qty will be the Minimum.

  • If the value in Minimum is less than the sum of Keep on Hand minus Qty on Hand, then the Reorder Qty will be the sum of Keep on Hand minus Qty on Hand.

  • If there is no value in Minimum, then the Reorder Qty will be the sum of Keep on Hand minus Qty on Hand.

The Reorder Qty Field

  • If there is no value in Minimum, then the Reorder Qty will be the sum of Keep on Hand minus Qty on Hand.

  • If there is no value in either Minimum or Keep on Hand, then the Reorder Qty will be whatever is in the field.

  • When the Reorder Qty field is green, then it means that the item is ready to be posted to a PO.

  • The On Order checkbox indicates that the item has been posted to a PO and is waiting to be received (from the PO). While it is checked the item will not be posted again.

How to Setup Multi Site Inventory

  1. Hand-enter the quantity in the Qty On Hand field.

  2. In the Threshold field, enter the quantity amount that will trigger a re-order.

  3. If you always want to keep a fixed amount on hand, add that value into the Keep on Hand field.

  4. In the Reorder Qty field, enter the amount you want to re-order when the threshold is reached.

  5. If your supplier requires that you order a minimum amount, enter that number in the Minimum field.
