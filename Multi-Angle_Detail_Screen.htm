Multi-Angle Detail Screen

Work Orders > Framing Materials section > Multi-Angle text button (or any clickable text in Framing Materials Section) > Multi-Angle tab

The Multi-angle component calculates a charge to cover the additional time needed to create a multi-angled frame. The charge is based on a percentage of the total framing price; the more complicated the construction, the higher the percentage.

Multi-Angle Tab Explained

Item Drop-down

  • Use to set the item; the values are pulled from the Price Codes file.

  • To edit, do a Find in your Price Codes for the Item name (in the Multi-Angle group).

Markup Field

  • Pre-set in your Price Codes but may be modified for this Work Order.

Minimum Price Field

  • The Minimum Price field is pre-set in your Price Codes but may be modified for this Work Order.

Price Field

  • The Price field is pre-set in your Price Codes and is not-modifiable on this screen.

Clear (X) Button

  • Use to remove the line item entry.

Done Button

  • Use to return to the main Work Order screen.

How to use the Multi-Angle Tab to calculate a labor charge

The "Multi-angle" field on the work can be used to calculate the labor charge.

  1. Go to the Price Codes file and click the New Price Code Item button.

  2. Select Multi-Angle as the Group.

  3. In the Item field, enter  Labor Charge  (or whatever else you might want to call it).

  4. In the Markup field, enter  0.35 

  5. Go back to the work order and you should now see "Labor Charge" in the list.

    Based on the sum of all the components (except for "Other" or artwork) it will add 35%.
