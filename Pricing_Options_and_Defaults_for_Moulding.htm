Pricing Options and Defaults for Moulding

Price Codes > Moulding sidebar button > Frame Pricing tab > Pricing Options and Defaults button

The Pricing Options and Defaults window is a separate file used as a reference for vendor price updates and for storing your own unique formulas.

What is a Default Record?

  • When FrameReady imports a new vendor record, such as a new moulding, it needs to know what pricing formula to apply to the new record.

  • So, FrameReady searches the Pricing Options and Defaults file for a Default Record - and when FrameReady finds one, that default record describes and instructs FrameReady on how to price the item.

When is a Default Generic Record Used?

  • When you click on the Lookup My Default button (located on the Frame Pricing tab), it will paste the appropriate pricing default into the Formula and Set Price fields for the item you are currently viewing.

  • When you download your Vendor Pricing Updates, your default selection will be applied to all new moulding records for that vendor.

  • If the Default check box is not selected, then the formula will not be applied to any records. It is simply a pricing option that you may chose to use at a later date.

Therefore, it is important to understand and properly set up the Default Records.

Moulding Pricing Options and Defaults

  1. Open the Price Codes file, switch to Moulding (form view) and open the Frame Pricing tab.

  2. Click the Pricing Options and Defaults button.

  3. The Pricing Options and Defaults window appears. 

    In this window are multiple Pricing Records, on alternating rows of colored blocks, going down the screen.

    Each Pricing Record has its own Formula, Set Price, Minimum & Surcharges tabs and Default selection boxes.

  4. Each Pricing Record can be thought of as two parts:

    • The part which determines how to calculate the price (the Formula, Set Price and Minimum & Surcharges tabs)

    • And the part which controls how and when that price is used (the Default column)

Pricing Options and Defaults for Moulding Screen Explained

1. Current Record

  • There are numerous pricing records on alternating colored blocks going down the screen. Each record consists of the Formula, Set Price, and Default selection boxes. These can be divided into two parts. The part which determines the price to be calculated: Formula, and Set Price. And the part which governs when and if it will be applied: Default.

  • Indicates the current, active record.

2. Formula Tab

  • Required: must have pricing formula entered into it.

  • The formula must identify which wholesale cost field to use (cost, chop, or join) and what markup is to be applied to it. It can also include other factors, such as, a dollar amount per foot, or a vendor discount that you wish to pass on to your customers.

  • The formula that is entered here determines your selling price per foot of moulding.

3. Set Price Tab

  • A fixed dollar amount that is added to the calculated price of a frame.

  • Set Price can be entered as a number or a formula.

4. Minimum & Surcharges Tab

  • The Minimum & Surcharges tab contains 3 additional charges which can be added to the retail price:

  • Minimum Footage

    • Ensures that smaller frames do not price below the footage amount entered in the field, e.g. 4 foot minimum order. 

  • Footage and Surcharge for Oversize 1 and Oversize 2

    • Add an additional percent to the retail price when the moulding exceeds the length entered in the field, for example for footage over 10 feet add 10% to the retail price.

  • Width Multiplier

    • Increases the width of the moulding by multiplying the moulding width against the number in the field.

    • Note: The field must always have a value of at least 1 and not exceed 2.

    • This will increase the amount of footage priced by a small amount. However, the size of the frame on the Work Order will still be accurate, e.g. 1″ frame with 1.25 width multiplier will become 1 1/4″ and the required footage will increase accordingly.

5. Note Field

  • Record any type of information, such as, the date it was last modified, how it is intended to be used, where you got the formula

6. Default Checkbox

  • Appears on each Pricing Record but is only applied/active if an X appears in the box.

  • When the Default checkbox is selected, a Group list and Supplier field appear below it.

  • The Group list controls which records will have the Pricing Formula applied it, e.g. Wood or Metal.

  • The Supplier field allows you make the pricing formula vendor specific, e.g. when a vendor pricing update is performed and new records are imported into your Price Codes, then FrameReady searches for a vendor-specific default record before applying a generic record.

  • If the Supplier field is left blank, then the pricing default is applied to all Suppliers with items belonging to the selected Group(s).

Important: For any given Group (Metal, Wood etc.) there should always be at least one default generic record, i.e., the Supplier field is left blank.

 

7. New Record Button

  • Creates a blank Pricing Record (at the bottom of the screen) for you to fill in. If this was created in error, use the Delete button to remove it.

8. Show Defaults Only

  • Is both a heading and a button (that’s why it is underlined).

  • When clicked it will find and display all the Default records.

9. Find Button

  • Opens a Enter Search Criteria Screen to find one or more pricing records by whatever criteria you enter. Click the Find button on the left side of the screen or press the Enter on your keyboard to perform your find.

10. Show All Button

  • Displays all of your pricing records in a list view.

11. Done Button

  • Returns to the Price Codes file and the moulding record you were previously viewing.

 

12. Print Button

  • Prints data for the current, active record.

13. Enlarge Button

  • Opens another window where the Formula and Set Price are the only items on the screen -- giving you more room to view longer formulas.

  • The window also contains a button to send your formula, by email, to the FrameReady Team for tech support.

14. Select Button

  • Applies the formula to the moulding record that you were previously viewing in the Price Codes file.

15. Apply to Group Button

  • The Apply to Group button presents a dialog box where you can apply the formula to a select group of records.

16. Duplicate Button

  • Creates a duplicate record which you can then modify for a different group or supplier.

17. Delete Button

  • Removes any unwanted Pricing Formula records.
