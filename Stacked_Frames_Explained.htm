Stacked (or Layered) Frames Explained

Work Order File > Layered Frames icon

When stacking (or layering) frames, it is important to ensure that each frame fits properly into the next frame.

Ensure Accuracy and a Good Fit

  • FrameReady is able to calculate the exact dimensions for each frame to ensure a proper fit.

  • However, if the width of the moulding in any of the layered frames is not accurate, then you will not have a good fit.

Verify the entry in the width field of the Frame or Liner being used

  • Sometimes suppliers for Frames and Liners will enter 1 1/2 when the actual size is 1 5/8 or 1 3/8.

  • In rare cases, the number is not correct at all. Do not rely upon someone else's entry when stacking frames.

  • Before stacking frames, always check the dimensions and build from the inside-out.

  • It only takes a moment to check the size.

How to Correct a Width Measurement

  1. If the actual measurement of the sample is different than the measurement in the width field of the Layered Frames screen, then use the Modify button to change the measurement.

  2. Once the measurement is corrected, all subsequent entries of the same moulding will be correct.

    Note that vendor pricing updates do not update the width field.

Note: If you are stacking frames from different suppliers, then it is a good idea to order the inside frame (Frame1) to the supplier first and, upon it's return, measure the frame and then order the second (Frame2) based on the outside measurements of the first frame (Frame1).

Verify the entry in the width field of the Fillet being used

  • Fillets are sometimes erroneously given the entire width of the sample rather than just the sight size.

  • Even if the fillet is placed between two matboards, it is important that the width be as precise as possible.

  • FrameReady is able to handle fractions in 1/2, 1/4, 1/8, 1/16 and 1/32 of an inch.

How to Correct a Fillet Measurement

  1. Click the Layered Frames icon.

  2. Use the Modify button to change the width of the fillet.

  3. Once the measurement is corrected, then all subsequent entries of the same fillet will be correct (vendor pricing updates do not update the width field.)
