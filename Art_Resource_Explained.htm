Art Resource Explained

Main Menu> Art Resource

The Art Resource File is a user-friendly catalog for searching your Products File based on Artist or Subject. It is just another way of looking through your products.

Art Resource Form View

DetailsTab

  • Title, Item Number, Artist, Subject, Size, Category, Price, Stock (Quantity) fields are all auto-filled from the Products file when you select a record from the Subject or Artist tab.

  • You must have Artist and Artwork data in your system in order to proceed.

Browse by Subject Tab

  • Subject: Transfers from the Subject1 field in the Products file. E.g., "Americana"

  • Show in List View: shows all found set in a list format.

Browse by Artist Tab

  • Shows all other works for the artist.

Art Resource List View

  • The Art Resource List View shows the information from the Products File in a list with a preview image if one has been uploaded.
