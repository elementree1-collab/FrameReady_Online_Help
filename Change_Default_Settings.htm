Change Default Settings

If changes to FrameReady settings, using a Guest computer, are lost the next time FrameReady opens or the computer is reset, then those changes must be made on the FileMaker Server computer.

Change FrameReady Settings when using FileMaker Server

List of Global Fields that can only be changed on the Server Computer

Below is the list of Global Fields which can only be changed on the Server computer. If you are on a FrameReady guest computer and change a global field, then the entry remains until you exit FrameReady. But, when you re-open FrameReady, the change reverts to the original entry on the Server computer.

The following fields are "global," that is, they revert back to their original state when you re-open FrameReady.

To change their original state, the FileMaker Server must be closed, the changes made, and then the FileMaker Server reopened.

  • Products

    • Wholesale Value Calculation

      • Located in Products file, form view (grey button on lower left side).

      • This percentage is used when you click the Convert/Update button on the work order screen. The amount is used to calculate the wholesale cost of a work order which is updated to a readymade frame or a work order which is used to convert a piece of art into a pre-framed art item.

  • Work Orders:

    • Defaults

      • Options tab > More Options… > Work Order Defaults tab

    • Printing Options

      • Options tab > More Options… > Print Options tab

      • Make sure all Yes/No options have a selection

      • See: Set up Work Order Print Options

    • Email Completion & Proposal Messages

      • Options tab > Edit Email Message

      • See: Set up Work Order Email Messages

  • Contacts:

    • Ranking and Ranking Date

      • Run the report located on Main menu > Invoices block > Sales Reports > Customer button

      • See: Ranking Explained

  • Invoices:

    • Printing Options

      • Options tab > More Options… > Print Options tab

      • Make sure all options have a selection

    • Terms

      • Options tab

      • E.g. Net, Net/30, etc.

    • Email Invoice & Statement Messages

      • Email Invoice Message

        • Options tab > Edit Email Message > Invoice tab

        • See: Set up Invoice Email Message

      • Email Thank you Message

        • Options tab > Edit Email Message > Thank You Note tab

        • See: Set up Invoice Thank You Message

      • Email Statement by Aging Message

        • Options tab > Edit Email Message > Statement by Aging tab

      • Email Statement by Date Range Message

        • Options tab > Edit Email Message > Statement by Date Range tab

  • Main Menu:

    • Auto Zoom (lower left)
