How to Add a Multi-Angled Frame

The Multi-angle charge is based on a percentage of the total framing price; the more complicated the construction, the higher the percentage.

  1. In the Work Order, enter all of the components for your frame design, eg. frame, mat, glass, etc.

  2. Click in the Multi-Angle field and select the number of sides from the dropdown. 

    This will multiple all components of your Work Order (frame, mat, glass, etc.) by the percentage markup entered in the Price Codes file for the item you selected, e.g. Five sided frame. 

  3. If the item you are looking for is not listed, you will need to add it to your Price Codes file. See: Set up Multi-Angled Pricing

  4. Based on the Markup Formula for the Multi-Angle item, FrameReady will scale up the Retail Price.

Note: if you wish to change the percentage amount on the Work Order without changing the original item in the Price Codes file, then click on the underlined word Multi-Angle and change the percentage amount in the Markup field. Be sure to enter it as a decimal value, e.g. .5 will be 50%.
