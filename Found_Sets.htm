Found Sets

What is a Found Set?

  • When you perform a find, FrameReady searches all records, comparing the search criteria you specified with the data stored inside it.

  • Those records with data matching the search criteria become the Found Set. These are your search results.

  • The Found Set is a subset of records being browsed -- because records that did not match were omitted.

  • FrameReady shows you the number of records in a Found Set and informs you which record is currently displayed, e.g. 7 of 96 Total: 15614

Note: You do not need to choose Show All Records before performing finds. FileMaker Pro always searches all records in the tables you specify unless you have narrowed the existing found set.

Working with a Found Set

  • You can work with just the records in the Found Set. For example, you can view, edit, calculate summaries for, sort, print, delete, export, or replace data in these records.

  • The yellow navigation arrows (first record, previous record, next record and last record) operate as normally, except only within the Found Set.

  • To clear or get rid of a Found Set and go back to seeing all records, click the Find All button.

Cancel

  • To cancel a find operation before it is finished and leave the previous found set unchanged Press Esc (Windows) or Command + period (Mac).

Show All Records

  • To show all records in Browse mode, click Show All, or choose Records menu > Show All Records.

  • In Find mode, choose Requests menu >Show All Records.

Activate Browse Mode

  • At the bottom of your screen, click on the screen icon to the left of the word Browse.

  • The FileMaker Pro control bar appears.

  • The light green area of the pie chart in the status toolbar above indicates the portion of the total records displayed

  • You can click the pie chart to toggle between your found set and the omitted records in the database. When all the records are displayed, the pie chart is a solid color pie.
