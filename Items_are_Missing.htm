Items are Missing

The Problem

  • Instead of the expected information appearing when you add an item to a Work Order, it is not found.

Possible Reasons

  • The item is new but the data is old and does not list it, or

  • The item was flagged as Not Verified, then manually marked as Discontinued and then manually deleted from your FrameReady setup, or

  • The item was manually deleted from the Price Codes file, or

  • The item name contains an invalid character, or

  • The item name begins with a spacebar character (may be difficult to see).

How to Find Missing Price Code Items

Possible Solution: Update your Vendor Pricing

  1. On the Main Menu, click the Update Vendor Pricing button (bottom right).

    The Vendor Update window appears.

  2. In the My Vendors tab locate the vendor. An X in the checkbox indicates an update is available. Click the vendor name.

    The Processing Vendor Update window appears.

  3. Click Proceed to download the latest data.

  4. If there are new items, then you are given an opportunity to import them.

  5. You will also be given the opportunity to choose how you order (length, chop or join) and to print out a list.

  6. If there are discontinued items, then you are given the opportunity to mark them as Not Verified.

  7. After the update, go back into your Work Order and enter the missing item. It should now appear.

  8. If it does not, then the likelihood is that the item has been discontinued.
