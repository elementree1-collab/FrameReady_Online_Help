Shopify Integration

Shopify Integration Set Up

Main Menu > Setup Data > Integrations > Shopify Integration

Follow these steps to set up the Shopify Integration in your FrameReady.

How to Set up the Shopify Integration

  1. On the Main Menu, click the Setup Data button (top right).

  2. Open the Integrations tab.



    In FrameReady 13.1.3 or earlier, open the Fiscal tab.

  3. Click the Shopify Integration Settings button. Do not close FrameReady.

  4. The Shopify Integration Settings opens. You will notice a few new fields: Store Name, Access Token and some others.

    Before we can obtain the information for these new fields, you need to open your web browser and login to your Shopify Admin Center.

Connect to your Shopify Account

  1. Go to www.shopify.com and log into your Shopify account. 

  2. Once you are logged in, go to the left hand side of the page in the left sidebar and look for the ‘Apps’ button and click on it. This will open up a dropdown as shown below. At the bottom of the dropdown is an option for ‘App Settings - click this option to continue on.


  3. This will open up a new screen for App and Sales Channels. From this screen you need to click on the ‘Develop Apps’ button which will allow you to begin the set up for the integration.

  4. Once you click on the Develop Apps button, it will open up the App Development screen for you to set up the Shopify Integration. Hit the ‘Build Apps in Dev Dashboard’ button to continue.

    Once you click the ‘Develop Apps in Dev Dashboard’ button, it will open up the Shopify dev dashboard where you will click the Create an app button. This will open up a new window to enter the name of the App and hit create. You can name the integration anything that you want but in this example, I am going to name the app ‘FrameReady Integration’.


  5. Once the integration has been created, you will see the “Create Version” screen. Click the ‘Configure Admin API scopes’ button. The first step now that Shopify is authenticating through OAuth 2.0 is to enter your “App URL”. For your App URL you should enter the homepage for our parent company Quilt LLC which is: “https://quiltsoftware.com”

  6. Next you will need to select the proper access scopes for the Shopify integration that it needs to access your data. Click the link to the right that says “Select Scopes” which will pop up a window with all available scopes. Look at the image below to see exactly which Admin API scopes that you need to select the checkboxes for. Once you have selected all the of API scopes click the “Done” button at the bottom right to save your Admin API Scopes.



  7. After you have saved your API scopes, we need to enter in a “Redirect URL” for the OAuth 2.0 authentication. Our parent company Quilt LLC also has a redirect page that we have set up which is: “https://quiltsoftware.com/quilt-unified-operations”. Enter that URL in the box for the Redirect URLs and then finally click the “Release” button in the bottom right of the page to complete. You will get another pop up to specify the version name which you can simply skip this step and just hit the release button again.

  8. Now that you have created your App release, go to the lefthand sidebar when you are in your current integration and click on the “Settings” link. Under Settings will be the heading for “Credentials”. Here you can access your “Client ID” and “Secret” which you will need for the next step.

  9.  

How to Enter the Client ID and Secret Into FrameReady

  1. Return to FrameReady; the Shopify Integration Settings should still be open.

  2. Click into the ‘Client ID’ and “Client Secret” fields in FrameReady Shopify Settings page. Here is where you will need to paste the Client ID and Secret that you copied from Shopify.

  3. Next, paste your Store Name from your Shopify store into the Store Name field (above the Access token).

    You can find the Store Name in the web address of your web browser for your Shopify store when you are logged in. It is the text that is in between the  https://  and  .myshopify.com .

    In the example below, it is framereadydev . Once you have that copied, paste it into the Store Name field in FrameReady.

  4. To finish the authorization process click the “Generate Access Token” button in the Shopify settings. This will open up a new window with a web browser viewer window. It may ask you to login to your Shopify but eventually it should take you to a screen that says Quilt. After reaching that screen, the process should automatically take you back to the Shopify settings screen and let you know your Access Token was generated. If it does not, simply hit the back button to go back and then click the “Generate Access Token” button again and it should automatically load it this time.

  5. If you select Orders, then you can import web orders from your Shopify store and FrameReady will check the customer on the order to see if that customer exists in FrameReady already. If the customer does not exist in FrameReady, then FrameReady creates a new Contact record for you. You can then view each order and review before converting them into FrameReady Invoices.
