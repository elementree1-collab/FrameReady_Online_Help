Mat Design Detail Screen

Work Order > Framing Materials Section > Mat Design Text Button (or any clickable text in Framing Materials Section) > Mat Design tab

Tip: The tabs at the top of each Work Order Detail Screen allow you to move through the Work Order in different ways.

Mat Design Detail Screen Explained

  • The Mat Design Detail menu is available when you require several different design elements.

  • When pricing and production will change based on the number of elements used, this menu will allow you to provide all of the details for the order.

  • Enter up to five mat designs and add individual mat design discounts.

 

Mat Design Screen Explained

1) Item Field

  • Click on the field to bring up the list of Mat Designs already entered into your Price Codes file.

2) Placement Field

  • Select the measurements for the current Mat Design, such as length of inset corners. Select from the pull down menu, use Edit to add in additional measurements as needed.

3) Thickness Field

  • Fills in this value based on the information in the Price Codes file. Effects the total depth required for framing components shown on the main Work Order screen.

4) Price Field

  • Retail price based on the current Work Order sizing and calculated from data within the Price Codes file.

5) Qty Field

  • Apply design to multiple mats by entering the total number of mats used in the design.

6) Extended Price Field

  • Shows the total retail cost based on the quantity entered in the previous field.

7) Discount Field

  • Used to apply a percentage discount to the individual mat design. Must be notated on every mat design it should be applied to.

8) Total Price for the Mat Designs Field

  • A not modifiable field listing the total price for the mat designs selected for the order.

 

Mat Design Detail Tabs Explained

Special Tab

  • Shows the number of openings and the retail price per window. The price per window can be changed here and will only affect this current work order. Selecting the oval/circle Window checkbox will result in a round opening to appear on the printed Work Order.

Extra Openings Field

  • When empty, FrameReady assumes that there is at least one window. When there are more openings, enter the additional amount in this field. Ex. 4 openings listed as 3 as the 4th is understood by FrameReady.

Per Window Field

  • The default price is determined within the Work Order Options. Manually edit that price here.

Price Field

  • Not modifiable field listing the total cost for the additional mat openings.

Oval/Circle Window Checkbox

  • Select this box when the opening is either shape to inform inform the framer when they begin production.

Num of Layers, Price Per Layer, Price Field

  • These fields appear only when a Mat Design software is selected in the Work Order Options.

Show Designs Button

  • Opens your Design Software of choice to display the current designs your frameshop offers.

Unit of Measure Tab

  • Lists only the current measurements for the Work Order in terms of UI and Square Inch.

  • Code - Enter the code you would like to override to.

  • Code Price by XY - Will have priority over UI pricing.

  • Code Price by UI - Will only effect the pricing if nothing is entered in the XY field.

Formula Tab

  • The formulas created on this tab will only override the prices when there is no Code Price entered for the specific mat design.

Cost Tab

  • Cost calculations cannot be edited on this tab. These values originate from the Price Codes file.
