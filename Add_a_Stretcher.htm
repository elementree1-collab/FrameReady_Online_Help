Add a Stretcher

Main Menu > Work Orders

Stretchers or strainers can be entered into the Work Order the same as any other frame.

  • Use the Stacked Frame icon to access the details window where you can layer up to five frames. Enter the stretcher bar into the Frame1 field and the moulding into the Frame2 field.

  • With the popularity of canvas printing, it is important to be sure that you have the correct size for your stretchers and frames. Stretchers, Strainers, etc. must all be in the Group: Extender. This prevents the frame from being enlarged by the width of the stretcher bar. It also builds the frame in depth so that the stretcher size is the same as the image size. 

  • The trick is to make sure that the Group of the stretcher is not Wood, but instead, is Extender.

  • Verify the width of your frames to ensure accuracy when stacking multiple frames.

Note: Information sent to us by suppliers does not distinguish items by group. We recommend that you find all the stretchers or strainers you use and change the group from Wood to Extender. To find these items, type  stretcher  (strainer, boxer, etc.) in the Description field of the Price Codes file and manually change the Group (to Extender) on each record.

How to Enter a Stretcher on a Work Order

  1. In the Work Order, click the Stacked Frames icon.



    The details window appears.

  2. Enter the stretcher moulding number into the Frame1 field.

  3. If the Group field is not "Extender", then click the Modify button and change the Group from “Wood” to “Extender“.

Note: Using the Modify button to make changes will affect the current Work Order and all subsequent uses of the same item. So, once you have switched the stretcher Group to Extender for this one item, it will be accurate every time you use it.

  1. As needed for your design, enter the rest of the frames into the Frame2 to Frame5 fields.

    For information on entering a float mount, see: How to Enter a Floater Frame and Floater Space

  2. Click Done to return to the Work Order.

How to Enter Support/Center Bars

If the piece requires cross- or center-bars, then use the Other field to add it:

  1. Click the underlined Other button.

  2. The Other Items window appears.

  3. Click the Add Item button.

  4. The Add Other Line Item window appears.

  5. In the Item field, enter the stretcher moulding number.

  6. In the Size field, enter in the length of extender that you need.

  7. Verify the calculated retail price, then click Done.

  8. Click Done again to close the Other window.
