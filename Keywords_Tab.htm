Keywords Tab

Main Menu > Contacts > Keywords tab

Keywords provide an excellent way to track mailing lists, advertising campaigns, group discount members, frequent framers coupons, etc.

  • Use keywords to group customers together, not for individual notes such as "Works at law office" (Use the Group/Details tab for such information as birth dates.)

  • Keywords can be of great statistical help when used in conjunction with the Find feature. For example,

    You keep track of all the needlework customers and each quarter you wish to send a special notification, to just this group, and let them know about a promotion. But you wish to only send out emails. So you use the Keyword: “Needle worker” and Perform Find for only those on this special list with an email address in the field.

  • See: How to Use Keywords

Keywords Tab Explained

Add/Remove Keywords Button

  • Opens a new window to the right of the main window, listing all keywords.

  • See also: How to Search and Find, How to Use Keywords

Reward Points

  • The customer's total reward points. Open the Invoices/Rewards tab for more detail.

Creation Date

  • The full date when this customer record was added into FrameReady.
