Add Customer Artwork

Main Menu > Work Orders

This is an overview of adding customer artwork or art product to a Work Order.

How to Add Customer Artwork to a Work Order

Use these steps to record the customer's artwork on the Work Order.

  1. Click the Artwork field and select the type of artwork to be framed.



    To edit this list, see: Add a New Artwork Category

  2. Enter a customer-friendly description of the artwork (it will appear on the Invoice).

  3. Choose a Condition that best describes the artwork, e.g. Good or Stained. For special cases, hand-type one in.

  4. Choose a Location where the framer can locate the artwork.

  5. For insurance purposes, enter the artwork value in the Value of Art field. 

  6. Do not add a Price -- the art already belongs to the customer.

  7. If a Certificate of Authenticity came in with the customer's art, then put a tick in the checkbox.

How to Add an Artwork Product to a Work Order

  1. Click the magnifying glass icon.

  2. A search dialog box appears.

  3. Enter either the Item Number, Description or Artist.

  4. Click the Search button.

  5. A list of search results appears.

  6. Click an item name to add it to this Work Order.

    Where applicable, the Artwork field, Description, Product number, Artist, L.E.#, and Retail Price of the product appear in the Work Order.

Can more than one art be added to a Work Order? 

  • No, but you could put two additional products into the Readymade field BUT you must check the box to Post separately AND change the Category on the Invoice when it is posted.

  • OR, manually enter the other art pieces after posting the Work Order to an Invoice.
