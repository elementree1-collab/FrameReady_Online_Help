Set up City and States List

Main Menu > Data05.fmp12

FrameReady allows you to edit the main list of the your customers' most common cities and states/provinces.

  • Helps prevent misspelled city names and unnecessary duplication by using pre-filled values.

  • During intake, easily select the city and state with the mouse instead of hand-entering.

How to Edit the City and States List

These steps are for FrameReady 13.1.3 or higher.

  1. On the Main Menu, in the file menubar, click Perform and choose Restore Full Menus.

  2. Again in the file menubar, this time click Window > Show Window and choose Data05.

  3. The Data05 window appears.

    This is a utility layout where some important FrameReady data can be managed.

  4. Click the blue City or State button to reveal the values.

  5. Use the + icon (top right) to add an entry to your list of cities or states; the new entry is at the top.

    Type the new City or State name into the empty field.

    When seen in FrameReady, all values are sorted alphabetically.

  6. Use the - icon (right of each entry) to remove an item.



    Click Delete or Cancel.

  7. Click the Main Menu icon (top left).

    Go into the Contacts file and click into the City or State field to see the changes.
