Update a Posted Work Order on an Invoice

Work Order  > Posted Button

Changes have been made to a Work Order that was already been Posted to Invoice. Now the Invoice needs to be updated.

How to Update an Invoice after changing a Work Order that has been already been Posted to Invoice

  1. Find the Work Order in question.

  2. Make the appropriate change(s) to the Work Order.

  3. Click the Posted sidebar button.

  4. A dialog box appears asking if you would like to update the Invoice to reflect changes made to this Work Order.

  5. Click Yes.

    The updated Invoice appears. Proceed as needed.

Tip: If you hover the mouse over the Posted button, then a tooltip appears "This work order was posted to Invoice# on [Date/Time]"
