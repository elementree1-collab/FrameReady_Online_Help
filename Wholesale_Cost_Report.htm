Wholesale Cost Report

Work Order > Print Document sidebar button > Wholesale Costs button

This report provides a breakdown of the wholesale cost of all items in a custom order.

  • The total also appears in grey numbers on the Work Order screen in the bottom left corner.

  • Waste factor can be modified, Main Menu > Work Order Options. See also: Set up Work Order Options - General Tab

Example Print

How to Print Wholesale Costs

  1. Perform a Find for the Work Orders you wish to include in the report.

  2. Click the Print Documents sidebar button.

  3. The Print Documents window appears.

  4. Click the Wholesale Costs button.

  5. If you do not have a found set, then FrameReady alerts you to perform a find before running the request.

  6. Click OK and do a find for the Work Orders. Note that a large Found Sets may take time to prepare.

  7. Otherwise, a print preview appears.

  8. Click Save as PDF or Continue to print.
