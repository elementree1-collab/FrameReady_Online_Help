FileMaker Server Overview

FileMaker Server is a software package available through Adatasol Inc. for opening FrameReady over a computer network.

  • FileMaker Server allows you to open FrameReady on more than one computer or device.

  • FileMaker Server software is installed on a separate computer that is dedicated to sharing your FrameReady files. The system requirements for this computer are strict.

  • Typically, you do not access FrameReady on this computer, but instead, access is from other computers over your Local Area Network (LAN) over ethernet (recommended) or wifi (not recommended).

  • While earlier versions of FrameReady could be shared with up to five devices using peer-to-peer, Claris (formerly FileMaker Inc.) has discontinued peer-to-peer networking and now requires the use of FileMaker Server to share FrameReady to multiple computers/devices.

  • See: FileMaker Server system requirements --- www.frameready.com/server

Important!

If you choose to run your server "headless," that is, without a monitor, keyboard or mouse, then you must have a backup monitor, mouse, and keyboard available for Tech Support calls. Alternatively, have a remote desktop solution setup so that you can "dial into" the server computer from another computer on your network.

Additional benefits to using FileMaker Server

  1. Improved FrameReady performance over your LAN able to support hundreds of users

  2. Built-in automatic backups which can be scheduled hourly, daily, or weekly

  3. Creates a security log file to track unauthorised access to your data

  4. Reduces risk of damaged files

  5. Share data with more than five devices

  6. If you purchase a static IP address from your Internet Service Provider, and route port 5003 to your server computer, then you can access FrameReady off-site.
    See: Remote Access
