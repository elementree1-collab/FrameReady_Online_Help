Stopping and Starting Files on FileMaker Server

How to Stop Serving Files

  1. Quit FrameReady on all computers.

  2. On the server computer, open the FileMaker Server Admin Console.

    See: Opening the FileMaker Server Admin Console

  3. In the nav bar, click Databases.

  4. To the right of All Databases, click the dropdown arrow and choose Close All.

  5. Select Close All.

  6. In the "Close All Databases" dialog, change the delay time to  0  (minutes) and click OK.

    The FileMaker Server closes all database files.

  7. Wait for the blue icon to turn grey; when this happens, the files are no longer being served by FileMaker Server and can be opened locally for changes.

How to Start (or Restart) Serving Files

  1. On the server computer open the FileMaker Server Admin Console.

    See: Opening the FileMaker Server Admin Console

  2. In the nav bar, click Databases.

  3. To the right of All Databases, click the dropdown arrow and choose Open All.

  4. Exit the Server Admin Console.

  5. Re-open FrameReady on your guest computers.
