Matboard Is Priced By Area

You can price it by Formula

  • Matboard can be priced by a Formula which takes your cost of goods (COG) and multiplies it by a Markup then adds a Set Price, for example:

    Retail Price =  Cost  x  Markup  +  Set Price  

You can price by it Code Table (UI)

  • Matboard can also be priced by a Code Table. This spreadsheet-like chart cross-references the United Inches of the piece with a Retail Price.

    Retail Price =  Code Table  

You can price by it Code Table (Fixed Size)

  • Or matboard can be priced by a Code Table which cross-references a Fixed Size with a Retail Price.

    Retail Price =  Code Table  

What Are Formulas?

  • See: Understand Default Pricing Formula for Matboard

Which Way Is Right For You?

  • A question that is often asked is, “What is the easiest method for pricing my matboard?” The easiest method in FrameReady is to use a Formula: you can use the FrameReady default formula or set up your own Formulas and custom defaults.

Tip: In most cases a Formula is more desirable because it is easier to set up, and when your COG changes, the retail price updates automatically.

  • If you want to price your matboard using an existing chart or table that uses the UI, then you will need to create Code Tables (or modify the existing ones) to match your chart.
