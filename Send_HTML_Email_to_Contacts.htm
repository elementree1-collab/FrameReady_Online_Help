Send HTML Email to Contacts

New in FrameReady 12!

Main Menu > Contacts 

Send HTML email directly from the Contacts file in FrameReady.

  • Useful for sending customer-facing, marketing emails, e.g. upcoming specials and events, to your customers.

  • You can copy and paste the HTML source code (images and other files must be hosted somewhere online in order to appear) as well as make use of "merge" fields, such as First Name and Last Name. Online editors exist to visually design HTML emails.

  • See also: Set up HTML Email

HTML Email Overview

  • You can store prepared HTML emails in FrameReady and quickly send, as needed, to a customer.

  • Currently available for use when sending email from Contacts.

How to add an HTML Email in FrameReady

  1. Follow the steps to switch to SMTP HTML email: Set up HTML Email

  2. On the Main Menu, in the Contacts section, open the Options tab.

  3. Click the Edit Email Messages button.

  4. The Edit Email Templates window appears.

  5. There are two tabs, Plain Text and HTML. These represent the different types of email that FrameReady can send. You can store your message templates in either or both.

  6. Open the HTML tab and click the plus + icon button.

  7. Enter a meaningful Template Name, Subject line, and paste the HTML source code into the Body field.

Tip: Keep your Email Template names brief so that you can easily identify them in the list, e.g. Summer Sale, Referral, Pickup order, etc.

  1. Do not paste non-HTML markup in this field.

  2. Use the Preview button to see the HTML email displayed in a web browser window.

  3. Click Done.

Tip: If your website designer is able to supply an HTML file, similar to your website, to use as an HTML email template, then you can certainly use it here. See the section "Mail Merge Fields" below.

How to send an HTML Email in FrameReady

  1. Locate the customer you wish to email.

  2. Click the blue Send button associated with their email address.

  3. A dialog box appears.

  4. Click Current to send an email to just this customer.

  5. The New Message window appears.

  6. To load a template, click the Templates button and choose one of your stored templates:

  7. Click Preview to see how the HTML Email will appear.

  8. Click Send or Cancel.

Merge Fields for Contacts

The following merge fields are available for HTML email in the Contacts file:

  • §Company§

  • §First Name§

  • §Last Name§

  • §Your Business Name§

  • §Your Business Address§

  • §Your Business Hours§
