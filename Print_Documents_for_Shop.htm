Print Documents Screen Explained

 Main Menu > Work Orders (form view) > Print Documents sidebar button

Print Documents for Shop

The Print Documents window features the following Work Order sections:

  • Print Documents for Customer

  • Print Documents for Shop

  • Print Documents for Production

  • Print Documents Reports for the Found Set

Print Documents for Shop

This Work Order Button

  • Print only the Work Order last seen on-screen. It will not print 1 of 4, etc. if it is part of a larger order.

Art ID Tags Button

  • Asks if you wish to print for Found Set or Current.

  • Tags may be defaulted to print automatically when the Work Orders are printed. Follow this path: Main Menu > Work Order Options > Print Art ID Tags when Printing Work Orders.

  • See also:How to Print Art Identification Tags

All [Contact]'s Orders Button

  • Print the Work Orders created for this contact (on the same day or with the same Job #). They will be numbered 1 of 4, 2 of 4, etc.

Product Labels Button

  • Print a label for artwork entered on a Work Order and updated in the Products file using the Convert/Update sidebar button.

  • The label is intended to be used as a gallery display tag. Includes the total of the artwork and framing combined.
