Delete Invoice Line Entries

Main Menu > Invoices

Oops, I clicked the Done button but I wanted to delete a line item entry first? How do I delete it now? You don’t!

How to adjust Line Items on an Invoice

  1. Locate the Invoice.

  2. Click the Data Entry button.



    The Line Item Entry screen appears.

  3. Determine if the item is:

    A) a retail item from the Products file,
    B) a retail item manually entered on the Invoice; not yet in the Products file, or
    C) a Work Order.

    Then go the appropriate step below:

A) A retail item from the Products file

  1. Do not delete the item.

  2. Instead, enter the same item again on the next available line but use a negative quantity in the Qty field.

    This returns the product back into inventory.

B) A retail item manually entered on the Invoice; not yet in the Products file

  1. 1. Use the teal X button on the far right to delete the item.

C) A Work Order

  1. Click on the teal X button on the far right.

  2. A dialog box appears asking if you want to unpost the work order before deleting it.

  3. Click Yes.

    Unposting the Work Order removes the Work Order from the Invoice and changes its status so that it appears as if it had never been on an Invoice. On the Work Order screen, the button once again reads, “Post To Invoice”.

  4. If the customer is not going ahead with the framing, change the Work Order to an estimate by clicking the Estimate button (after clicking this button, it changes to read Activate).

  5. If the customer wants the Work Order on a separate Invoice, then you can click the Post To Invoice button on the Work Order screen and a new Invoice will be created.

  6. If the customer wants this Work Order added to another, existing Invoice, then note the Work Order number. Go to the existing Invoice (to which the Work Order will be added) and use the magnifying glass icon to add the Work Order number. Click the Search button. All the other fields (Desc, Qty, Price) are filled in.
