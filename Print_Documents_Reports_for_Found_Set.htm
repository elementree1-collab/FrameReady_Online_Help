Print Documents Screen Explained

 Main Menu > Work Orders (form view) > Print Documents sidebar button

Print Documents for Reports for the Found Set

The Print Documents window features the following Work Order sections:

  • Print Documents for Customer

  • Print Documents for Shop

  • Print Documents for Production

  • Print Documents Reports for the Found Set

Print Documents Reports for Found Set

Reports covering large time periods and/or with many records may take longer to prepare. Do not cancel or interrupt the process.

The following reports are for use after you perform a find; they are prepared using your found set.

Wholesale Cost Report Button

  • Uses your Found Set.

  • Print a report providing a breakdown of the wholesale cost of all items in an order.

Moulding/Matboard Usage Button

  • Uses your Found Set.

  • Show totals by group and quantity of specific items used for any period of time.

  • Matboard is calculated to a quarter sheet; moulding is rounded up to nearest half foot.

  • Estimates are included in this report; Work Orders on Hold are included.

  • See also: Moulding/Matboard Usage Report

Glazing Usage Button

  • Uses your Found Set.

  • Shows totals by glazing type, size, and quantity used for any time period.

  • Use to help determine which glazing sizes are most cost effective to have available and which ones can be purchased in bulk.

  • See also: How to Print a Glass Usage Report

Moulding Usage by Supplier Button

  • Uses your Found Set.

  • Generate a report of moulding used in a found set in the Work Order file, sorted by Supplier listed in the Price Codes file.

  • See also: Moulding Usage by Supplier Report
