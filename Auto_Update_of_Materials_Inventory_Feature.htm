Auto Update of Materials Inventory Feature

Main Menu > Work Order panel >  Options tab > More Options button
General tab > Auto Update of Materials Inventory checkbox

When you enable the Auto Update of Inventory feature in FrameReady, the following changes happen when working with Work Orders.

When a new Work Order is Created

  1. Click New Work Order.

  2. A slightly different Work Order data entry screen appears; it features two buttons at the top: Work Order Done and Keep as Estimate.

  3. Create your Work Order as usual.

  4. To exit the Work Order, you must click one or the other. There is no other way to exit the Work Order!

  5. If you click Work Order Done, then the inventory is automatically updated; the framing components that you added to the Work Order are removed from inventory.

    Specifically: moulding footage, matboard, mounting & glass (increments of 1/4, 1/2 or full sheet), and hardware are removed from inventory.

  6. If you click on Keep as Estimate, then the inventory remains unaffected.

How to choose? Work Order Done or Keep as Estimate?

  • Work Order Done

    • The customer is committed to purchasing the work; you are committed to building it; you want your inventory to reflect this and/or you want to order the materials.

  • Keep as Estimate

    • The customer has not committed to purchasing the work; you do not want your inventory to change nor do you want to order the materials.

When you go back to a Work Order

  1. If you go back to the Work Order, the fields are locked.

  2. To make changes, you must click the purple Modify Work Order button.



    The Work Order data entry screen appears.

  3. Materials on the Work Order are returned to inventory when you click the Modify Work Order button and only returned when you click the Work Order Done button.

There are pros and cons for using either auto or manual inventory systems. See: Manual vs Automatic Inventory Management

In the Price Codes file you will need to use one or the other, or none.
