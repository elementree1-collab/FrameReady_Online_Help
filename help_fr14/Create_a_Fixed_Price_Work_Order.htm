Create a Fixed Pricer Work Order

Main Menu > Work Orders

You have given a quote for an order of a fixed amount and now need to create a Work Order that shows that exact total.

How to Create a Fixed Price Work Order

  1. Create a new Work Order using the New button (upper right corner).

  2. Click on the Lock Price button located in the Pricing Options section, upper right.

  3. A dialog box appears where you can enter a fixed price.

    This price will remain locked until you choose to unlock it.

  4. Fill in the rest of the Work Order as usual, e.g. measurements, materials, artwork, customer.

    If this is a bulk order, then you will need to change the quantity to identify the amount in the order. On the Invoice it will identify the unit price you have entered, the quantity it is multiplied by, and the total price.
