Set up Package Specials

Work Order > Options tab > Setup Package Specials… (text button)

or

Work Order file > Perform Menu > Setup Options > Package Special

Package Special is a feature where any number of predetermined framing configurations can be set up and then auto-filled on a Work Order simply by entering an abbreviation or code name.

  • Use for fixed-price special offerings or sales promotions.

  • There is no limit to the number of packages that can be stored, however each package special must have its own identifying code.

  • The components that make up a package special can be actual items or they can be generic, e.g., wood up to 16×20.

Tip: Package Special prices are determined at the time of set up. When added to a Work Order, the price is locked at the Package Special price.

Note: to create Work Orders with fixed features but with adjustable measurements and prices, see How to Create a Work Order Template.

Some examples could be:

  •  BJ   = Boston Celtics Basketball Jersey shadow box frame

  •  PS001   = Poster Special (14″ x 17″) metal frame

  •  PS002   = Poster Special (20″ x 26″) metal frame

  •  PS003   = Poster Special (14″ x 17″) wood frame

  •  ARwood   = Artist Special, wood

  •  ARmetal   = Artist Special, metal

  •  CH001   = Christmas Sale, polysterene frame promotion

How to Set Up Package Specials

  1. To set up a new package special do either:

    Main Menu > Work Orders section > Options tab > Setup Package Specials…

    or

    Work Order > Menu Bar > Perform Menu > Setup Options > Package Special

  2. Click the Add a Package Special button.

  3. Create a Code name, a generic description like “Oak Wood” or a specific moulding # in the Frame1 field.

Caution: Each code must be unique - duplicates may cause problems.

  1. Fill in each component you desire. The components and the price could both be arbitrary depending on your Reference # or name.  

How to Use Package Specials

Work Order > Measurements tab > Package Special

  1. Click the grey Package Special button.

  2. A dialog box appears asking "Do you want to apply the package special to a new work order or to the current work order?"


  3. Click Current to undo the Work Order's pricing and replace it with the Package Special pricing.

    OR

    Click New and a brand new Work Order is created.

  4. The Choose Package Special dialog box appears.

  5. Select a Package Special code name.

    The Work Order auto-fills with data, but it is still necessary to enter the frame dimensions at this point.

  6. In addition to auto-filling the Work Order, the Work Order is locked so the price does not change.
