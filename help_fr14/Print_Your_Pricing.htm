Print Your Pricing

How to print a backup hard copy of  your pricing set up in FrameReady

Is there a function to allow for a spread sheet of all the glass, fitting, mounting, etc to be printed in standard sizes columns?

Yes, The method for printing depends on which pricing system you are using. Here are a few options:

Code Table Pricing

  1. In the Price Codes file, click the Code Tables side bar button.

    It is available in every group except Moulding.

  2. Select which table you wish to print using the drop down menu arrow on the left.

  3. Click the Printer button and print out the table.

  4. After printing, manually write on the page what it's for. i.e. Drymount on Foamcore.

Pricing by Mark Up and Set Price

If you are pricing using a Markup and/or Set Price, you can print the Price Sampler.

  1. Find the record for which you want to print.

  2. Click on the dark blue Pricing tab, i.e. Matboard Pricing.

  3. Click Show More Details.

  4. Click the Printer icon (top).

Glass and Mounting Prices

  1. Go to Price Codes file.

  2. Click on the dark blue Pricing tab.

  3. Click the grey button for Show More Details.

  4. Click the Printer icon (top of the screen).

  5. Or, locate all of your glass items, and in the form view, click the grey Price Comparison side bar button (lower left corner). This will give all of your glass items and 6 standard UI measurements. The printer button is in the top left corner.
