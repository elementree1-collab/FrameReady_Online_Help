Pricing FAQs

FrameReady offers a wide selection of pricing options for all of the components of a custom picture frame with the goal of generating a retail price. “How should I price my mats? Should I use a code table or a formula based on my costs? Should I use length pricing for my frames or chop?”

Many shop owners already know how they want to price their framing components. Others feel confused by the vast array of pricing options. How you arrive at that retail price is another question. FrameReady allows the shop owner to price their own way and not be encumbered by rigidly imposed formulas which may work for some demographics but not for others.

What are Code Tables and why have them?

Many framers have developed sophisticated charts or tables to price their frame components. Some of these tables cannot be easily translated into a formula that will work in FrameReady. The program uses Code Tables to price items either by the united inch or by a fixed size, e.g. 8×10, 11×14, 16×20, etc.

A set dollar amount is associated with the UI and the fixed size measure (the fixed size is referred to as XY). Prices can be modified individually by clicking in the price field and entering an amount. This method provides a way duplicating previously used charts and other arbitrary pricing schemes. The Code table screen allows you to view which items are being used by that table. Once the Code Table is created, all you have to do is assign the item record to the code.

How do I compare how FrameReady will price an item in comparison with my existing chart?

In the Price Codes file, the form view of each group’s Pricing tab has three columns of numbers over to the far right.
This ‘price sampler’ displays what the retail price will be using the current values, i.e, Formula and/or Set Price.
Changing the values in these fields will result in a change in the sampler.
It is a great way to quickly look up a retail price for any moulding without creating a Work Order.

I am unsure of how to price my matboard?

If you are unsure of how to do your pricing or wish to use the FrameReady matboard default formula do the following:

  1. Go to Price Codes file > Matboard side bar button > Pricing tab.

  2. Click Install Program Defaults. This will allow you to install the default formula to just the current record or to all matboard records.

  3. Click OK.

Why does each moulding number have to have a dot suffix?

Each vendor has a specific suffix, supplied by Adatasol, which differentiates it from possible duplicates. This gives mouldings with the same number, but from different companies, their own identity, e.g. 11-05.N from Nielsen and 11-05.EN from Engelsen.

If you are entering your own mouldings, then they must have a unique Item #. If you type in a number that already exists you will be alerted. But they do not require a dot suffix.

Another reason for the vendor suffix is to allow you to search in the item number field for the extension i.e. LJ, leaving off the dot. All the mouldings from that company will appear in a list.
