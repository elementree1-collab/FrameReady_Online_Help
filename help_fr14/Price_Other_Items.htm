Price Using the Other Detail Window

Main Menu > Work Order > Form View > Other

The Other field allows for calculating odd items and adding them to a Work Order.

How to use the Other Detail Screen

  1. From your Work Order, click the underlined Other button.


  2. The Work Order Details window appears, with the Other tab opened.

  3. Enter a description to identify what this"other" item is, e.g. shadow box. The description is used as a heading for mutiple items.

  4. Click the Add Item button.

  5. The Line Item Entry dialog window appears.

  6. Adjust the Qty to match your needs, the default is  1  .

  7. Either enter the Item name or use the magnifying glass icon to locate it from your Price Codes file.

  8. Enter the dimensions of the item in the Size fields. The field order is: width, height, depth.

  9. Optional: If the Price Code item has Other pricing, then, in the yellow table (lower right), the Otherpricing values appear. Choose a row and click to load in the Other price.

    See also: Other Tab

  10. Adjust other fields as needed.

  11. Click Done when complete.
