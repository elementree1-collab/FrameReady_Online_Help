Print Labels for a Frame Job

Main Menu > Price Codes / Main Menu > Product Labels

A great production tool create barcoded labels for finished packages or for items being shipped to another location to be framed.

How to Print Labels for a Frame Job

  1. In your Price Codes, search for the moulding or matboard items in need of barcode labels. Click Perform Find.

Tip: Mark the records and then perform a Find for the Marked box. The results are a list view of all marked items.

  1. Click the Product Labels button.

    The Product Label window appears.

  2. Enter the Print Layout Number you wish to use.

  3. In the Menubar click Perform > Import from Work Order file.

    A dialog box appears.

  4. Enter the starting position of the first label, e.g.  1 .

  5. Click OK.

    The dialog box closes.

  6. Click the Print button.

    A print preview appears.
