Outbound Consignment Data Entry

Main Menu > Outbound Consignments > Data Entry button

The Consignment Data Entry screen is where your consignment items are entered and assigned to someone in your Contacts (the Consignee).

Data Entry Screen Explained

Tip: To exit this screen, you must decide if the Consignment Order is Done (Process Out) or Done (Leave on Hold).

If processed out, then the Consignment Order cannot be modified. If left on hold, then you can return to it at a later time and continue.

Name Button

  • Find customer by First and/or Last name.

  • Fields are auto-filled when a consignee has been selected. Once the ID# is auto-filled then you may type in the name fields in order to make spelling or other changes.

Company Button

  • Find customer by Company name.

Phone Button

  • Find customer by Phone number.

Languages Checkboxes

  • Set the language, syncs with the language setting your Contacts.

ID#  Field

  • Customer ID# is assigned automatically when entering new customers. If you know a customer’s identification number, you can type the number in and press the Enter key.

Telelphone Fields

  • Non-modifiable fields, from your Contacts.

Consignment # Field

  • Automatically generated number, non-modifiable.

Tax 1 No. Field

  • Non-modifiable fields.

Tax 2 No. Field

  • Non-modifiable fields.

Not Tax Exempt Checkboxes

  • Not Tax Exempt Checkboxes

Line Item Section

Product File / Magnifying Glass Icon Button

  • Search your product inventory for an item.

  • Search by Item Number, Description, or Artist.

  • Click Show All for a list of all product items, then click the item you wish to select.

Item Number Field

  • Enter the Item # by typing the product number or scanning the bar code number.

Description Field

  • Auto-fill from the Products file when an item number is entered.

Status Field

  • In, Out, or Sold. Defaults to hold.

L/E Number Field

  • The Limited Edition Number, if applicable.

Artist Field

  • The Artist dropdown values can be found at Contacts > Artists > Edit Artists List button

Unit Price Field

  • Self-explanatory.

% Field

  • Shows if the product was discounted in the Products file.

  • It may also be used to discount an item when sold by the Consignee.

  • The discount carries over when posted to an Invoice.

Tax Exempt Fields

  • Check the box to exclude the line item from the specified tax.

Delete Button

  • Removes the line entry.

Totals Section

Subtotal, Tax1, Tax2, Total Fields

  • Self-explanatory.

Tax % Fields

  • Enter as decimal values, for example use  0.12  for 12%

Recalculate Button

  • Forces the recalculation of the Subtotal, Taxes and Total values.

Done (Leave on Hold) Button

  • If you need to leave this Consignment Order unfinished or to attend to other matters, use the Done (Leave on Hold) button. The information will be available when you return.

Done (Process Out) Button

  • Once marked as Done (Process Out) this Consignment Order will become non-modifiable.
