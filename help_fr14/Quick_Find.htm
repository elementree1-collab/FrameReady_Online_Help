FrameReady "All" Find

"All Find" is the ability to search all fields in a file by simply entering the search criteria in a single field.

  • Previously named "Quick" Find; it is in fact slower than searching a single because it will search ALL fields in your database.

All Find Overview

  • The All Find option is available in all components, in addition to the General Find.

  • All Find can be initiated from the Main Menu or from the file you wish to search. It is represented by a small button with a magnifying glass icon (on each file it is located beside the Find button) such as this:

  • If you know the field to search in, then use the Find button, as it is much faster than the "Quick" Find.

Tip: It is called "Quick Find" because a user can quickly enter their keyword search. However, because this feature searches ALL FIELDS, it may be slower than using the Find button.

Two Methods of Searching

Use the first method if you needed to search a specific field, such as Due Date, but also ignore searching Completed Date or Creation Date.

  1. The Find button takes you to an Enter Search Criteria screen where you must enter values into specific fields.

    FrameReady looks for a match in the fields you have filled. This is efficient when searching through a lot of data.

  2. The All Find magnifying glass button gives you a simple popup dialog box.



    You may enter a word, phrase, date or number. Dates should be entered as  MM/DD/YYY .

  3. Enter your search keyword or term. 

  4. To search all fields, click the Search All button. 

    Because All Find searches all fields, it may take longer to examine each field in each record across all your database files.

  5. To search just the Item field, click the Search Item button.

    This is the faster of the two searches. 

All Find dialog in Work Orders

  • Use Search All to search all fields for your keyword.

  • Use Search WO# to search just the Work Order number.

All Find dialog in Invoices

  • Use Search All to search all fields for your keyword.

  • Use Invoice# to search just the Invoice number.

All Find dialog in Contacts

  • Use Search All to search all fields for your keyword.

  • Use Last Name to search just the last name field.
