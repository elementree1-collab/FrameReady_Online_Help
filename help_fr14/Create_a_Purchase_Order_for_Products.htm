Create a Purchase Order for Products

Main Menu > Purchase Orders section > New Purchase Order button > Auto-Create Product Order button

FrameReady can search the Products file for Special Orders and items that have fallen below the inventory threshold set to trigger a re-order.

How to Create a Product Purchase Order

  1. On the Main Menu, in the Purchase Orders section, click the New Purchase Order button.



    An empty PO appears.

  2. At the top right, click the Auto-Create Product Order button (not to be confused with the "Frame" button beside it).



    FrameReady searches the Products file for items that have fallen below the specified Threshold. Artwork entered on the Work Order file using the Special Order button or the Special Order for this Customer sidebar button on the Contacts file is also added to the PO.

  3. This dialog box appears:



    Click OK.

  4. A list of vendors appears, displaying the items marked for special ordering or re-ordering.

    If retail items for re-order are found, or artwork for a customer on Special Order is located, then the process continues to a screen where you may Omit vendors. Omitted vendors will appear on the list the next time the Create Product Order button is clicked.

    If no retail items were found for re-ordering, then a dialog box appears.

  5. Click Continue.

    A list of the newly created POs appears.
