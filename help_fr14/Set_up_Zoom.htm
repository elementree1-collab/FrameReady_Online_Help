Set up Zoom

Main Menu > Auto zoom checkbox (lower left)

This feature allows you to take advantage of higher screen resolutions so that  FrameReady will attempt to fill your entire screen.

Important: A minimum screen resolution of 1600 x 900 must be available for working with FrameReady (in normal mode).

  • You should not have to scroll up or down to view any of your FrameReady Form View screens.

  • Higher resolution screens allow for more records to be displayed when in a List View. If the screen resolution is sufficient, FrameReady can be scaled (at fixed intervals) and fill more of the screen.

  • The Zoom setting in FrameReady is controlled by Claris Corporation in their FileMaker Pro software. We are not able to offer the option of a 125% setting (it would be great if we could as other clients have asked for this as well). The only other option is to change the display settings on your computer. This has it's drawbacks as it affect all programs; not just FrameReady.

Auto Zoom Feature Explained

  • Click the Auto Zoom checkbox (lower left of the Main Menu) to activate. FrameReady will attempt to resize the FileMaker window to fill the screen.

  • FileMaker for Windows requires additional height for it's menu and controls. Therefore your desktop height must be 1120 pixels or higher to support Auto Zoom.

  • In order for Auto Zoom to work properly in Windows 10, 8 and 7, the Display properties must be set to 100%. Choose Control Panel > Display and change the size of all items to Smaller - 100% (default)

  • In order for Auto Zoom to work properly in (older versions of) Windows the Taskbar must be set to not always be on top.

How to set up Auto Zoom

  • Click the Auto Zoom box in the lower left corner. If your screen resolution is capable of enlargement, then the screen resizes to a larger view. If not, read these instructions or view on web:  How to set up full screen view.

Tip: On Windows, it is recommended that the taskbar not be selected to be always on top of other applications. To deselect this option, do the following:

  1. Press Windows + X  and choose Control Panel.

  2. Click the Task-bar & Start Menu icon.

  3. Uncheck the Keep the Task-bar on top of other windows option.

  4. Click OK.

Setting up Auto Zoom on a Network

  • When running FrameReady on a network and you wish to have the Auto Zoom either default to On or Off, this procedure must be done on the Host/Server computer using a copy of FileMaker Pro.

  • See: Change Default Settings

Important Windows Note

Windows 8 and 10 has its own, built-in zoom control. It must be set to 100% in order to properly function with FrameReady's auto zoom feature.

  1. Right-click the desktop and choose Screen resolution.

  2. Click Make text and other items larger and smaller.

  3. Confirm that the size of all items is set to 100% (default). Alternative values interfere with FrameReady's auto zoom feature.

  4. For other Windows versions, please Google for instructions.
