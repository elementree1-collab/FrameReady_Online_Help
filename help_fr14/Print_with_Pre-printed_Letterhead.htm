Print with Pre-printed Letterhead

If you wish to use pre-printed letterhead for your printed customer documents use this method.

  • This procedure will leave the top left corner blank on all customer documents, invoices, letters, envelopes, and the Classic style of gift certificate.

How to Print using Pre-printed Letterhead

  1. On the Main Menu, click the Set Up Data button.

  2. Open the Logo tab.

  3. Be sure there is no X in the checkbox. And remove the logo by backspacing, if there is one present.

  4. Click Done.
