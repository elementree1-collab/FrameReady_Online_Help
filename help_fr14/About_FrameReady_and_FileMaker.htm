About FrameReady and FileMaker

FrameReady is a FileMaker Solution, built using the FileMaker platform from Claris International, a subsidiary of Apple, Inc.

How FrameReady and FileMaker Work Together

  • FileMaker is a Windows and Mac database program from Claris International, a subsidiary company of Apple.

  • FrameReady is a point of sale software package for the picture framing industry.

  • FrameReady and FileMaker are intimately connected; you need both in order to use FrameReady.

Important Things to Know

FileMaker is bundled with FrameReady

  • FileMaker is bundled with FrameReady as per a contractual agreement between Claris International Inc. and Adatasol Inc.

  • FrameReady and FileMaker are intimately connected; you need both in order to use FrameReady.

FrameReady is built with FileMaker

  • FileMaker is a clever program: it integrates a database, a graphic user interface, and a built-in programming language. FileMaker programs are known as "solutions."

  • Because FrameReady is a FileMaker solution, it requires FileMaker in order to run on your computer; FileMaker is bundled with FrameReady.

Available for Mac and Windows

  • FileMaker is available for Mac and Windows operating systems, as well as iPhone and iPad devices.

  • Each computer using FrameReady must have its own FileMaker license.

FileMaker Server is needed to use FrameReady on multiple computers

  • To connect multiple computers and devices, you install FileMaker Server (which we provide) on one of your computers. When using FileMaker Server as your central hub, you can mix and match Mac, Windows, and iOS computers/devices to connect to it and run FrameReady.

FrameReady is an SBA (Solution Bundle Agreement) member of Claris International Inc. This means that we have passed the certification to have FileMaker Software bundled with FrameReady when we sell it. As part of this agreement with Claris, this also means that the copy of FileMaker you receive with your purchase of FrameReady cannot be used to create other programs or solutions. It is restricted to be used solely with FrameReady. Our licensing with Claris is in large volume licenses.
