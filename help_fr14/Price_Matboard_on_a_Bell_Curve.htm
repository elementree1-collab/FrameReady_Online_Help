Price Matboard on a Bell Curve

Uses a Combined Formula and Code Table

  • You can create your own unique price curve for your matboards to ensure the sizes you use the most, or any range of united inches, are priced for added profit.*

  • The price line created by cost x markup + set price has a slight convex curve that can be straightened or arched by adding a specially created Code Table.

  • You can set the arch of your curve to rise by any amount and for the length of any united inch range.

  • The bell curve can be used to cover storage of unused portions for smaller sizes, or waste on mid sizes, or ensuring a better profit on sizes you sell the most.

First, Create the Code Table

  1. In the Price Codes file, create a Code Table using a blank template.

    See: Create a Code Table

  2. Enter your sizes in one United Inch (UI) increments, starting and ending where you want your curve to be.

    In this example it starts at 23UI and ends at 67 UI.

  3. Enter your prices. They should start at zero and end at zero.

  4. Enter the last UI as 200 and enter the price as zero.

    This will cause all sizes between your last price and the largest size to have 0 as the add-on.

  5. Test your pricing using the Price Sampler with the combined formula and Code Pricing option checked. Make sure that the prices go up gradually, in small increments.

Warning: If your prices decrease too quickly or by large amounts, then you will create a price dip – where the pricing of larger sizes will be less than the pricing of smaller sizes.

Note: The amounts in this example are designed to show the curve best in a small diagram, they are not intended for use.

Before checking the box, make sure you have entered:

  • Wholesale cost of item

  • Markup

  • Set Price (optional)

  • Code Table

  • See: Combine Formula and Code Pricing

The same curve can be applied to all your mats by adding this formula to your Pricing Defaults and Options. Or, you can create different curves for different price ranges. Once set, the arch of your curve remains in place as vendors are updated or as you increase or decrease your markups and set prices.

Available for pricing Matboard, Fabric, Mounting, and Glass under the dark blue Pricing tab in the form view screen. This pricing option is also available on the Pricing Options and Defaults screen.

Warning: If the check box is removed, the program will default to price by Code Table only. To price by set price and markup, remove the code table.
