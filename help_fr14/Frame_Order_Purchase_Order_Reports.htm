Frame Order Purchase Order Reports

Access: Main Menu > Create Frame Order

This report provides a list which can be sent to the vendor to order your supplies or used in-house.

Print a Frame Order List for Suppliers

This report may also be emailed as a PDF file or printed for in-house use. This is the simplest way to create your vendor shopping list.

  1. On the Main Menu, in the Work Orders section, click the Create Frame Order button.

  2. Select a range of dates in either Work Order Date or Due Date fields .

    or

    Leave the date fields blank to select all work orders since the last time you placed an order.

  3. Choose to Create Purchase Order at the same time. Or Restore Last Order. Choose whether or not you would like to preview before printing.

  4. Select Proceed.

    A cut list appears first, click Continue.

  5. Click Continue to print.

Print a Purchase Order with Cut List

  • The Create Frame Order button compiles the PO and cut list. The PO can be adjusted on-screen before printing.

  • Identical items ordered by length can be consolidated to a single line entry.

  • A Cut List is also complied for moulding, mats, glass and mounting.

  • Several companies can be batched onto the same PO, e.g. order Bainbridge, Crescent and Larson-Juhl from Larson-Juhl.

How to Print a Purchase Order with a Cut List

  1. On the Main Menu, in the Work Orders section, click Create Frame Order.

    If the date range is left blank, FrameReady finds all items required since the last frame/purchase order was created.

  2. Mark the box for Create Purchase Order.

  3. Select Proceed.

    A Cut List appears first to Print or Cancel. Then the Frame Order appears.

  4. Click Continue to proceed to the Purchaes Order(s).

  5. Choose a vendor by clicking on the Vendor's name.

  6. Adjust or Consolidate order.

  7. Click the Print icon.
