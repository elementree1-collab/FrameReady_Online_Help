Time Cards Sidebar Buttons

 Main Menu > Time Cards > Form View

Time Cards Top and Sidebar Buttons Explained

The following buttons are available only after a successful login:

Printer Icon Button

  • Prints a detailed report of the current time card period.

New Card Button

  • Creates a new time card for a pay period for whichever employee is logged in.

  • Each record represents a specific pay period. At the end of the pay period the employee needs to create a new card.

Logout Button

  • Logs the current user out and returns to a list view of the Time Cards records.

Employee Sidebar Buttons

The following buttons are available after an employee logs in:

Calculate Daily Overtime Button

  • Calculates Daily Overtime

Print Options Button

  • Set Pause on Preview and/or Show Print Dialog Box.

Change Login Password Button

  • Change password for the currently logged-in account.

  • Requires confirmation of the new password.

  • Password hint available (not required) and is visible to any users.

Administrator Sidebar Buttons

The following buttons are available after the admin logs in:

New User Button

  • Create a new user (employee) account.

Print Report Button

  • Generates and prints employee summary reports for a date range.

  • The report includes Employee Name, ID, Regular hours, Overtime Hours, Total Hours.

Enable User Button

  • When enabled, the employee name appears in the list view.

Disable User Button

  • Reverses the former action.

Create Vacation or Holiday Line Button

  • Creates a line item(s), preset for an 8 hour day, for one of several day types over a custom range of days.
