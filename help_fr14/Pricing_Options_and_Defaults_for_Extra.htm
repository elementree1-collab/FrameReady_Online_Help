Pricing Options For Extra

Price Codes File > Extra Group (Side Bar Button)

Sometimes you may wish to list items and have no prices associated with them, e.g. wire hanging device, sawtooth hanger, shrink wrap, reverse bevel. The Extra Group is a good place for these.

  • You may also add items with no associated price, e.g. wire hanger, shrink wrap, reverse bevel.

  • These "no cost" items serve to inform the framer of items or labor necessary for this project.

You Can Price Extra Items By

When using this Group, there are three pricing considerations to take into account:

Set Price (Fixed amount per item)

  • Extras can be priced by a single charge or Set Price for items that are not affected by the size of the frame.

    Retail Price =  Set Price  

    For example, custom mat corners where the size of the mat has no bearing on the time you would spend laying out and executing the cuts.

Code Table

  • Extras can be priced by a Code Table cross references the UI (or UCM) with a Retail Price.

    Retail Price =  Code Table  

  • Code Tables work best for items sold by fixed sizes or if you are trying to match an existing price chart. The entire code chart can be increased or decrease by percentage or you can manually adjust the price for each size on the chart.

Price Per UI

  • Extras can be priced by a straight Price per UI.

    Retail Price =  Price per UI  

    For example, a charge for doing an inlay mat.

 

 

Item Field

  • Enter the name of the Item, e.g. Brass Corners 

  • Items in this Group appear alphabetically in the drop-down list on the Work Order screen.

  • Take note of how you want the item to appear in the list. If ‘Brass’ written first, then all the Brass items will be grouped together. However, if ‘Corners’ is written first, then all of the Corners will be listed together, e.g. Corners - brass 2 inch, Corners - gold 2 inch, etc.

Order Number Field

  • The manufacturer’s number which is used when the item is reordered.

  • The Order Number appears on the Purchase Order.

Remember: It is the Item # that appears in the drop-down list on the Work Order screen not the Order #.

Cost Field Field

  • This field is used to identify the wholesale cost you paid for this item.

  • It is added to the total wholesale cost of a Work Order, however, it is not used in any calculations to determine the retail price of this item.

Thickness Field

  • Used by the Work Order to calculate the overall thickness of the job and whether it exceeds the rabbet depth.

Supplier Field

  • Used to enter the name of the supplier or manufacturer. 

Tip: If there is no supplier or if you are unsure, then select In House from the drop-down list.

Set Price Field

  • This field will charge a fixed dollar amount (e.g. Brass Corners $10.0) regardless of the size of the piece.

Code Field

  •  Allows you to use a Code Table for pricing for any of these items.

Price Per United Inch Field

  • Calculates the retail price by taking the UI and times it by whatever amount is in this field.

Note: The Price Per United Inch and the Set Price can be combined to calculate the price by size then add a fixed amount to the total (e.g. Double V-groove .15 per UI + 10.00). You may also price any of these items with a Code table.

Reset Size Defaults Button

  • This button enters or re-enters the united inch values to enable the price sampler to the right of the UI column.

  • Use the Price Sampler to gauge how your pricing will work with different entries or combination of entries.
