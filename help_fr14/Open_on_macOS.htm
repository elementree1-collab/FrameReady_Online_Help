Open FrameReady on a Mac (Single User)

If you have multiple FrameReady computers, then see: Open on Guest or Client

How to Open FrameReady in macOS

  1. On your Desktop, double-click the FrameReady alias icon.

Is the icon missing? See below!

How to Add a FrameReady Icon to the Mac Desktop

Tip: FrameReady is located in your Home folder.

  1. Open the Finder program.

  2. In the file menubar, click Go > Home or press Shift + Command + H

  3. Locate and double-click the FrameReady folder.

  4. Locate the file named FrameReady.fmp12, single-click the file and choose Make Alias from the File menubar.

    A shortcut icon (an alias) appears.

  5. Move the alias to your Desktop or to the Dock, whichever you prefer.

  6. To change the icon's artwork, see: Change the Desktop Shortcut Icon
