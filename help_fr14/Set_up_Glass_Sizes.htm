Set up Glass Sizes

Main Menu > Work Order section > Options tab > More Options button > WO Defaults tab > Enter Default Glass Sizes

OR

Work Orders > Perform (menubar) > Setup Options > Default Glass Sizes

This is the only place in FrameReady where you may set your default glazing lite sizes.

How to Set the Default Glass Sizes

  1. On the Main Menu, in the Work Orders section, open the Options tab and click the More Options... button.

  2. The Work Order Options window appears; open the Work Order Defaults tab.

  3. Click the Enter Default Glass Sizes... button.

  4. The Default Glazing Sizes screen appears.

  5. Glass sizes entered into this chart are the basis for calculating the best/optimal lite size to be used.

    When preparing a Work Order, the suggested glass size appears in green text, above the Frame1 field, i.e. 16x20

  6. Enter the sizes (X and Y columns) you normally stock, in order from smallest to largest.

    Backspace-out any sizes you do not carry.

    FrameReady calculates the required lite based on these entries, from smallest to largest, e.g. 8 x 10, 24 x 30, etc.

  7. Click Done.

    Once your chosen lite sizes have been set as defaults, only those sizes can be recommended in the top left corner of the components of the Work Order.

Set the Default Glass Sizes from Work Orders - Menubar

You can also use the "Perform00000" menu in the file menubar.

  1. In the file menubar, click Perform.

  2. Click Setup Options and then select Default Glass Sizes.

  3. The Default Glass Sizes screen appears.

  4. Glass sizes entered into this chart are the basis for calculating the best/optimal lite size to be used.

    When preparing a Work Order, the suggested glass size appears in green text, above the Frame1 field, i.e. 8x10

  5. Enter the sizes (X and Y columns) you normally stock, in order from smallest to largest.

    Backspace-out any sizes you do not carry.

    FrameReady calculates the required lite based on these entries, from smallest to largest, e.g. 8 x 10, 24 x 30, etc.

  6. Click Done.

    Once your chosen lite sizes have been set as defaults, only those sizes can be recommended in the top left corner of the components of the Work Order.
