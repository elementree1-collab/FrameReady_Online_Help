Set up a Receipt Printer

Important: The Print Receipt icon in the Invoices file is specifically designed to work only with receipt printers.  The layout is not formatted for use on Letter (8.5 x 11) paper.

Set Up for Windows & Mac

With a Receipt Printer using Windows

  1. Open FrameReady with the level4 password.

  2. On the Main Menu, in the menu bar, click Perform and choose Restore Full Menus.

  3. Caution: You now have access to FileMaker controls.

User Name Set Up

  1. In the menu bar, click Edit and choose Preferences.

  2. The Preferences window opens.

  3. Take note of the User Name field: it should be  Register1  

    If it isn’t so named, then rename it accordingly. What this does is identify the computer and corresponding receipt printer which is attached to the computer on the network.

  4. Click OK to close the window.

Receipt Printer Set Up

  1. On the Main Menu, in the Invoices section, open the Options tab.

  2. Click the More Options... button.

  3. Open the Print Options tab.

  4. On an Invoice, there are two print buttons:

    1) the first prints an 8.5" x 11" invoice
    2) the second prints a 3" receipt.

    If you wish both print buttons to only print a receipt, then set Only print receipt to Yes, otherwise leave as No.

  5. Click Done.

Script Set Up

  1. In the menu bar, click Perform and choose Restore Full Menus.

    If the Perform menu does not appear, then full menus have already been restored.

  2. Click the Invoices icon.

  3. In the menu bar, click Scripts and choose Script Workspace.

  4. The Script Workspace opens. In the left column, scroll to the item labelled Print Receipt.

  5. Single-click Print Recieipt to see the script.

    Note: Do not click the checkbox.

  6. In the right-hand pane, double-click on the 7th line that says, Print Setup.

  7. The Print Setup window appears.

  8. Select your receipt printer in the printer.

    If you do not see your receipt printer, then you need to install the appropriate print driver before proceeding.

  9. Select the correct paper size for the printer (usually 72mm x Receipt).

  10. Click OK to close the Print Setup window.

  11. Next, look for the script line that ends with the user name of the computer you are configuring, for example  Else If [Get ( UserName ) = “Register1”].

    Directly below that line, double-click the Print step.

  12. The Print Setup window appears. In the Print dialog box, select the receipt printer that is connected to the computer.

  13. Select the number of copies to be printed (if more than one).

  14. Click OK to close the Print dialog window.

  15. Close the Script Workspace window.

  16. A Save dialog box appears.

  17. Click Save All.

    The FrameReady Invoice window appears.

  18. Run a test print by clicking on the Invoice Printer icon.

    If the test is okay, then return to the Main Menu, exit FrameReady, and re-open with the appropriate user name and password.

    If the print test fails, then follow the steps again or call tech support. If the print is blank, check that the thermal paper has been installed correctly.

Repeat for each computer that has a receipt printer attached to it.

Set Up for Macintosh

With a Receipt Printer using a Macintosh.

  1. Open FrameReady with the level4 password.

  2. In the menu bar, click Perform and choose Restore Full Menus.

  3. Caution: You now have access to FileMaker controls.

User Name Set Up

  1. In the top menu bar, click FileMaker Pro and choose Preferences.

  2. The Preferences window opens.

    Take note of the “User Name”. It should be “Register1” or “Register2” or “Register3”. If it isn’t so named, then rename it accordingly. What this does is identify the computer and corresponding receipt printer which is attached to the computer on the network.

  3. Click OK.

Receipt Printer Set Up

  1. On the Main Menu, in the Invoice section, open the Options tab.

  2. Click the More Options… button.

  3. Open the Print Options tab and make sure that Allow for use of receipt printer is set to Yes.

  4. Click Done.

Script Set Up

  1. In the menu bar, click Perform and choose Restore Full Menus.

    If the Perform menu does not appear then full menus have already been restored.

  2. Click the Invoices icon.

  3. In the menu bar, click Scripts and choose Script Workspace.

  4. Look for the line that says, Print Receipt and double-click (or select the line and click the Edit button).
    Note: Do not click the check box.

  5. In the right-hand pane, double-click on the 4th line that says, Page Setup.

  6. Select your receipt printer in the printer drop down menu.

    If you do not see your receipt printer, then you need to install the appropriate print driver before proceeding.

  7. Select the correct paper size for the printer (usually 72mm x Receipt).

  8. Click OK.

  9. Look for the line that ends with the user name of the computer you are configuring (e.g. Else If [Get ( UserName ) = “Register1”]). Double-click the Print step that is directly below the line.

  10. In the Print dialog box, select the receipt printer that is connected to the computer.

  11. Select the number of copies to be printed (if more than one).

  12. Click OK, and then click OK again.

  13. Click Edit Script.. close button (X). Save changes.

  14. Click Manage Scripts close button (X).

  15. Run a test print by clicking on the Invoice Printer icon.

    If the test is okay, return to the Main Menu, exit FrameReady and re-open with the appropriate user name and password. If the print test fails, then follow the steps again or call tech support.

  16. Repeat for each computer that has a receipt printer attached to it.
