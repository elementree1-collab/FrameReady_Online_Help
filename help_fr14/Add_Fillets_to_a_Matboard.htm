Add Fillets to a Mat

Main Menu > Work Orders

This article deals with entering fillets into mats as opposed to using them as a moulding embellishment.

(see entering a fillet in a moulding).

How to Add Fillets to a Mat

  1. Enter all mat board choices into the Mat fields first.

  2. Click the underlined Fillet button.

  3. The details screen appears, showing entry field for up to 7 fillets (determined by the number of mats you have entered). This is also where you enter Bevelled Accents™ and Faux Fillets™.

  4. Enter the fillet number in the field(s) where you would like it to appear.

    Entry can be done by bar code scanner, search button or entry of exact fillet #. suffix. Be sure to verify the fillet size provided by the vendor before leaving the screen. This screen is also where you would adjust the Bevelled Accent™ size. The top mat will be reduced by the width of the fillet.

  5. If necessary, click the Adjust margins of top mat button to enter the size of the top mat/top margin (the size of the other margins will be adjusted accordingly).
