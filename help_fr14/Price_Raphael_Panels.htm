Price Raphael's Panel Liners

Raphael's Panel Liners and Custom Wrapped Mats can be priced accurately in FrameReady.

  • These products are sold to the custom framer by the United Inch; the cost imported into FrameReady is a cost per United Inch (unlike matboard which has a cost per sheet).

  • These products belong to the Matboard Group and function in a Work Order the same as a matboard.  

  • Once imported to your Price Codes, the framer needs to set up a dedicated record in the Pricing options and Defaults section.

How to set Pricing Option and Defaults for Raphael's Panel Liners

  1. Go to Price Codes > Matboard > Matboard Pricing Tab > Pricing Options and Defaults button.

    This will take you to a new screen where your default pricing formulas are stored.

  2. Click on the New Record button at the top center of the screen.

    A new blank record is created (at the bottom of the list).

  3. A cursor should now be blinking in the Markup field in the lower left corner. Enter in the markup you wish to charge,  e.g.  2,  2.5,  3,  whatever you think is fair.

  4. Click in the Set Price field (directly to the right) and enter a set price.

    A set price is the dollar amount added to the calculated United Inch price.

    ((Cost per United Inch x Markup) x United Inch of piece + Set Price = Retail Price)

Tip: You could also have a formula that calculates a minimum charge based of the united inch cost. (For example, Raphael's has a 24 united inch minimum charge. Your formula then, for the set price, could be "Cost * 24" (no quotes). That way your minimum cost will always be covered.)

  1. Click in the Minimum Price field and enter a minimum price.

  2. If you are using a Code Table, then click in the Code field and enter it.

  3. Click the radio button beside United Inch (the last item in the list: not to be confused with the first United Inch Area).

Note: if you do not see a 6th circle, please call the FrameReady Team for support.

  1. The Combine Formula and Code Pricing check box is used in special circumstances where neither a formula nor a code table will work -- but a combination of the two will.

    An example of this is a fabric wrapped mat where the fabric is priced by the linear yard and the mat or substrate on which it is wrapped is priced by a code table.

  2. In the Show Defaults Only column, chose on the Default checkbox.

    Additional options appear.

  3. Click the Matboard checkbox.

  4. From the Supplier drop-down, select Raphaels_Panels or Raphaels_Mats.

  5. Click the Apply to Group button for this new record.

    A new screen appears.

  6. The Apply formula to identified product or found set screen allows you to clarify which records will be updated.

    • The Group will already be chosen as Matboard.

    • Optional. If you specified a Supplier, it will auto-filled.

    • Optional. You can apply this formula to items of certain dimensions, e.g. 32x40

    • Optional. You can omit items belonging to a specific category, e.g. Misc

    • The Markup, Set Price, Minimum Price and Code that you may have added earlier will be reflected in this screen. Optionally, you may override those values here. Note that the original value, not the override, will be recorded.

  7. Click Apply to Found Set if you wish to change all items in the specified Group.

  8. Click Apply to Selected Criteria if you wish to change only items that match the values specified in the Group, Supplier, and/or Dimensions fields.

Note: Once this formula has been set up, it will be used for any future imports.
