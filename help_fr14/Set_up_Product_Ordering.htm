Set up Product Ordering

You can set Products to be included on Purchase Orders using a reorder threshold or a keep on hand value.

How to Set Up using Reorder Threshold

  1. Do a find for the Product you are setting up.

  2. Enter the actual number of items into the Qty on Hand field.

  3. If you want FrameReady to automatically add this Product item to a Purchase Order when your on hand inventory drops below a certain number, then enter that threshold number into the Reorder Threshold field.

    Do not use a value of 0 (zero).

  4. In the Reorder Qty field, enter the number of items that should be added to the Purchase Order.

How to Set Up using Keep on Hand

  1. Do a find for the Product you are setting up.

  2. Enter the number of items into the Qty on Hand field.

  3. In the Keep on Hand field, enter the number of items you always want to have available.

  4. The Reorder Qty automatically calculates the number of items that will be added the next time you create a Product Purchase Order.

How to use the Minimum Order Field

  1. Some suppliers require that you order a minimum number of items. Enter this number into the Minimum Order field.

  2. If the minimum order is greater than the reorder quantity, then FrameReady uses the minimum order instead.
