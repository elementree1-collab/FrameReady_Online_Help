Code Table Screen Explained

The Code Table screen manages the items are being priced by that table. Once the Code Table is created, all you do is link your item(s) to it.

Create a New Table Button

  • Creates a new Code Table based on your selection of an Incremental Template and choice of name.

Adjust All Tables by % Button

  • Increase or decrease all tables (as found in the Code Table drop-down menu) by the percentage you wish.

  • Use decimals when entering percentage amount.

Adjust Current Table by % Button

  • Increase or decrease only the current table by the percentage you wish.

  • Use decimals when entering percentage amount.

Duplicate Table Button

  • Duplicate your choice of Code Table using a new name. This offers a quick way to create highly customized pricing structures by duplicating an existing table then adjusting it by a percentage.

Update Vendor Codes Button

  • Requires an active Vendor Subscription from Adatasol Inc.

  • See also:  Manual Updates with Vendor Subscription

Printer Button

  • Prints out the current Code Table in two columns per page showing UI / XY and price.

Delete Table Button

  • Choose the Code Table to be deleted. A second dialog box reports the number of records in the Code Table and confirms that you wish to delete the table. Once a table has been deleted, it cannot be retrieved. However, the deleted Code Table identifier, e.g. AH, can be reused to create a new table.

Code Table Dropdown

  • The Code Table title field identifies the code table currently being viewed. To select another, click in the field for a drop-down list.

Go to Source Button

  • View the data in FileMaker Pro table view format. Includes additional fields.

X & Y Columns

  • X & Y fields represent the size increments for this table.

    These sizes usually follow set frame or glass sizes but can also be set arbitrarily depending on what the table is to be used for. If left blank, FrameReady uses the UI fields. When filled in, the XY fields have priority. For example, a size of 15×21 prices at 18×24 rather than at 36 UI because 18×24 is the closest fit.

Note: when entering the XY values, always enter the smaller value in the X field. Also the UI fields auto-fill with the combined value of the XY fields.

United IN Column

  • The UI measure. Can be modified or deleted as desired from this screen.

Square IN Column

  • The square increments corresponding with a specific vendor’s price chart.

  • In order for this to be activated you must tick the checkbox in the Code field in the item's Pricing tab.

Price Column

  • The amount to be charged for either the UI field or the XY fields to which it corresponds. The amount can be changed by clicking on the field and typing over the existing amount.

  • To change all of the prices in a Code Table use the Adjust Current Table by % button.

Note Field

  • Note field is your opportunity to enter something to help you identify the usage of the table, e.g. 25 cents per UI, Conservation Clear, Regular Mats, etc.

  • Displays when you click on the Code field in the Price Code screen (all screens except moulding).

Date Field

  • Date field should be used to identify when the pricing took effect or was modified. This will serve as a reminder to update your pricing on a regular basis.

Items using this Table Fields

  • Not modifiable.

  • Item number, Description, Category fields show the items currently using the Code Table for pricing. If the area is blank, then no items are being priced by this Code Table.
