Recover a Damaged File

Note: Data files can be recovered in Windows and Mac OS X.

  • Power failures, hardware problems or other factors can damage a FrameReady file.

  • If a file is damaged, then when you open the program FrameReady alerts you to the file(s) that need to be recovered.

  • There are two types of files in your FrameReady program.

  1. If the file is a Data file (Data01, Data02, Data03, Data04 or Data05), then use this Recover Method below.

  2. If it is any other file that is damaged (Main Menu, Invoice, Work Order, etc), then recover the files from a recent backup.

Warning: The Repair Method replaces the damaged file with a clean copy from the original FrameReady installer. This is a feature built into Windows.

If you have made any customizations to that file, then they will be lost using the Repair Method. If this is the case, then use this Recover Method or recover from a backup copy of FrameReady.

See also: Restoring from a backup

How to Recover a Damaged Data File in Windows (Single Installation)

If you have FileMaker Server, then see: Recover a Damaged File (Server)

  1. Close FrameReady and FileMaker Pro.

    If you have multiple computers, then close Frameready and exit Filemaker on all Guest computers.

    If you keep getting popup error messages and/or open file boxes, then click Cancel until the program closes (there will be many Cancel buttons, but FrameReady will eventually exit).

  2. Open File Explorer using the Windows + E keys or using the shortcut in the taskbar.

  3. Navigate to your FrameReady folder.

    By default, FrameReady is located on Local Disk (C:) in the Users\[User name] folder.

  4. Select the damaged data file and rename it:

    Right-click the file and choose Rename.
    Add the word “old” to the existing file name, e.g.  Data01  becomes  Data01old  and press Enter.

    If the files have a .fmp12 extension showing then make sure old is added before the .fmp12 -- i.e. Data01old.fmp12.

  5. Close File Explorer.

  6. Open FileMaker Pro, not FrameReady, from the Desktop shortcut.

    If you do not have a shortcut, you can find the program in C:\Program Files\FileMaker\FileMaker Pro ##\FileMaker Pro.exe.

    If FileMaker Pro opens to the Launch Center, then click Close.

  7. In the file menubar, click File and choose Recover.

  8. The Select Damaged File dialog appears. 

    Navigate to your FrameReady folder.

    FrameReady 11 Default location is C:\Users\[Username]\FrameReady 11

    FrameReady 10 and older is located C:\SoftTouch Solutions\FrameReady ##

  9. Select the damaged file, e.g.  Data01old  and click the Select button.

    In the File Name field, notice that FileMaker has added the phrase "Recovered" to the file name.

  10. Click in that File Name field and backspace out the word Recovered and old so that the file is saved with it’s original name, e.g.  Data01old Recovered  becomes  Data01  and press Enter

    If the files have a .fmp12 extension showing make sure you keep the .fmp12 - e.g. Data01.fmp12.

  11. Click Save.

    Wait for any progress bars to finish, a message appears when recovery is complete.

  12. Click OK.

    Repeat steps 4-12 for any other damaged files.

  13. Close FileMaker Pro and re-open FrameReady.

  14. Backup your files!

How to Recover a Damaged Data File in Mac OSX (Single Installation)

If you have FileMaker Server, then see: Recover a Damaged File (Server)

  1. Close FrameReady and FileMaker Pro.

    If you receive error messages and open file boxes, then click Cancel until the program closes.

  2. Open Finder using the dock icon and go to your FrameReady folder.

    FrameReady 11 default location is Macintosh HD\Users\[Username]\FrameReady 11

    FrameReady 10 and older is located on the Macintosh HD in the Applications folder.

  3. Select the damaged data file and press Return.

    Add the word “old” to the existing file name, e.g.  Data01  becomes  Data01old  and press Return.

    If the files have a .fmp12 extension showing then make sure old is added before the .fmp12 -- i.e. Data01old.fmp12.

  4. Close Finder.

  5. Open FileMaker Pro, not FrameReady, from the desktop shortcut or alias.

    If you do not have an alias, you can find the application in Macintosh HD\Applications\FileMaker Pro ##\FileMaker Pro.app.

  6. If FileMaker Pro opens to a quick start screen, then click Cancel.

  7. Go to the File menu and select Recover.

    A file dialog appears.

  8. Navigate to your FrameReady folder.

    Default location is Macintosh HD\Applications\FrameReady ##

  9. Double-click the damaged file.

    FileMaker adds the term Recovered to the file name in the Save As field.

  10. Click in the Save As field and backspace the word Recovered out so that the file is saved with it’s original name, e.g.  Data01 Recovered.fmp12  becomes  Data01.fmp12  .

  11. Click in the Where drop-down list and select Desktop.

  12. Click Save.

    Wait for any progress bars to finish, a message appears when recovery is complete.

  13. Click OK.

    Repeat steps 4-12 for any other damaged files.

  14. Quit FileMaker Pro.

  15. Open the Macintosh HD and drag all recovered files from the Desktop into your current FrameReady folder.

    A prompt that the files already exist appears.

  16. Click Replace.

  17. Re-open FrameReady.
