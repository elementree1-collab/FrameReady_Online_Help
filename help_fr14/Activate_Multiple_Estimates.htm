Activate Multiple Estimates

Work Order  > Form View

When you have created several estimates for a customer on the same day, you can later activate all them at once -- instead of one by one.

How to Activate Multiple Work Order Estimates

Tip: This procedure only works for Estimates created on the same day for the same customer.

Tip: If you want to include an Estimate with a different date, then give all Estimates the same Job #. When posting to an Invoice, all Work Orders with the same Job # will be posted to the same Invoice.

  1. Locate any of the customer's Estimates.

  2. Click the green Activate button (located on the Order tab in Form View).

  3. If more than one Estimate was created on the same day for this customer, then a list of those Work Orders appear.

  4. To remove an Estimate from the list, click the associated Omit button.

  5. Otherwise, click the Activate All button.

  6. FrameReady loops through the Estimates and requires that you choose between using the current price or updating to the latest pricing.



    Click Saved or Update.



    Click Saved or Update.

  7. After you have made a selection for all listed Estimates, the List View screen shows all activated Work Orders.

    To create an Invoice (and take a payment), proceed as usual with the Post to Invoice button. FrameReady will find all orders for the same customer created on the same day, or all orders with the same Job #, and post them to one Invoice.
