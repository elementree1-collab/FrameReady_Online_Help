Set up Network Information

 Main Menu > Setup Data > Network tab

Use this section to enable FrameReady's network features.

Setup Data - Network tab Explained

Enter Network Key Button

  • A Network Key will be provided to you by Adatasol when you are using FrameReady on more than one computer.

Set Files to Single-User Button

  • If you are not networking and you receive a message when you open the program that says “Filemaker cannot share file because file sharing is turned off” then click this button to set all files to Single-User.

Set Files to Multi-User Button

  • No longer applicable.

  • Click this button to set FileMaker Pro and all the FrameReady files to multi-user when you are setting a network.

What's My IP Address Button

  • If this is a stand-alone installation of FrameReady, then clicking this button displays a single IP address.

  • If this is a Client/Guest computer, then clicking this button will display the IP address of this computer as well as the Server computer's IP address.

Enable Phone Capture App

  • A specially-designed app is available for use on your iPhone or iPad.

  • See: iPhone and iPad App
