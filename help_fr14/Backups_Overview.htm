Backups Overview

After many years of hearing horror stories from FrameReady clients, we cannot emphasize strongly enough the need to get into the habit of making daily backups.

Built-in Backups

  • FrameReady includes backup capabilities; we recommend you use them exclusively.

  • FrameReady is set up in two different ways, Single Computer users and FileMaker Server users.

Single Computer Users

  • Use the manual Backup Now feature in FrameReady.

  • You can tell FrameReady which folder to save the backups. 

  • See: Set up Single User Backups

  • See: Make a Single User Backup

FileMaker Server Users

  • Use the FileMaker Server Admin Console to schedule when backups happen.
