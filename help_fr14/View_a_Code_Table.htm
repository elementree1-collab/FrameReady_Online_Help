View a Code Table

The Code Tables button appears in two locations in the Price Codes file on Form View screens for Moulding, Matboard, Mounting and Glazing

Code Tables Sidebar Button (not available in Moulding)

To go directly to the Code Table file, as well as locate additional code tables, click the Code Tables button (left sidebar). Available in all groups except Moulding.

When an item is priced by a Code Table, the name of table is displayed at the top of the screen, e.g., This item is being priced by: Code Table [Name].

If the item you are viewing is priced by a Code Table, it will go directly to the Code Table used to price that item when you click on the Code Tables sidebar button. If the item is priced by means other than a Code Table, the last previewed Code Table will appear.

Price Codes > Code Tables Sidebar Button (except Moulding)

Code Tables Tab in Pricing Tab (except Moulding)

Available in all groups except Moulding.

You can also access the Code Table used specifically by an item.

Price Codes  > Pricing Tab > Code Tab

The name of the Code Table also appears in both the field identifying the Code, e.g. Code = MT02, and in the Selection field, e.g. "MT02"

Click the Code Tables button to continue.

Code Tables for Moulding - Frame Pricing Tab

A Code Table is used to add shipping or joining fees to a moulding item.

Code Tables can also be used to cover additional expenses of Shipping Costs or a Join Fee.

Price Codes  > Frame Pricing Tab > Minimum & Surcharges

The name of the Code Table will appear in the Ship Code field if on has been selected by clicking on the down arrow on the right side of the Ship Code field. 

If a table is named in the Ship Code field, clicking the Code Tables button will take you directly to that Code Table where you can make changes. To view the pricing structure without making changes, click on the Show Code button.

Code Tables for Canadian Moulding - Code Pricing Tab

A code table is used to generate a Retail Price based on the supplier’s Retail Price List or Matrix. These codes are identified by the supplier and are updated on the Main Menu > Update Vendor Pricing > Vendor Codes Tab.

Price Codes  > Code Pricing Tab

The name of the Code Table will appear in the white field below Code =. The code name will be surrounded by double quotations. This is normal. When a Code is identified in the field, the same name (without the quotations) will appear in the title above the field. 

If a Code Table is named in the Code = selection field, then clicking the Code Tables button will take you directly to that Code Table where you can make changes. To view the pricing structure without making changes, click on the Show Code button.

Pricing with this code only takes affect when a checkmark appears in the “Check box to use Code Pricing” box. If the box is checked, a message appears at the top of the screen.

When a Code is used to price a moulding in this tab, prices will not be visible in the Frame Pricing tab. This is because the Code Pricing is the Retail Price and takes precedence over all other methods of pricing. However, the Ship Code can be used in conjunction with the Vendor Matrix Code. Eg. LW12
