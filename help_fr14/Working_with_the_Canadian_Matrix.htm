Working with the Canadian Pricing Matrix

Main Menu > Price Codes

If you live in Canada and order Joined frames, then you need to use the supplier’s Matrix retail price chart.

  • If you live in Canada and order Joined frames, then you need to use the supplier’s Matrix retail price chart. These are available in FrameReady as Codes.

  • You do not need to use the Matrix if you order length moulding; but you can use it if you wish to do so.

What is a Supplier Pricing Matrix?

  • The matrix is a supplier’s retail price chart, based on a Code, assigned to a moulding profile.

  • For example, Larson Juhl has a Code assigned to each moulding (1, 2, 3, etc.) and a retail price (e.g. $62, $67, etc.) for each group of united inches, (e.g. 18, 20, 22, etc.). The retail price is usually 2x the amount on the wholesale cost matrix.

  • In FrameReady, a Code contains the United Inch measurements and the retail price for that size range.

Using Code Pricing on Moulding Records

  • Open the Code Pricing tab. An X appears in the box if the Code Pricing is turned on.

  • The Code Pricing overrides all other pricing options and cannot be combined with any other pricing options under the Frame Pricing tab.

  • You can check the checkbox for a single moulding, click the Select All  Codes for [vendor] Only button, or click Select All Codes for all moulding records which have a Code assigned to them.

  • To see the Code details, click the Show Code button.

  • The date of the code you are currently using appears at the top of the popover window. 

Make sure that you have the most recent update for each Vendor 

  1. On the Main Menu, in the Price Codes section, click the Update Vendor Pricing button.

  2. When the Vendor window appears, open the Vendor Codes tab.

  3. Click the underlined Update Vendor Codes text button.
