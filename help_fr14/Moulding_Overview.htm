Before You Begin...

We recommend that you first customize your materials list to remove unwanted items. You can always come back later and tweak your prices; so don’t worry about making them absolutely perfect the first time.

Moulding Is Priced By Length

In FrameReady, items in the Moulding Group are priced according to their length; that is, how much moulding is required on a Work Order.

You can price it by Cost per Foot

  • Moulding can be priced by a Formula that uses a Cost per foot/meter (length, chop, or join cost), multiplied by a Markup, and then with a Set Price added on.

    Retail Price =  Cost per foot  x  Markup  +  Set Price 

You can price it by Price Per UI

  • Moulding can be priced by a Formula that uses a Price per united inch (or united centimeter), multiplied by a Markup.

    Retail Price =  Price per UI  x  Markup  

You can price it by Code Table

  • Moulding can be priced by a Code Table (provided by a vendor) which corresponds to a price matrix (primarily Canadian vendors).

    Retail Price =  Code Table  

What Are Formulas?

  • See: Pricing Formulas for Moulding

Tip: Given the vast number of options in terms of Formulas and how they can be applied, you may want to just give yourself a KISS (Keep It Simple Sweetheart).

If you are a new FrameReady user or just starting out in the business, then you can use the default Formulas as a temporary starting point. However, as time goes on, we strongly recommend that you add or modify your Formulas.
