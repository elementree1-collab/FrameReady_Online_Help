Prepare a Consignment Order

Main Menu > Outbound Consignments

This is for when your Product items are leaving your shop and going into someone else's care / somewhere else for sales.

Processing Items to go Out on Consignment

How to Create an Outbound Consignment Order

  1. Open the Outbound Consignments file and click the New Consignment button.

    The Consignment Line Item Entry screen appears, with the cursor flashing in the Item Number field.

  2. Enter the Item Number of the first Product item to be consigned out, or use the magnifying glass icon to search the Product file.

    The item number can be typed in or scanned with a bar code reader. If scanned, the cursor will move to the Item Number field in the next line. If typed, press Tab or Enter and the cursor will move to the next line.

Note: There is no quantity field. A quantity of one is assumed for each line. If you have several pieces of the same item to be consigned out, then a line will need to be created for each item. The reason for this is to allow each item to be processed differently, e.g. sold, returned, out.

  1. Add the Consignee to the order using the ID# or the Name or Company search buttons.

  2. If additional items need to be entered later, then click the Done (Leave on Hold) button.

    The screen returns to the form view; additional fields (non-line item fields) may be filled in.

  3. When all items for this Consignment Order have been entered, click the Done (Process Out) button.

    A dialog box appears asking you to confirm that the consignment is complete and ready to be processed out.

Caution: Once processed, the consignment cannot be modified.

  1. Click the Printer icon button to print a copy of the order to be given to the Consignee.
