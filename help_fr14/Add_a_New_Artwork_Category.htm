Add a New Artwork Category for Work Orders

Main Menu > Work Orders

Manage the list of artwork categories to reflect your business needs.

How to Edit or Add a New Artwork Category for Work Orders

  1. To add a new Artwork Category, i.e. sports Jersey, click into the field and choose Edit... at the bottom of the list.

  2. The Edit Value List dialog appears.

  3. In order for items to appear alphabetically, you must manually enter the at the correct position (the list is not automatically alphabetized). 

  4. To create a division line in the list, enter a hypen character  -  

  5. To add a "one-off" Artwork Category to the current Work Order only, click into the field and choose Other... near the bottom of the list.

    Enter your one-off category; it will not be added to the master list. This feature can help keep your list manageable. Click OK.

  6. Click the OK button to close the window.

    The keyword(s) you enter appears in the drop-down menu and may then be selected.

Tip: Click Other... (above Edit...) to add an Artwork Category for the current Work Order only; it will not be added to the list. This feature can help keep your list manageable.
