Gift Certificate List View

The List View displays all Gift Certificates and Store Credits which have the No radio button marked. You may print this list using Print List.

Tip: You do not need to manually mark the Redeemed radio button. As soon as you Enter A Payment on an Invoice and choose Certificate/Store Credit, FrameReady sets it to Yes.

Gift Certificate List View Explained

Find All Button

  • Shows every certificate, gift card and store credit ever created.

Unredeemed Button

  • Shows only unredeemed certificates, gift cards and store credits.

Print List Button

  • The current list will be sent to the printer.

Sell Gift Card Button

  • Opens a dialog box requiring a Gift Card Number and the Value of the Card; a new Invoice appears in Line Item Entry mode.

New Gift Certificate Button

  • Triggers the Gift Certificate Form View.

  • See also: How to Create a Gift Certificate

Column Headings

  • Sort each column by clicking on each underlined word, i.e. Serial#, Sold To, Given To, Amount, Redeemed, Category.

For instructions on how to redeem Store Credit or a Gift Certificate on an Invoice, see How to Redeem a Store Credit

Footer Area

  • Displays record count and found set.

  • Displays column totals (level3 and level4 only).
