Find Not Verified Items

When doing vendor pricing updates FrameReady can show a list of Not Verified (or possibly discontinued) items. Once you have completed a vendor pricing update and marked not found records as Not Verified, FrameReady displays those items in a list format.

  • See also: How to Manage Discontinued Items

How to Find Not Verified Items

  1. From the Main Menu click the Find Price Code Item button.

  2. In the find screen, enter your search criteria:

    Choose your Supplier.

    In the Validation field select Not Verified. 

    Optionally, you can use the Validation Date to limit the search results, e.g.  ..2014  will find only items with a validation date prior to and including 2014.

  3. Click the Perform Find button.

  4. Click the Print List button, top center.

  5. A dialog box appears, asking which type of list to print. There are three different types of printouts you can select from:

    • Retail Price – which lists the Item number, Description of moulding (as provided by manufacturer), Supplier, and retail price per foot. It fits approx. 32 items per page.

    • Items Only – which has 3 columns of item number only. This option may make it more difficult to find your sample.

    • Detailed – fits 12 items per page and provides all pricing and size info as well as item, description, barcode, group and validation date.

  6. Choose one.

    The Sort dialog box appears.

  7. The default sort is by item number. Click Sort or Cancel if you want the list to stay as it appears.

  8. A print preview of the document appears.

  9. Click the Continue button in top right corner.

    The Print dialog box appears.

  10. Click Print.

FrameReady 10+

To use the underlined Update All Vendors button (located on the New Updates or My Vendors tab) instead:

  1. Click the Update All Vendors button.

    This only applies to vendors marked as "Process Unattended - Yes" in the Options pop-over.

  2. At the conclusion of the update go to Price Codes > Find.

  3. In the Validation field, select Not Verified.

  4. Repeat steps 3-7 above.
