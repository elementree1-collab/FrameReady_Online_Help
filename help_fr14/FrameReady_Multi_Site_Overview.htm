FrameReady Multi Site Overview

FrameReady Multi Site is an available upgrade option designed for users that have multiple locations and a Central Production Facility (CPF).

  • Multi Site allows you to share all of your FrameReady information over the internet (including inventory, invoices, orders, etc.) with all of your remote locations.

  • Reports can be printed based on all or by individual locations.

  • Pricing is the same across all locations.

  • Requires FileMaker Server on a dedicated server computer, with robust internet and a static IP address with port 5003 routed to the server computer.

FrameReady Multi Site Overview

  • The FrameReady Multi Site configuration requires the use of FileMaker Server.

  • This computer is not used for anything except for hosting the FrameReady files and making them available to devices on your network.

  • The operating system for this server computer needs to meet the minimum requirements for FileMaker Server. See: System Requirements

  • The FileMaker Server computer relies on a static IP address so that remote computers can connect. See: Remote Access

Accessing FrameReady at the Remote Location

  • At each remote location, users access FrameReady by opening FrameReady (using FileMaker Pro) as they would on a local network.

  • Each location uses a number prefix attached to their login which allows FrameReady to separate records by the location they were created in. For example:

    • Store One: 1-level1, 1-level2, 1-level3 or 1-level4

    • Store Two: 2-level1, 2-level2, 2-level3 or 2-level4

    • Store Three: 3-level1, 3-level2, 3-level3 or 3-level4, etc.
