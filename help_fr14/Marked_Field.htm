Marked Field

Several of the FrameReady files include a special checkbox labelled Marked.

Marked Fields Overview

  • The Marked checkbox field can be used for a variety of tasks. For example, it can be used for special mailings in the Contacts file or deleting discontinued moulding in the Price Codes file.

  • Many records in FrameReady can be specially marked (an X in the checkbox indicates an item is marked).

  • Each FrameReady file, e.g. Products or Contacts, has it's own Marked list.

  • All specially marked records are treated as belonging to the same special group: this allows you to perform special actions on them.

Tip: Be sure to un-mark previously marked records before marking your new set or the newly marked records will be added to the group when your perform a Find for Marked records search.

Marked Buttons Explained

Available in list view for: Products, Price Codes, Contacts, Purchase Orders, Invoices, Work Orders

Unmark All Button

  • Clears the list of marked items, there will be no marked items after clicking Yes. This cannot be undone.

  • Clearing marked items in one file, e.g. Products, does not affect marked items in other files, e.g. Contacts.

Mark Found Set Button

  • Perform a Find prior to using otherwise all items in the list view will be marked. There is no quick undo but you can manually uncheck the Marked field or use the Unmark All button.

  • If there is no found set, then instead a confirmation request appears asking if you wish to mark all records in the current file.

Find Marked Records Button

  • Switches to a list view of all marked records in the current file (e.g. Products, or Contacts).

How to Mark a Single Item

  1. Go to Products, Price Codes, Contacts, Purchase Orders, Invoices, or Work Orders.

  2. Locate the record you wish to mark.

  3. Locate the Marked checkbox and click.

    The record is added to the specially Marked group.

How to Mark Multiple Records

  1. Go to Products, Price Codes, Contacts, Purchase Orders, Invoices, or Work Orders.

  2. Switch to the list view and click the Unmark All button.

    A confirmation request appears.

This action clears all records of any X in the Marked field from any previous search you may have done earlier. This prevents other, older items from being included.

  1. Click the Find button.

    The Enter Search Criteria screen appears.

  2. Choose a field and enter a value that will give you some results.

    A list of results appear.

  3. Click the Mark Found Set side button.

    All of the found records are now Marked.
