Change Invoice Numbering

Main Menu > Invoices

This procedure is only to be done when you are first setting up FrameReady and would like to continue with your old invoice numbering system. It is recommended that you contact the FrameReady Team for assistance with this procedure.

WARNING:  If this process is done incorrectly, you will not be able to “undo” it and all of your previously entered invoices will be lost!

How to Set up Your Invoice Numbering

You must be logged in as level4 in order to perform the following.

  1. On the Main Menu, in the menu bar, click Perform.

  2. Click the New Invoice button.

  3. Without entering any data, click the Done button. You do not need to enter a customer.

    An empty Invoice appears.

  4. Right-click in the Invoice # field and select Find Matching Records.

  5. The Found Set should now be 1 of 1.

  6. Click in the Invoice # field then, in the menu bar, click Records and choose Replace Field Contents.

  7. The Replace Field Contents dialog box appears.

  8. Select the "Replace with serial numbers:" radio circle.

  9. Enter the invoice you want to start from in the Initial value field.

    Make sure "Update serial number in Entry options?" is checked.

  10. Before clicking Replace: verify, in the opening paragraph in the Replace Field Contents dialog box, that you are performing this operation on just one (1) records of the current found set.

    If it says there are more than one record, then click Cancel and start again from Step 3.

  11. The invoice numbering will now follow the correct sequence when a new invoice is created. The last invoice you created will display the number you entered and all subsequent invoices will increase by one.

Tip: You can also change the Invoice serial numbering option when you begin to enter your existing Invoices and it will save you having to type them in for each Invoice. Keep the numbering for Work Orders, Invoices and Products different so as to prevent conflicts (which could result in a lookup error when making an entry on an Invoice, e.g. WO # 100004 and Product # 100004 would result in a conflict.)
