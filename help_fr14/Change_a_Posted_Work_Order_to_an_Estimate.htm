Customer change their mind? This is how to change a Work Order which has been posted to an Invoice into an Estimate instead.

How to Change a Posted Work Order to an Estimate

Caution: This procedure cannot be applied to Invoices which are Paid in Full.

  1. In your Work Orders, locate the Work Order in question.

  2. Click the Find Invoice sidebar button.


  3. The Invoice's Line Item Entry screen appears. Click the Delete button (X) on the line which contains the WO# (far right).

  4. A dialog box asks if you wish to unpost the Work Order before deleting it.

  5. Click Yes.

  6. Click Done.

  7. Return to the Work Order by clicking on the Work Order icon.

  8. Open the Order tab, and click the Estimate button.

  9. A dialog box asks for you to confirm.

  10. Click Yes.

  11. The button changes to read Activate.

  12. The Work Order is no longer posted to an Invoice and now has the status of Estimate. See also: Print a Work Order Estimate
