Add a New Work Order to an Invoice

Main Menu > Invoices

The customer already has an existing Invoice from this morning and you want to add the Work Order created this afternoon to it.

How to Add a (New) Work Order to an Existing Invoice

  1. Take note of the new Work Order number, e.g.  A0028 

  2. Locate the customer’s existing invoice, e.g. search for the customer’s name in the Contacts file and then click the blue Invoices/Rewards tab at the bottom.

  3. Click the Data Entry button.

  4. The Line Item Entry screen appears.

    Do not hand-enter the Work Order into the Item Number field.

    Instead, click the Search Item magnifying glass icon. 

  5. A search dialog box appears.

  6. In the Search for Item dialog box type in the Work Order number, e.g.  A0028 , in the Item Number field.

  7. Click the Search button.

    The Work Order now appears on the Invoice.

If the new Work Order has already been posted to an Invoice, you will receive an error message informing you of the Invoice number and date. You may choose to repost it.
