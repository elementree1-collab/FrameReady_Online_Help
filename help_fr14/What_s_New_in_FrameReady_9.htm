What (was) New in FrameReady 9

The new features of FrameReady 9 are listed below.

FrameReady 9.x Release Notes

For a brief video demonstration of what's new in FrameReady 9, please click here:

http://frameready.ca/tutorial/FR901/FR901.htm

Networking

  • A Network Key is now required for networking FrameReady between two or more computers. If you are licensed to network FrameReady then you will have received a network key in the upgrade email that was sent to you. Go to Setup Data, click on the Network tab and click the Enter Network Key button.

Minimum Footage and Surcharges

  • If you have vendors where you have assigned minimum footage and/or surcharges, you will need to go to the Pricing Options and Defaults screen and create a vendor specific record for them (if you don't have one already) and enter the minimum and surcharges otherwise new items that are imported during a vendor update will not be assigned those values. This is a change in behavior from previous versions.

Multi Site

  • The multi-site version is now a feature of the standard version of FrameReady. Throughout the program you will see the multi site field in the top right corner. Unless you are licensed for multi site you can just ignore this field.

All Files

  1. All components have been resized to a resolution of 1024 x 768. There is now space between fields. And buttons have been enlarged. All these make it possible for FrameReady to be used on the Apple iPad.

  2. The List View in each file has been enhanced with gradient coloring for a more pleasing look and feel.

  3. All buttons have been modified to give a more up-to-date look and feel. The background of most of the files have been given a more pleasing gradient look.

  4. Added the ability to send email via SMTP. This will allow users who have web-based email accounts, such as, gmail or hotmail to send mail using those accounts. Read more about how to Set Up the Email Tab.

  5. Added the ability to enter a tax exemption number without first having to go to the Contacts file.

Main Menu

  1. Added a vendor update notification icon. This feature is triggered when the Main Menu is opened for the first time during a session. A number will appear in a red circle indicating the number of vendors that need to be updated.

  2. The vendor pricing update screen has been enhanced with a "Remove" vendor button, display of the vendor suffix (moulding) or prefix (matboard). The list can now be printed.

Work Orders

  1. Added an enhanced calculation engine to the "Other" component. This allows for calculating things like a 3D plexi boxes (cubic inches/centimeters), or multiple fillets for multiple opening mats (each window can be sized separately and priced by the foot or metre), or printing (price by the square foot/metre or square inch/centimetre). This "Other" component also has the special property of "Do not discount" and "Do not tax". This is useful for pricing items such as restoration where tax and discounts do not apply. Read more about the Other Detail Screen.

  2. Added an option to the List View where you can hold down the Shift key when changing the Work Order status from "incomplete" to "complete" and have a dialog box appear so you can choose who completed the order and choose the date (current date is auto entered).

  3. Added a "Package Special" feature where any number of pre-determined configurations can be set up and then auto-filled on a Work Order simply by entering a code. Read more about how to Setup Package Specials.

  4. Added three new fields to track corporate installations: Sidemark, Plan, and Room. These fields are found on the "Notes" tab and will copy to line items when posted to an Invoice.

  5. On the Shop tab when you select "Completed By" the Work Order status now changes to "complete" and the current date is entered.

  6. Changed the property of the "Job Number" field from numeric to alpha numeric.

  7. Changed the "Job Number" Index button to display the values in an alpha numeric order.

  8. Added the option to post readymade frames separately to an Invoice.

Code Tables

Added a column to price by increment square inches/centimeters. This allows for matching a vendor's price chart where a price defaults to the next highest value. Example, up to 100 square inches is this much, 101-200 is this much, 201-300 is this much, etc.

Price Codes

  1. Added a width multiplier to each moulding record. Instead of just having a single moulding width multiplier for all moulding you can now specify a width multiplier for any moulding. This is useful for moulding that require extra footage for waste.

  2. Added Minimum Footage, Surcharges, and Width Multiplier to Pricing Options and defaults (Pricing Options and Defaults Button). This will allow you to create vendor specific parameters when performing an import of new vendor moulding.

  3. Added "Other" tab to all Groups. This will allow you to set up different pricing options for different types of situations and/or customers without having to create additional item records. The different options display when creating new lines in the work order "Other" section.

  4. Added an "inStock" moulding feature where a frame shop can enter their own moulding number (SKU) and tie it to a vendor record so the price can be updated after the vendor has been updated.

  5. Added an option to increase or decrease all pricing by a percentage. Or, select only a specific group.

Contacts

  1. Added multiple email fields. Easily select the primary address. Create a text file of all email addresses.

  2. Added the ability to consolidate duplicate contact records.

Invoices

  1. Added a Packing List option which will print a packing list for the items listed on the invoice or (from the List View) all the items for all invoices that have been "Marked".

  2. Added the option to round change to the nearest nickel when a customer pays with cash. The rules for rounding follow the recommendation of the Canadian Retail Association.

Products

The multi-site inventory in the Products file has been re-designed to allow for more than six locations. Licensing is now issued on a per site basis.

Time Cards

  1. Added the ability for users to clock in and clock out without having to log into their time card.

  2. Added the option to calculate overtime on a daily basis as well as the pay period. This allows part-time staff to track overtime when required.
