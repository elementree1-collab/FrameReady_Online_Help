File Not Found

When selecting Update Vendor Pricing you may receive the error message:

File Not Found! Please ensure you are currently connected to the internet.

Use the following steps to prevent this dialog from showing during startup.

There is a problem with your internet connection 

  • Open your web browser and ensure that you are able to navigate the web.  

  • Additionally, make sure that you can navigate to www.frameready.com

  • Check your internet connection; check your wifi connection.

  • Check any network monitoring software. If found, temporarily disable it and see if the update proceeds. Sometimes, these types of programs need frameready.com and frameready.ca to be added to their "white list" or "exclusion list."
