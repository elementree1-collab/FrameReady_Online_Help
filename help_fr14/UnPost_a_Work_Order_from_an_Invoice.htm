UnPost a Work Order from an Invoice

Main Menu > Invoices > Line Item Entry screen

After you have posted a Work Order (or group of Work Orders) to an Invoice, the customer decides that they do not want to go ahead with the order (or one of them).

  • Let's face it, people change their minds... and it is usually right after you post a Work Order to an Invoice.

  • Also a great option for when the customer wants two orders on two different Invoices, but doesn’t tell you that until after you have them on one Invoice.

How to Unpost a Work Order from an Invoice

Note: This feature is not available when using the "Enter Deposit / Deposit Invoices" feature.

  1. Locate the Invoice with the Work Order on it. If there is a purple Data Entry button, then click it.

  2. In Line Entry / Data Entry screen, click on the teal X button on the right side of the screen.

  3. A dialog box appears, asking if you would like to unpost this Work Order before deleting the line from the Invoice?

  4. Click Yes.

    The Work Order is removed from the Invoice.

    At the same time, in the Work Order file, the     Posted button changes back to Post to Invoice, giving you the option to post the Work Order to an Invoice at a later date, e.g. when the customer is ready to go ahead with the order.

    Also, review any payments on this Invoice and confirm if they should remain, be adjusted, or removed.

  5. Clicking the No button removes the Work Order from the Invoice, but you will not be able to post that Work Order to another Invoice.

  6. If you are removing a Product, then the dialog box asks "Deleting this line item may create an error in your inventory. Are you sure you want to delete it?"

  7. If you remove a Gift Card, then the dialog box asks "This line represents a gift card which has been credited in the system. Deleting the line will also delete the credit. Are you sure you want to delete this line and related credit?"

  8. Click Done to finish working with this Invoice.
