Invoices Rapid Entries Screen

Invoices > Data Entry button > Rapid Entries button

Rapid Entries is designed to quickly enter multiple retail items into an Invoice and is particularly useful with barcode scanners.

Rapid Entries Overview

The Rapid Entries screen is particularly useful with barcode scanners; the Item Number field is selected and ready for input. Scan the barcode. The item is entered with a Qty of  1 . Continue to enter or scan all items.

How to Activate the Rapid Entries Screen

  1. From Main Menu, open the Options tab in the Invoices section.

  2. Click the More Options... button.

  3. In the General tab, look for the Default to Rapid Entry Screen control and select Yes.

Rapid Entries Screen Explained

The "Rapid Entries" screen is designed to quickly enter multiple retail items into an Invoice and is particularly useful with barcode scanners.

Done Button

  • Exits the "Rapid Entries" screen and returns to the "Line Item Entry" screen.

Enter a Payment Button

  • Opens the "Receipts" window for recording a payment.

Discount Button

  • Triggers the "Calculate Discount" window to auto-enter a discount.

  • Select a discount to apply to all retail items on the current Invoice. When finding line items to subtotal, FrameReady automatically omits items that already have a discount, or if the Invoice Category is set to "Work Order" or "Gift Certificate".

  • Select a preset or enter the discount value in the Discount field. It is recommended that you enter all items eligible for the discount, apply the discount, and then enter non-discounted items (or group items by their discount rate).

Start Over Button

  • Removes all line entries, but only if no payments have been made on the Invoice.

Sales Rep Field

  • Mandatory; a name must be entered before leaving this screen.

  • Set your default Sales Rep in Main Menu > Invoice section > Options tab. See: Set up Invoice Options

Item Number Field

  • When the screen appears, the cursor is positioned in this field for the benefit of barcode scanners.

  • Note: Items in the Products file with a UPC Number will only display the UPC# and not the Item Number.

  • If you type in the Item Number manually and press Enter then the same information will be looked up.

Quantity, Price, Description, L/E Number, Artist, Category Discount, Tax Exempt Fields

  • Data is pulled from the Products file when a valid Item Number is entered.

Accept Button

  • Click a line item to populate the fields in the upper portion of the screen.

  • Now you are able to edit any of the fields, for example, Quantity, and save the changes by clicking the green Accept button.

Delete Button

  • Click a line item to populate the fields in the upper portion of the screen.

  • Click the red Delete button to remove the line.

Clear Button

  • Blanks out all fields in the upper portion of the screen.

How to Use Rapid Entries Feature

  1. Click the Rapid Entries button.

    The Rapid Entries Screen appears. The cursor is placed in the Item Number field.

  2. Scan the barcode or enter the Product/Item Number and press Enter, Return or Tab on your keyboard.

    The item is entered as a line item with a Quantity of  1  (or the default quantity as specified in the Price Codes file).

  3. Continue to enter or scan all items.

  4. Click Done to exit the "Rapid Entries" screen and return to the "Line Item Entry" screen.

  5. Click Discount to apply a bulk discount to Product items.

  6. Click Enter a Payment to handle the sale.

How to Manually Use the Rapid Entries Feature

  1. Click the Rapid Entries button.

    The Rapid Entries Screen appears and the cursor is placed in the Item Number field.

  2. Enter the product number manually and press Enter or Return on your keyboard.

    FrameReady looks up the item and a Quantity of one is added.

  3. If you press the Tab key, then the cursor tabs through the fields and does not perform a lookup in the Product file (you would do this if the item was not in the Product file.)

  4. You are required to click and Accept the entry in order for it to appear as a line item.

How to Edit a Rapid Entry

  1. Select the line entry item.

    The Item Number, Quantity, Price, Description etc. appear.

  2. Adjust the values as needed.

  3. Click the Accept button to commit the changes.

    The Accept button must be clicked or the edit will be lost.

How to Delete a Rapid Entry

  1. Select the line entry item.

    The Item Number, Quantity, Price, Description etc. appear.

  2. Click the Delete button to remove the selected line item.

    The item is removed,     no warning dialog appears.

How to Enable or Disable Rapid Entries

  1. On the Main Menu, in the Invoices section, open the Options tab.

  2. Click the More Options button.

  3. The "Invoice Options" window appears.

     

  4. In the General tab, locate the Set Default to Rapid Entry Screen radio button:

    • Yes - FrameReady defaults to the "Rapid Entry" screen each time an Invoice is created.

    • No - FrameReady will default to the "Line Item Entry" screen each time an Invoice is created.

  5. Click Done.
