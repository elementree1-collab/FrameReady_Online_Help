What's New in FrameReady 11

The new features of FrameReady 11 are listed below.

FrameReady 11.x Release Notes

New FileMaker Features

FileMaker Pro 17

  • FrameReady 11.x requires minimum FileMaker Pro 17.

FileMaker Pro 17 Features

  • Cards: A floating dialog box appears above the current screen (which is dimmed) without resizing the current window.

Interfaces

  • Gunnar Computerized Mat Cutter.

  • QuickBooks software (macOS is online only) via Annual Subscription.

All Files

Added:

  • Heading/descriptions to popup windows and cards.

  • Calendar icon for date fields.

  • In List View, column totals appear in footer (level3 or greater).

Modified:

  • All FrameReady files are now located in the user/account's Home folder.
    In Window: C:\Users\[Account Name]\FrameReady 11
    In macOS: Macintosh HD\Users\[Account Name]\FrameReady 11

  • Only FrameReady 9 and FrameReady 10 can upgrade to version 11; FrameReady 7 and FrameReady 8 must first upgrade to version 10, then to 11.

  • Except for Marked Record fields and Do Not Tax fields, checkboxes now display a checkmark symbol instead of an X.

  • All fields that collect a percentage now auto-convert, e.g. enter 50 auto-converts to decimal 0.5.

Setup Data

Added:

  • Ability to explicitly set Excluded (closed) Dates for when generating a Work Order due date.

  • Ability to backup FrameReady files to a folder on the Desktop or in the Documents folder or a custom folder. Not visible/available when using FileMaker Server.

  • For Vendor Updates, ability to sort vendors in ascending and descending order.

  • In Email settings, added BCC (blind carbon copy) field.

  • When sending an email with an attachment, automatically creates a "FrameReady Documents" folder if one does not already exist.

Modified:

  • Several buttons under the Network Tab are now only visible when  the user is on the host computer and the files are open locally (Set Files to Single, Set Files to Multi, Enable Work Order Photo).

Fixed:

  • All fields that collect a percentage will auto-convert, e.g. enter 50 will auto-convert to decimal 0.5.

Main Menu

Added (to Work Orders):

  • For Incomplete Work Orders button, added a badge to indicate the number of Incomplete Work Orders.

  • A confirm dialog to the Omit vendor button in Create Purchase Orders window.

  • A note to the Usage Reports window concerning reports which cover large time periods and/or with many records may take longer to prepare.

  • For printing Art ID tags when printing Work Orders; the quantity of Art ID tags matches the Work Order Qty field.

  • Gunnar checkbox to Work Order Options: Work Order Defaults.

  • Mat Design and Extra fields to Work Order Options: Work Order Defaults.

  • Opiton to suppress generating matboard/moulding cut lists.

Added (to Package Specials):

  • A record status field to Package Specials.

  • A Delete button to Package Specials.

  • Ability to run Work Order report for a Found Set.

Added (to Vendor Pricing):

  • Vendors not installed in the program display a "Click to add" placeholder message in the Last Updated field/column.

  • Added a "?" to display in the Update Vendor Pricing badge (red circle) if a network error occurs.

  • Added a script to run the check vendor updates process at 4:00 am daily (if the program is left running).

  • Added housekeeping tasks to clean up temporary tables much faster.

Added (to Contacts):

  • Added an Export Email Addresses button. Visible only to level3 and level4 users.

Added (to Invoices Options):

  • Added Auto Enter Terms field for new Invoices.

Added (to Gift Certificate Options):

  • Added an Options tab containing Print Option settings.

Added (to Price Codes Options):

  • Checkbox in Option tab: Do not import a lower price if an item has dropped in cost (if the Cost in the vendor update is less than the Cost already in FrameReady, then do not import lower wholesale cost).

Added (to Products Options):

  • Popover to edit t four Product tier labels.

Added (to Purchase Orders Options):

  • A More Options... button to hide Customer name and Work Order number on printed Purchase Order.

Modified:

  • Package Specials screen displays in a card window.

  • Work Order Options displays in a card window.

  • Invoice Options displays in a card window.

  • Work Order Email Message displays in a card window.

  • Purchase Order Email Message displays in a card window.

  • Invoice Email Message displays in a card window.

  • Create Frame Order window shows the number of Work Orders selected for frame order.

  • Sales Report window, "Category" button renamed to "Invoice Category".

  • Vendor Update lists now auto-sort alphabetically upon opening the corresponding tab.

Fixed:

  • After importing a customer database, the Customer ID serial number is reset to the next available number.

  • Search format for phone number field to support partial phone numbers.

  • Print Address Labels - Cancel button (within sort dialog) where if the process is canceled then and user is returned to the contact form view.

  • Change Passwords did not change in Contacts and Invoice file.

  • Vendor Updating: when moving from Vendors to My Vendors and then back, all vendors were shown.

  • Vendor Updating: Red circle did not appear until after opening Vendor Update window.

Price Codes

Added:

  • In the Glazing group, in the Glass Pricing tab, added the Glass Pricer button. This new screen allows for easy construction of a Code Table for glazing.

  • In the printed Code Table layout, added column headings.

  • In the Frame Pricing tab, in the Minimum & Surcharges tab, added Join Code field for each moulding item; based on total dimensions of the frame.

  • Omit Category field to Pricing Options & Defaults for moulding (now same as Matboard).

  • Join or Ship Code added; to cover costs based on size (Moulding only)

  • Glass Pricer; button to add additional line items to table. Also button to Sort lines in table.

Modified:

  • Renamed "Glass" group to "Glazing".

  • Default Mat Reveals displays in a card window.

  • Grouped fields together in the Auto Inv tab.

  • Updated the email address for the "Email to Tech Support" button.

  • Font size of page numbers in printed Inventory Reports.

  • Post to Purchase Order button appears dim when Order From field is empty.

  • Image tab displays in bold text if an image has been added to the record.

  • Item number field displays in bold text.

  • A note and outlined border to Manual Inv (first 2 fields) used in the Inventory Report.

  • "Find Not Verified" records to omit records marked as "Discontinued".

Fixed:

  • The ability to create a new Blank Table in the Create New (Code) Table screen.

  • The Discount field in the Manual Inv tab converts decimal to percentage.

  • Price Code items (mats, supplies, etc.) sold directly on an Invoice correctly deduct from the Auto Inventory Qty field of the original record in the Price Codes.

Products

Added:

  • In the Pricing tab, added "Keep on Hand" and "Minimum Order" fields to each product, used when calculating Purchase Orders.

  • In the Pricing tab, added four "Tiered Discount" fields (percentage discounts) for each product. The tier labels are rename-able from the Main Menu.

Modified:

  • "Post to Purchase Order" button is now greyed out when the Order From field is empty.

  • "Post to Purchase Order" button reads "On Order" when item is flagged for ordering.

  • Threshold and Reorder backgrounds turn red if one field has a value but the other is left empty.

  • Changed "Export to Excel" button to "Export Found Set to Excel".

  • Renamed "IN" label to "Qty on Hand".

  • Renamed "Enlarge" button to "Picture File".

  • Renamed "Insert Picture" to "Add a Photo".

  • Adjusted font size of page number in printed Text Directory, Image Directory.

  • Tooltip added to Committed checkbox.

Fixed:

  • Fixed width and height formatting for Artwork dimension fields.

  • Fixed security password so, when set to not allow access to Products file, users can not go there from labels file without using password.

  • Inventory List; field for Threshold was "Inv Actual" changed to "Threshold."

  • Security to block access to Product file when Security Password is set and user is in Labels file.

Labels

Added:

  • Added a confirmation dialog to the Start Over button.

  • Added buttons to import from Products, Price Codes, Work Orders (previously these were in the menu bar).

Modified:

  • Layout of input fields to reflect order of operations.

Contacts

Added:

  • In the Terms tab, added "Tiered Discounts" for Products field for each contact.

  • In the Terms tab, added a "Tax Override" field for each contact.

  • In the Shipping tab, added the ability to store multiple shipping addresses per contact.

  • In Date/Notes tab, added record status next to Add a Note to all records in Found Set button.

  • iOS only: added SMS button when Phone Number Location is "cell," otherwise CALL button is displayed.

  • in Artist's Bio print layout, added History field.

  • In Find layout, ability to search for either Name1 or Name2 within the same field.

Modified:

  • In Print Letter screen, modified Settings into a popover button.

  • Email address field now allows @ character to be searchable.

  • The ID# field now appear as non-editable (but remains editable).

  • Updated the appearance of Manage Keywords window.

  • Renamed "Import Photo" button to "Add a Photo".

Fixed:

  • In Artists tab, Purchased Art group, fixed visibility toggle for delete X button.

  • Updated link to Google Maps for address lookup.

  • Phone number search now supports Area Code, Area Code + Exchange, 7 digit number, 10 digit number. No need to enter formatting characters such as parenthesis, spaces or dashes.

  • Fixed customer ID serial number. After importing a customer database, the serial number is reset to the next available customer ID number.

  • Fixed Print Address Labels - Cancel button (within sort dialog) where if the process is canceled then the user is returned to the Contact form view.

  • Tax1 Rate field auto-converts "25" to 25% instead of 2500%.

Gift Certificates/Card

  • Renamed "Unredeemed" button to "Find Unredeemed".

  • In List View, Serial number appears in bold font.

  • Background color of Post to Invoice button matches Invoice color scheme.

Purchase Orders
