Price Bravura Mouldings with Inlays

Price Codes

A number of Bravura frames can be ordered with a variety of inlays.

  • For example: do a find for 78-1. You will get a list of items beginning with 78-1. 78-1 is the bare frame, where 78-1-BD is the same frame with the BD inlay, 78-1-BR uses the BR inlay, etc. The cost for these inlays is per frame and varies depending on the particular moulding. These inlay costs appear in the Category field with the word “Inlay” preceding the cost per frame.

  • For example: the category for 78-1-BD reads “Inlay 18.80”. To price these inlay items you will want to enter the 18.80 into the Set Price formula. Rather than doing a find for each of the individual items and typing a new set price for each one, use the following instructions.

How to Price Bravura Mouldings with Inlays

  1. Navigate to the Price Codes file.

  2. Click the Find button.

  3. Select Bravura from the Supplier Drop-down list.

  4. Enter  Inlay 18.80  in the Category field.

  5. Click Perform Find.

    A list view of results appears.

  6. Click the Form View button.

  7. Click the Frame Pricing tab.

  8. Click the Set Price Tab.

  9. Click in the Set Price Formula field to only read 18.8.

    This value can be increased if you also want to include shipping surcharges etc.

  10. Make sure your cursor is still in the Set Price Formula field.

  11. Go to the Records menu and select Replace Field Contents.

    Verify the dialog says: Permanently replace the contents of the field “Set Price TXT” in the ## records of the current found set? Replace with: “18.8”.

  12. Click Replace.

    If the dialog says anything different, click cancel and go back to step 10.

  13. Repeat steps 2-12 substituting Inlay 18.80 with:  Inlay 11.23  ,  Inlay 16.86  and  Inlay 23.42  .
