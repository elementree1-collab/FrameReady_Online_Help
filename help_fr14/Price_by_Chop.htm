Price by Chop

Mounting > Pricing tab

More and more frameshops are electing to order their frames as chop rather than carrying an inventory of length moulding. Therefore it is appropriate to select the order type as chop.

Price Moulding by Chop

  • If you have elected to order your moulding by Chop, then FrameReady will look first in the Chop field.

  • If that field is blank, then it will look in the Join field.

  • If it too is blank, then it will base your retail price on the amount in the Cost field.

  • This is the Default Pricing Formula in FrameReady.

  • If you selected to price (and order) your moulding by Chop, then FrameReady will apply the appropriate markup based on the corresponding cost:

    Cost Type Less Than Mark
    Chop <5 2.85;
    Chop <10 2.80;
    Chop <15 2.75;
    Chop <20 2.70;
    Chop <25 2.65
    Chop (all others) 2.60

  • The default markups in FrameReady can easily be modified by clicking on the number and changing it. You can always undo and revert back to the FrameReady defaults by clicking on the Install Program Defaults button. This will allow you to install the default formula to just the current record or to all moulding records.

  • In addition to the markups, all woods, liners, and extenders have an additional $5.00 added to the final price of the frame. All Fillets have $7.50 added to the final frame price. These amounts are show under the Set Price. 

  • Adatasol Inc. loads your FrameReady program with this default. It is up to you to decide if you need to change this to a different amount or set to zero.
