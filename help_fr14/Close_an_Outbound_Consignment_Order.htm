Close an Outbound Consignment Order

Main Menu > Outbound Consignments

Use these steps when your consignment items return to your shop or are sold. This closes (or marks as 'processed') the Consignment Order and generates Invoices for the sold items.

Processing Consignment Items Back In

How to Process Incoming Consignment Products

  1. Locate the Consignment Order in question.

  2. You must determine which items have been sold to the Consignee or a Third Party.

    If it was a Third Party then you need to first make sure they are listed in the Contacts file before continuing. See also: Set up Contacts

  3. Click the Check Items In sidebar button.

    A screen appears listing all the items in the Consignment Order.

  4. If the Consignee did not sell anything, then click the Return all "Out" Items to Inventory button.

    Otherwise, continue.

  5. Click the Preset Customer & Bill # button. You will need to know the Customer ID number in advance.

    A dialog box appears.

  6. Enter the Customer # for the first Third Party to whom a consignment item was sold.

  7. Enter the Bill # used by the Consignee. If there was no Bill #, then make one up. Click OK.

Note: The bill number is a way of grouping the sold items with the party to whom they were sold.

  1. Click the Change to Sold button for the correct item. Each line item must be processed individually.

    This radio button changes to Sold and enters the buyers name.

  2. If an item was returned, then click the Status radio button to Return.

  3. Click the Process All Items Sold or Returned button.

    A dialog box appears, indicating that all items on this Consignment Order have been processed.

    Click Okay.

  4. If no bill has been created, then a dialog box appears asking for the bill number.

    If there is more than one bill # per consignee, then a dialog box appears for the bill number.

    Once a bill number is entered, the bill appears on the screen for printing. Click Continue.

  5. Invoices have now been created in the Invoices file for each bill.

Note: Go to Invoices file and use the Enter A Payment feature.

  • If you haven't processed the items in (by clicking the Process In button) and wish to return to the form view, clicking the Consignment button you will get this dialog box.

    Choose whether you wish to finish the checking in process Now or Later.

    This would happen if, for instance you were interrupted in the process and needed to return to the checking in later.
