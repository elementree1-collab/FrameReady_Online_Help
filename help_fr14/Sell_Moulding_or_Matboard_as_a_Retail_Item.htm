Sell Moulding or Matboard as a Retail Item

Main Menu > Invoices > Line Item Entry Screen

How to Sell a length of Moulding or sheet of Matboard

  1. First, locate the moulding or matboard in your Price Codes.

  2. Examine or set up the Retail Price. See also: Retail Pricing Tab

    By default, all Price Code items have a Cost and a Markup.

    To calculate a Retail Unit Price, FrameReady uses that formula (you can override this with your own Unit Price number).

  3. Then, to sell it to a customer, add it to an Invoice (not a Work Order!)

    Click the Data Entry button on your Invoice.

  4. In the Item Number column, type in the moulding/matboard number with it’s suffix as a Line Item entry, e.g.  335-45.CVS 

    Alternatively, click the     magnifying glass icon to search for the Price Code item.

  5. Enter number of pieces being sold in Qty field, the default is  1
