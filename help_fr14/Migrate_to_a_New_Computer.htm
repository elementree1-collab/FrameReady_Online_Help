Move FrameReady to Another Computer

These instructions are for Single User installations only.

  • The latest version of FrameReady always requires the latest or a newer version of FileMaker.

  • Your FrameReady Subscription provides you access to the latest versions of FrameReady and FileMaker: simply give us a call or email.

  • Note that without an active subscription, you will need purchase an Upgrade.

If you do not have a FrameReady Subscription

  • Older versions of FrameReady and/or FileMaker are not supported on new versions of Windows or MacOS. Additionally, newer versions of Windows or MacOS require newer versions of FileMaker; and backwards compatibility cannot be guaranteed.

  • Older versions of FileMaker are not available for download.

  • The FrameReady Team are unable to support migrating older versions of FrameReady and/or FileMaker to computers with newer operating systems. Doing so may result in unexpected performance and/or data loss.

Before you move FrameReady to another Computer

  1. Call the FrameReady Team at 1-888-281-3303 and ask about your options: you might require a version of FileMaker that is unavailable, in which case an Upgrade is recommended.

  2. If you are enrolled in our FrameReady Subscription plan, then you are eligible for the latest versions of FileMaker and FrameReady. This makes migrating to a new computer much easier.

  3. FrameReady is specialty software and your business deserves to avoid the hassle of unexpected downtime due to compatibility issues.

Your on-going FrameReady Subscription provides you with any FileMaker and FrameReady version upgrades.

Payable monthly, and is only valid for your original purchased version.

Without a FrameReady Subscription, the latest versions of FileMaker and FrameReady must be purchased as an Upgrade.

Install FileMaker Pro on your New PC

Your new computer needs FileMaker Pro installed.

  1. Visit this page to download FileMaker:

    https://www.frameready.com/download-filemaker

  2. Click the blue System Requirements... button and confirm that your new computer meets the FileMaker system requirements.

    If you require an older version of FileMaker, then our recommendation is that you upgrade your FrameReady to the latest version instead.

  3. Choose your computer; either:

    - Windows 11 Pro/Enterprise, Windows 10 Pro/Enterprise
    - Mac Sonoma 14, Ventura 13, Monterey 12

  4. Download FileMaker and the FileMaker License Certificate files for your chosen computer.

  5. Open your Downloads folder and double click the FileMaker installer file.

  6. Follow the on-screen instructions to complete the installation.

Move FrameReady to a Windows Computer

For Single User installations only.

Important! Remember to first install FileMaker Pro.

  1. Make a backup of your FrameReady and save it to a USB flash drive, then go to Step 2.

    See: How to Make a Backup

  2. Press Windows + E to open the File Explorer program.

  3. In the left panel, look under This PC and locate your backup folder on the USB flash drive.

    Single-click the FrameReady 11 folder, right-click and choose Copy.

  4. In the left panel, look under This PC and single-click Local Disk (C):

  5. Double-click the Users folder.

  6. Locate your user account name and double-click it.

    This is your Home folder.

  7. Paste the FrameReady folder into your Home folder.

  8. When the paste operation is complete, go into the new FrameReady folder and look for the FrameReady.fmp12 file.

  9. Right-click on FrameReady.fmp12 and select Send To > Desktop (create shortcut).

  10. Use the desktop shortcut to open FrameReady.

  11. From the Main Menu, click Setup Data, open the Network tab and click Set Files to Single-User.

Move FrameReady to a Mac Computer

For Single User installations only.

Important! Remember to first install FileMaker Pro.

  1. Make a backup of your FrameReady and save it to a USB flash drive, then go to Step 2.

    See: How to Make a Backup

  2. Open the Finder program.

  3. Locate your backup on the USB flash drive and locate the FrameReady folder.

  4. Single-click the FrameReady folder, so that it's selected and then from the menubar choose Edit > Copy.

  5. From the menubar click Go > Home.

    Your Home folder is shown.

  6. Paste the FrameReady folder into your Home folder.

    The FrameReady folder is copied over.

  7. Double-click the new FrameReady folder now listed in the Applications folder.

  8. Single-click and drag the FrameReady.fmp12 file to the Desktop.

    A new alias is created.

  9. Use the Desktop alias to open FrameReady.

  10. From the Main Menu, click Setup Data, open the Network tab and click Set Files to Single-User.
