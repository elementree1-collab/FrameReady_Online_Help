Print Documents Screen Explained

 Main Menu > Work Orders (form view) > Print Documents sidebar button

Print Documents for Production

The Print Documents window features the following Work Order sections:

  • Print Documents for Customer

  • Print Documents for Shop

  • Print Documents for Production

  • Print Documents Reports for the Found Set

Print Documents for Production

Schedule of Incomplete Button

  • The report lists all incomplete Work Orders, omitting any estimates and orders on hold.

  • Can be printed for all records or for the found set.

All Materials Cut List Button

  • Print a cut list for all materials other than matboard for a single Work Order or the found set.

  • See also: How to Print an All Materials Cut List

Moulding Cut List Button

  • See also: How to Print a Moulding Cut List

Matboard Cut List Button

  • Print a list for matboard with all dimensions, opening, reveal, total and quantity to be cut. It includes any instructions typed in the Note icon.

  • See also: How to Print a Matboard Cut List

Glazing Cut List Button

  • Print a cut list for glazing for a single Work Order or the found set.
