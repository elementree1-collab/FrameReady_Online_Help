Find Work Orders using Barcodes

The barcode which appears on the printed Work Order can be used as a convenient way to call up a particular Work Order on the computer screen, for example, from the production room.

How to Find a Work Order using a Barcode

  1. On the Main Menu, in the Work Orders section, click the Find Work Order button.

    The Enter Search Criteria screen appears with the cursor blinking in the Item/UPC field.

  2. Scan the barcode from the printed Work Order into the WO # field.

  3. If no a match is found, then click Modify Find and scan the barcode in the Item field.

Tip: This barcode is an excellent tool for many reasons. If you keep a hard copy backup of each of your work orders for reference, for example, you can use the barcode to locate the original work order easily on the screen.
