Edit a Time Card Entry

Main Menu > Time Cards > Admin Login

If an employee has made a mistake on a Time Card entry, or an entry needs to be changed, a user with Administrator access can edit the entry.

How to Edit a Time Card Entry

  1. On the Main Menu, click the Time Cards icon.

  2. Login to the Administrator account.

  3. Find the Time Card you wish to edit or click the List View button and click the appropriate Emp ID button (with the correct Pay Date).

    The employee's Time Card appears.

  4. Click the Edit button to the left of the incorrect line item.

  5. The Edit Time Card window appears.

Tip: To create a new line item, click the Clock In button and then click the Clock Out button.

  1. Edit the necessary fields, e.g. start and end time, day type, comments.

Important! Start and End times must be this computer-specific format:

MM/DD/YY HH:MM AM 

For example, for 3 o'clock December 25 you would enter: 12/25/16 6:00 PM

Be cautious of 'spaces'

  1. Click Done to close the window.

  2. You can also manually set any line entry as Overtime by clicking the checkbox in the Overtime column.

Caution: Changing the start and end date will not move the line item to a previous or later Time Card. Instead, if an employee has clocked in/out on an old Time Card, follow these steps.

  1. Click Logout when you are finished.
