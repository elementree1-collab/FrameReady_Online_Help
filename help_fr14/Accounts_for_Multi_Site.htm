Accounts for Multi Site

FrameReady Multi Site uses the same four account levels as the standard version except that a number with a dash is inserted in front of the word "level". This number represents the site location from which the user is logging in.

It is critical that whoever opens FrameReady in a site location uses the correct site number when logging in.

  • Each location uses a number prefix attached to their login which allows FrameReady to separate records by the location they were created in. For example:

    • Store One: 1-level1, 1-level2, 1-level3 or 1-level4

    • Store Two: 2-level1, 2-level2, 2-level3 or 2-level4

    • Store Three: 3-level1, 3-level2, 3-level3 or 3-level4

    • Etc.

Example Multi Site Accounts

  • At your main location, a user with level two access would login with the account  1-level2 

  • At a second location, a user with the same level of access would login using  2-level2 

Please Note

  • The password for each level remains the same regardless of the site location.

  • FrameReady uses the number at the beginning of the account name so that records can be site-specific.
