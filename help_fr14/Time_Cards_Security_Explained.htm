Time Cards Security Explained

Unlike all other files in FrameReady, the level of access in the Time Card file is not reflected by what account you logged into FrameReady with. Even if FrameReady is open with the level4 account, this does not mean that the user has full access in the Time Card file.

User and Admin Access Levels

  • By default, all new accounts you create are given the limited access level of "User".

  • Individuals with User access are only able to view their own Time Cards. The purpose of this is to prevent an employee from clocking in or out for another employee, and to prevent them from viewing private data that may be stored in this file, i.e. SN Numbers, Bank Account or Hourly wages.

  • Individuals with User accounts cannot modify the clock in / clock out time.

  • If an individual with User level access has made an error, only an Administrator can edit that entry.
