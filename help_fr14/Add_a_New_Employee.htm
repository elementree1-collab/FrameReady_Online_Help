Add a New Employee

Main Menu > Time Cards

Easily add a new employee to FrameReady.

How to Add a New Employee

  1. On the Main Menu, click the Time Card icon.

  2. Click the Administrator's Employee ID button.

  3. The password dialog box appears.

  4. Enter your password and click OK.

  5. Click the New User sidebar button.

  6. Enter a password, confirm the password and password hint for the new user.

  7. Click OK.

  8. A new account is created with a unique Employee ID.

  9. Enter the employee's First Name and Last Name into the appropriate fields.

    The full name will appear on the login screen and make it easier for the employee to locate their account in the list.

  10. Click the Logout button (top right) when you are finished.
