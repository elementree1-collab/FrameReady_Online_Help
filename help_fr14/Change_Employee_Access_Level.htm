Change Employee Access Level

Main Menu > Time Cards > Admin Login

Warning: It is recommended that only Owners and Managers be given Admin access.

With Admin level access, individuals can:

  • modify time cards

  • print reports

  • enable/disable users

  • create new users

  • view employee time cards

  • view private employee information

How to Change an Employee / User Access Level

  1. On the Main Menu, click the Time Cards icon.

  2. Login to the Administrator account.

  3. Find the Time Card you wish to edit or click the List View button and click the appropriate Emp ID button.

    The employee's time card appears.

  4. Open the Info tab.

  5. Click the Edit button next to the right of User and Admin radio buttons.

  6. The Edit Access window appears.

  7. Choose the radio button that represents the level of access for that employee, i.e., User or Admin.

Warning: Users with Admin access can modify time cards, print reports, enable and disable users and create new users. They are also able to view all employee's time cards and private information. It is recommended that only Owners and Managers be granted admin access.

  1. Click Done.

  2. Click Logout when you are finished.
