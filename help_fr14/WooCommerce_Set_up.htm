WooCommerce Integration

Main Menu > Setup Data > Integrations > WooCommerce Integration 

Follow these steps to set up the WooCommerce Integration in your FrameReady.

WooCommerce Integration Set Up

How to Set up the WooCommerce Integration

  1. On the Main Menu, click the Setup Data button (top right).

  2. Open the Integrations tab.

  3. Click the WooCommerce Integration Settings button. Do not close FrameReady.

  4. The WooCommerce Integration Settings opens. You will notice a few new fields: Store URL, Consumer Key, and Consumer Secret.

    Before we can obtain the information for these new fields, you need to open your web browser and login to your WordPress admin.

Log into your WordPress Admin

We assume that WordPress and the WooCommerce plugin have already been installed and set up.

  1. Log into the Admin area of your WordPress site.

  2. In the left sidebar navigation, click WooCommerce and choose Settings.

  3. On the Settings page, open the Advanced tab (upper right).

  4. In the Advanced tab, click the REST API link.

  5. Look for, then click, the Add key link.

  6. In the Description field, enter:  FrameReady 

  7. In the Permissions field, select:  Read/Write 

  8. Click the Generate API key button.

  9. Copy the Consumer key field.

    Return to the FrameReady WooCommerce Integration window and paste into the Consumer key field.

  10. Repeat with the Consumer secret field, as well.

  11. Lastly, in the Store URL field, enter the top level address of your Shopify store, e.g. www.frameready.com
