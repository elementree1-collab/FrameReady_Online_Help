Installing FrameReady on Macintosh

These instructions are for Single User installations only.

  • To use FrameReady with more than one computer with FrameReady requires the installation and use of FileMaker Server software on a compatible computer system.

  • See: FileMaker Server Overview

To uninstall a FrameReady Trial version

  1. Do not uninstall your FrameReady Trial.

  2. It can be activated to the full Standard or Lite version; doing so will keep your records intact.

To install FrameReady 

  1. In the email you received, follow the link to the web page to download the FrameReady and FileMaker Pro files.

  2. Open the Downloads folder and double click the FileMaker Pro and FrameReady files.

  3. Follow the instructions on the web page.

To create a Desktop or Dock Shortcut

New in FrameReady 11

Default location of FrameReady 11, 12

Windows: C:\Users\[Account name]\FrameReady 11 [or 12]

mac OS: Macintosh HD\Users\[Account name]\FrameReady 11 [or 12]

  1. Using Finder, open your Home folder.

    Press Command + Shift + H or, in the menubar, click Go and select Home.

  2. Open the FrameReady 11 folder.

  3. Single-click the file named FrameReady.fmp12 and select Make Alias from the File menu.

  4. Drag the alias to Desktop or to the Dock, whichever you prefer.

    This acts as a shortcut to open FrameReady once FileMaker Pro has been installed.

  5. Double-click the FrameReady alias to open FrameReady.

See also: Open on macOS
