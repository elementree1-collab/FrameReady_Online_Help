Print One Label per Item in Found Set

Main Menu > Price Codes / Main Menu > Product Labels

Print barcode labels for a selection of items in the Products file. This particular method allows you to print one label for every item in the current Found Set of the Products file.

How to Print one Label for each Item in a Found Set

  1. In the Products file, perform a Find to locate the retail products which require bar code labels.

Tip: You can use the Marked box to identify unrelated groups to be printed, then do a find for the marked records: the results will be a list of the marked items

  1. Click the Product Labels icon.

    The labels window appears.

  2. In the Print Layout Number field, enter the layout number you wish to print, e.g. Avery 5167 could be layout number #3.

  3. Click the Import from Products button, or click on Menubar > Perform > Import from Products file.


  4. A dialog box appears.

  5. Enter the Starting Position of the first label. Click OK.

All of the items in the list view from the Product file will now be imported into this file. Only one item will be displayed. The number of Records to be printed is displayed on the left side of the screen. The Found count should be ’1′. Do not change this.

  1. Click Print.
