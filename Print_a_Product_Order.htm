Print a Product Order

Main Menu > Create Product Order

This searches the Products file for Special Orders and items that have fallen below the threshold for re-ordering.

How to Print a Product Order

  1. On the Main Menu, in the Products section, click the Create Product Order button.



    A dialog box appears to locate all special orders and re-orders.

  2. Click Cancel or OK.

  3. A list of vendors appears. At this point you may select certain vendors to be omitted from this order at this time. Otherwise, no items were found:

  4. Click Omit, if necessary.

  5. Click Continue.

  6. Click vendor name to print.

  7. Click Save as PDF or Print.
