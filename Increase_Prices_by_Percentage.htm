Increase Prices by Percentage

 Price Codes > Menu Bar > Perform > Adjust Pricing by Percentage

There may be occasions when you want to adjust all of your pricing by a percentage.

Before You Begin...

Caution: Are you pricing by Code Table? If yes, then see: Increasing or Decreasing a Code Table by a Percentage

How to Change Prices by a Percentage

Tip: Test your price change on a single item first before applying it a larger group; choose Current Record.

Note: Changes made here will also update the Default Pricing and Options -- which means that any new items imported in the future will also receive this new price change.

  1. Go to Price Codes, in the menu bar, click Perform and choose Adjust Pricing by a Percent.

  2. The Adjust Pricing dialog box appears.

  3. Chose Increase or Decrease from the drop-down.

  4. In the Retaill Price by Percentage field, enter the multiplier value by which you want to adjust your pricing, e.g.  5  for 5%.

Tip: if you want to double the prices, then enter 100 and a dialog box will ask you to confirm that you want a 100% increase. The other options are to Cancel or increase 1 Percent. If you want to increase the price more than double, Eg. 150%, you will need to increase by 100% and then again by 50%. You cannot increase prices by more than 100% at one time.

  1. Chose the Group to receive the increase/decrease; only one can be chosen:

    • Everything - If you choose this option then all your pricing will be adjusted, including all Formulas, all Code Tables and all Vendor Matrixes. The other options (listed below) will NOT adjust a Code Table since Code Tables are shared across groups. Adjust one or all Code Tables here).

    • Current Record - The price of the record currently on-screen is adjusted; no other records are changed.

    • Found Set - You may perform a Find and use this feature to adjust the pricing for that found set. This could be for a particular vendor or a specific category, or a group, or whatever.

    • All Moulding, All Matboard, etc. - Only the pricing records within the specified group are adjusted. This option will not adjust a Code Table since Code Tables are shared across groups (adjust one or all Code Tables here).

    • All Vendor Matrix - Use this option if you are using the Canadian price matrixes and you wish to adjust the SRP for all the vendors.

  2. Click the Proceed button.

Caution: If you have tens of thousands of records this process may take a long time (20-40 minutes).
