Duplicate Codes

Error Message

When creating or working with a Code Table, you may see the following error message:

There are a number of duplicate codes which could be problematic for pricing. This should be resolved before continuing.

Use the following steps to assist you.

Examine the Duplicate Codes

  1. The error message dialog box options are Ignore or OK.

  2. Click OK.

    A list view of the records flagged as having duplicate codes appears.

  3. Examine the records so that you understand any differences between them.

    You may note the differences to be very slight.

  4. You may opt to delete duplicate items

    or

    You may opt to slightly edit the name of the duplicate code.

  5. Click Done to exit.
