Navigating in FrameReady

Navigating between the FrameReady files is easily accomplished by clicking on the corresponding icon button.

Navigating Between Screens (or Filing Cabinets)

Screenshot of FrameReady's main navigation.

  • These buttons are always located at the top.

  • They may compact or adjust on some screens.

  • When switching from one file to another, it is not necessary to close, save or exit the file you are currently viewing. Just click on the icon.

  • When you are in a file, e.g. Price Codes, the icon for that file will not appear.

How to Navigate in FrameReady (Video)

Navigating Between Views

  • Each of the FrameReady files has two views; a form view and a list view.

    • A Form View has forms for you to fill out. It represents a single record in the database.

    • A List View is a list of multiple records.

  • You can toggle back and forth between views by clicking on the Form View or List View button at the top of the screen.

  • When you are in the List View Screen, the button will offer to take you to the Form View (the Form View button is located directly below the four yellow arrows).

  • When you are in the Form View Screen, then the button changes to List View, and vice versa.

Navigating Between Records

Yellow Arrow Buttons

The yellow arrow buttons are used to move between records.

  OR  

  • Go to First Record - Yellow arrow left

  • Previous Record - Yellow triangle left

  • Next Record - Yellow triangle right

  • Go to Last Record - Yellow arrow right

The Number of Records

  • The number of records in the file is always displayed somewhere on the Form View screen.

    • Message Center: bottom right

    • Contacts: top right

    • Price Codes: top center

    • Gift Certificate / Store Credit: top right

    • Purchase Order: top right

    • Invoice: top right, 1/3 of the way down

    • Work Orders: bottom right

    • Consignments: top right

  • If you are in a found set of records, then it displays your position in the set and the size of the set. For example: 2 of 4  Total: 2698 (Unsorted)
