Layered (Stacked) Frames Detail Screen

Work Order > Framing Materials section > Layered Frames icon button

Tip: The tabs at the top of each Work Order Detail Screen allow you to move through the Work Order in different ways.

Stacked or Layered Frames on a Work Order Explained

  1. On the Work Order, click the Stacked Frames icon button.

  2. The Layered Frames window appears.

Note: Frame1 is always closest to the artwork. Fillets and Extenders will not increase the size of the frame that are layered on top of them. This allows for a proper fit within the rabbet of next frame.

  1. Click the Clear button to remove the information from this layer. Doing so will move the other frames down.

  2. Click the blue button (override) to open a window where you can enter a Moulding Number and Retail Price for the entire frame. 

  3. Click the Modify button to make adjustments which will affect the outside dimensions of the frame. This is particularly important when stacking or layering one frame upon another.

    An accurate calculation is possible by adjusting the lip size of the inner frame.

Important: Changes made using the Modify button are saved in the Price Codes file and applied to the current Work Order AND all future orders.

  1. Click the Insert button to move Frame 1 into the Frame 2 position, etc.

Fillet or Bevelled Accent is too Wide

  • Your fillet or Bevelled Accent™ is so wide that it covers up too much of the artwork.

  • Verify the sight size of the fillet in the Width field.

  • Enter  0  in Lip field; this will increase the overall size of the frame.

3/16" is the assumed Lip size

  • 3/16" is assumed as the Lip size if the field is empty.

  • When measuring the lip of a moulding or liner, subtract 1/16" from the actual size as a fitting allowance. This gives you an accurate size for the next frame.

  • For example, if you have a liner that has 1/2" lip, then the size must be entered as 7/16".

Note: When you return to the main Work Order screen, the icon changes color to indicate the number of frames being layered. Only the Frame1 moulding appears on the screen, but the total price is calculated and displayed. All mouldings are detailed on the printed Work Order.
